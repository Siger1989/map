# 本地等高线字体

- `Noto Sans Regular/0-255.pbf`：从 OpenFreeMap 的公开字体服务取得的 0–255 字形段，用于数字等高线及拉丁字符。来源：https://tiles.openfreemap.org/fonts/Noto%20Sans%20Regular/0-255.pbf 。
- Noto 字体使用 SIL Open Font License 1.1，完整授权随附于 LICENSE.txt；原始授权：https://github.com/notofonts/noto-fonts/blob/main/LICENSE ，blob c82d72e422e2d08c5ab439b6bac7c2177ea0c565。
- 国内底图使用本地字形；中文地名采用天地图栅格注记，中文端点文字采用地图引擎的本机字体。

安装与启动
直接复制并运行“山兔桌面.exe”即可，无需保留同目录的应用文件夹。Windows电脑需要可用的 Microsoft Edge WebView2 Runtime；PNG渲染还需要系统安装 Microsoft Edge 或 Google Chrome。电脑无需另装 Python 或 Node。

地图与行业工具
同一窗口可切换“地图”和“行业生图”。地图在线图源需要网络。地图下方的移动控制器按住并偏离中心即可平移，松开停止；绘图和双图时可用，锁定时不移动。桌面端不显示开始记录入口，手机端记录及已有轨迹不受影响。鼠标绘图、框选等操作以各自当前工具提示为准。

完整工程 JSON
使用完整工程 JSON 在手机与桌面间迁移项目数据。文件包含支持范围内的照片、图源、CAD原始文件、行业Excel及相关工程和设置数据。导入前会检查并预览，确认后按稳定ID合并：同ID对象由导入文件覆盖，接收端独有对象保留。请把JSON当作可能含私人照片、图源授权信息和工程资料的完整备份，妥善保存。

旧 v1 备份JSON兼容导入是单独的历史格式入口，字段范围和行为与完整工程JSON不同；不要把旧v1文件视作完整工程存档，也不要据此判断完整JSON所含数据。

文件与存档位置
导出的文件、上传文件和日志写入用户文档目录“山兔桌面”。桌面应用的本地地图存档位于WebView持久化目录，与手机和网页预览分开。默认本机地址为 127.0.0.1:9190；端口占用时按应用提示处理，不要随意切换地址，以免误以为原存档丢失。

本机私有构建可能包含授权使用的私有地图配置；不要将该运行包、配置、日志或含个人数据的交换文件上传公开仓库或公开Release。桌面验证不代表Android系统文件保存/分享、GPS或后台能力已在真机验收；HarmonyOS原生包尚未交付。更多当前验证与限制见项目目录 docs/desktop-json-pan-20261008.md。

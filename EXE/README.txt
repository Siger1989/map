山兔桌面应用（本机私有构建）

启动：进入“山兔桌面”文件夹，双击“山兔桌面.exe”。
请保留整个文件夹；_internal 和 resources 是随应用一起使用的运行资源。
电脑无需安装 Python 或 Node；Windows 需要可用的 Microsoft Edge WebView2 Runtime。
PNG导出沿用原管线，还需要系统已安装 Microsoft Edge 或 Google Chrome。

同一窗口顶部可切换“地图”和“行业生图”，地图使用原完整功能页面。
全屏：顶部“全屏 · F11”或 F11；再次操作退出。
鼠标：左键拖移、滚轮缩放、右键拖动旋转/俯仰。
绘图和框选时左键用于当前任务，具体差异和验收状态见项目 docs/desktop-app-20261008.md。

地图图源在线请求需要网络；行业Excel生成SVG/PNG可在本机运行。
生成文件、上传文件和日志写入用户文档目录“山兔桌面”；地图存档保存在其 WebView 持久化目录中。
桌面存档独立于手机和网页预览，可使用地图原有导入/备份功能迁移。
默认本机地址固定 127.0.0.1:9190。占用时会提示，避免切换地址造成原存档看似丢失。
本包内含用户授权的私有地图配置，仅作本机交付，请勿上传公开仓库或公开Release。
Android GPS、相机、后台记录及分享能力不等于Windows桌面平台能力；平台实测情况见验收文档。

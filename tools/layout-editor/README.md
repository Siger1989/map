# 本地布局编辑器

入口 `npm run dev:layout`，打开 `http://127.0.0.1:9241/__layout`。地图API沿用3108的本地网页服务，另一个终端运行 `npm run dev -- --host 127.0.0.1 --port 3108`。已有服务时直接打开页面，不终止其他进程、不自动改端口。

先切换“正在操作页面”，在真实界面打开对应功能；再切回“正在选择布局”，选整个组件或单个控件。拖蓝框改变位置，拖右下角改变宽高，右侧可输入尺寸、比例和字号。方向键微调1px，Shift微调10px；支持4px网格、锁定宽高比、撤销/重做、隐藏、恢复组件默认值。

保存写入 `config/ui-layout-draft.json`。下次打开自动载入；导出/导入JSON可换电脑。草稿记录相对默认布局的偏移、可选宽高/字号、缩放、隐藏与参考手机尺寸。空宽高保留原自适应。草稿只在编辑器的预览中应用，后续正式整合需统一响应式对齐及44px触控目标；不会直接改变已安装APK。

模块职责：`model.mjs`校验和CSS生成；`selection.mjs`组件登记/控件选择器；`editor.mjs`交互、历史和预览；`plugin.mjs`只在Vite开发服务注册页面和本机保存接口。无运行时地图状态或几何写入。控件优先稳定ID/语义标签，动态列表使用DOM位置，页面结构变化后可能需要重新选定。尚未打开的组件保留草稿，进入对应页面才显示。

保存接口限制本机同源、256KB、有版本号且逐字段校验，临时文件重命名写入。不可解析的原草稿不会自动覆盖。功能图示位于 `artifacts/screenshots/ui-0228`，不属于源码；换电脑下载Release的图示ZIP，解压到该目录后可在窗口查看。独立ZIP自带index.html。

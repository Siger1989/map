# 本地布局编辑器

推荐入口 `npm run start:layout`，就绪后打开 `http://127.0.0.1:9241/__layout`。该命令独立启动后台地图API（3108）和布局页面（9241），不弹终端、不打开或控制浏览器，关闭启动命令不停止服务。已有匹配服务会复用；端口被其他服务占用时明确报错，不终止其他程序或改端口。进程记录和日志在`.openai/layout-server-state.log`及`.openai/layout-*-out.log`。

地图接口复用`desktop-web/server.ts`已有的四个API，用独立入口`api.ts`按需打包；不启动整站vinext/Sites/Cloudflare开发链。应用凭证仍来自本地环境，不写入布局草稿或源码。内部地形重定向保留在前端原地址，避免跨端口后无法读取像素。需要前台调试时仍可用`npm run dev:layout`启动页面服务。

先切换“正在操作页面”，在真实界面打开对应功能；再切回“正在选择布局”，选整个组件或单个控件。可搜索名称，从清单选到被其他面板挡住的控件；点选框标题拖位置，四边/四角调大小，右侧也可直接输入尺寸、比例、字号和层级。方向键微调1px，Shift微调10px；支持4px网格、锁定宽高比、靠边/居中/移回画面、撤销/重做、隐藏和恢复默认。层级只在同一父级的堆叠范围生效，整组被挡住时选外层组件调整。

保存写入 `config/ui-layout-draft.json`。下次打开自动载入；导出/导入JSON可换电脑。草稿记录相对默认布局的偏移、可选宽高/字号、缩放、隐藏与参考手机尺寸。空宽高保留原自适应。草稿只在编辑器的预览中应用，后续正式整合需统一响应式对齐及44px触控目标；不会直接改变已安装APK。

模块职责：`model.mjs`校验和CSS生成；`selection.mjs`组件登记/稳定选择器和清单；`geometry.mjs`纯拖动/缩放/对齐计算；`gestures.mjs`指针生命周期、缩放补偿与动画帧节流；`editor.mjs`组合属性、历史和预览；`plugin.mjs`只在Vite开发服务注册页面和本机保存接口。无地图状态或几何写入。控件优先已登记选择器、稳定ID/类/语义标签，动态列表使用DOM位置，页面结构变化后可能需要重新选定。尚未打开的组件保留草稿，进入对应页面才显示。

修改字号或层级不生成多余transform，避免改变固定定位子控件的参照系；作者预览CSS优先级覆盖应用自带密度限制。拖动在父级缩放后按对应CSS像素换算，尺寸变化后保持对边的位置；拖动过程不反复重建清单。保存格式保持version1，层级字段可选，兼容旧草稿。

保存接口限制本机同源、256KB、有版本号且逐字段校验，临时文件重命名写入。不可解析的原草稿不会自动覆盖。功能图示位于 `artifacts/screenshots/ui-0228`，不属于源码；换电脑下载Release的图示ZIP，解压到该目录后可在窗口查看。独立ZIP自带index.html。

验证：9项布局模型/几何/实际HTTP保存测试，2项共用本地服务器测试，以及脚本打包、控件ID关联、实际页面/脚本/草稿/地形图片HTTP检查通过。鼠标拖动、多尺寸画面和保存重开GUI尚未完成自动验收；用户要求不再控制桌面，后续依据用户在右侧窗口的手动反馈完善。实际功能包为0.2.30；此开发控制器未进入APK。

# 山兔 Windows / Mac 网页版

这是本地网页版，使用与当前安卓测试版相同的地图及业务界面，附带本地接口服务和区域地形。无需安卓模拟器、Git或安装项目依赖。

1. 首次使用安装 Node.js 22.13 或更新的 LTS 版本：https://nodejs.org/en/download 。
2. 将整个 ZIP 解压到固定文件夹；不要在压缩包里运行，也不要直接双击 web/index.html。
3. Windows 双击 `Start-Windows.cmd`。Mac 双击 `Start-Mac.command`；若提示不可执行，在该文件夹的终端运行 `sh Start-Mac.command`。也可在文件夹终端运行 `node server.mjs`。
4. 浏览器自动打开 `http://127.0.0.1:8787/`。如未自动打开，复制该地址到浏览器。保留启动窗口，关闭窗口就停止服务。

地图需要支持 WebGL2 的浏览器与可用图形驱动。Windows 可用 Chrome/Edge，Mac 可用 Chrome/Safari；Mac 真机和Safari尚未验证，不等同于所有系统版本均已验收。地图、天气、搜索、道路规划及区域外高程仍需联网；地质云1:20万仍需有效服务授权，未配置时明确提示。

网页可画线、编辑节点和拼合、按颜色记录路况、添加标记/模型、查看平剖图并导出。鼠标滚轮缩放，拖动地图平移；编辑路线时点选节点再拖。Mac触控板手势及真实Mac性能尚未验收。

收藏、路线和标记保存在当前浏览器，手机与电脑不会自动同步。换浏览器、电脑或版本前用“工具→行程与数据→数据→存档备份”导出，在另一端导入。照片原文件另行保管。使用固定地址和端口，不要混用localhost与127.0.0.1以免看到不同浏览器存储。

浏览器的保存/分享能力依系统而异，可使用下载文件；后台锁屏轨迹记录请使用Android安装包。这里的启动服务只监听本机，不能把此地址发给别人作为在线网址。

开发者可设置 `SHANTU_WEB_PORT` 换端口，或 `SHANTU_NO_OPEN=1` 禁止自动打开浏览器。若端口占用，先关闭旧的启动窗口再启动新版本；保留原浏览器数据。

模块职责：`server.ts`只负责本地HTTP、公开文件和4个现有API适配，直接复用app/api处理逻辑；界面由mobile浏览器入口构建。`scripts/build-desktop-web.mjs`打包成无需node_modules的跨平台ZIP，不包含私钥、Token、.env或个人路线。

# 山兔 Mac 应用

新版 DMG 包含使用 AppKit 与 WKWebView 的独立 `Shantu.app` 窗口，支持 macOS 13 及以上的 Apple Silicon 和 Intel。它自带两种架构的 Node 运行时，不需要安装 npm、依赖或系统 Node。用户交付版保留已注册的内置天地图与个人图源。地图界面复用网页代码，在应用窗口内运行；不再默认打开 Terminal 或外部浏览器。

打开 DMG，把 `Shantu.app` 拖入 Applications，再打开应用。服务只监听本机 8787 端口；旧版本或其他程序占用端口时会提示，不会擅自结束其他程序。退出应用会停止本次启动的服务；复用已有同版本服务时不会关闭它。应用尚无 Apple Developer ID 签名或公证，Finder/Gatekeeper 安装验收以本次交付记录为准。

路线、收藏、标记等保存在应用自己的本地存储中。旧 Safari/Chrome 版数据仍留在原浏览器，不会自动迁移：先在旧版“工具→行程与数据→数据→存档备份”导出，再到新应用导入。帮助菜单也提供迁移说明。照片原文件另行保管，不要清除旧浏览器数据。

地图需要 WebGL2 与可用图形驱动。搜索、天气、道路规划及部分地图服务需要网络或有效授权；本包未配置地质云服务授权。定位、触控板性能、后台记录与系统权限仍按平台单独验收，不等同于 Android 原生能力；Windows 行业 Python 工作台不在此包中。

`Start-Mac.command` 仅保留为内部诊断和旧便携模式入口；它会打开浏览器，不是新版 DMG 的正常启动方式。构建中的 ZIP 是供 DMG 打包使用的资源清单，用户安装入口为 `Shantu.app`。

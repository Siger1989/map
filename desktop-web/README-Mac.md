# 山兔 Mac 便携版

这是通过本地浏览器打开的便携网页版本。它包含 ARM64 与 x64 的 Node 运行时，不需要安装 npm、项目依赖或系统 Node。内置 Node 22 的 macOS 平台要求为 macOS 11 或更新版本。公开包不包含用户注册的天地图 Key；本机自用私有包会按本机 APK 预览配置读取 Key。它不提供 Windows 行业 Python 工作台，也不是原生 macOS `.app`，没有 Apple 开发者签名或公证。

将 ZIP 解压到可写文件夹，然后双击 `Start-Mac.command`。若 Gatekeeper 阻止打开，先在 Finder 中对启动器点按右键并选择“打开”；仅在确认来源可信时，才按系统“隐私与安全性”中的提示继续。Gatekeeper 的安全提示与启动文件的执行权限是不同问题；不要把 `chmod` 当作绕过 Gatekeeper 的办法。启动器只支持 macOS Apple Silicon（arm64）和 Intel（x86_64）；其他操作系统或架构会显示原因并退出。应用在浏览器打开 `http://127.0.0.1:8787/`，服务固定监听本机地址和 8787 端口。重复启动同一版本会打开已运行的服务；旧版本或其他程序占用端口时会报错，不会结束占用端口的进程。关闭最先启动的服务终端会停止服务。

路线、收藏、标记等数据保存在当前浏览器的本地存储中。换浏览器、电脑或版本前，请在“工具→行程与数据→数据→存档备份”导出并妥善保存备份；照片原文件需要另行保管。不要删除浏览器数据来代替导出。

地图需要支持 WebGL2 的浏览器与可用图形驱动。搜索、天气、道路规划及部分地图服务需要网络或有效授权。当前 Mac 包没有配置地质云服务授权，因此地质云 1:20 万图层不可用。此便携包尚未在 Mac 设备上完成安装、浏览器、触控板、性能和定位验收；浏览器能力不等同于 Android 原生 GPS、后台记录、系统分享或文件权限。

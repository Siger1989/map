# 布局调节

手机入口：地图右侧「更多 → 布局」。默认252×40px单行工具条，抓左端拖动位置；「使用」让地图照常操作，「选择」拖动界面。「多选」点选/再点取消，拖选中的组件可一起移动；外框边角调整尺寸，父子同选仅调整外层一次。默认没有组件列表、空的层级下拉、展开参数或说明区。「参数」按需显示宽、高、比例、字号、选择范围/外层、撤销重做与备份恢复；多选参数区实测总高148px。

保存后立即使用，重启自动恢复；退出会保存未保存修改，保存失败保持编辑器可用。放弃未保存恢复上次保存。非空布局保留独立的「布局」恢复入口，避免把地图工具移走后无法回来。导出/导入为与桌面一致的JSON，手机通过现有Android文件接口导出；文件选择、系统保存位置仍需手机实测。

模块与接口：

- `LayoutCustomization.tsx`：网页/Android共同生命周期，异步加载编辑视图，应用已保存样式和独立恢复入口。`events.ts`只公开打开事件，不读取地图内部状态。
- `model.mjs`：版本1校验与CSS；手机限定`.observatory`内部，布局不能隐藏编辑器或恢复按钮。
- `selection.mjs`：语义组件自动发现、稳定选择器、整块外框与内部层级、多选去重。具名登记用于易懂标签，不再作为可选组件白名单。
- `geometry.mjs`、`gestures.mjs`：纯移动/缩放计算、父级缩放换算、触控/鼠标、八边角和多选批量调整。
- `session.mjs`：单独存储键`shantu.ui-layout.v1`、历史、批量提交、本地保存和坏文件保护。不写原路线、标记、天气、离线缓存或定位设置。
- `mobileEditor.mjs`、`uiLayout.css`：独立紧凑DOM视图与样式；功能状态由session接口提供。编辑器是地图的兄弟节点，不改地图组件层级。

桌面控制器复用上述四个纯模块；原`tools/layout-editor`同名文件保留兼容导出，开发插件以原URL提供共享模块。桌面预览40%–250%、1px视觉线/5px点、可隐藏选框、Shift点选和列表Ctrl/Shift多选。JSON配置格式与现有草稿兼容；未把用户桌面草稿写入APK。

范围与回滚：应用仅在`mobile/main.tsx`、`app/layout.tsx`挂载生命周期，`MapActions.tsx`增加事件入口。移除这些接入即可停用，不需要迁移业务存档；手机也能从参数菜单恢复默认。跨不同宽高屏幕的自定义尺寸可能需重新调节，地图UI结构更新可能使部分旧选择器失效，尚未打开的面板进入功能后才可选。

验证：DOM与纯几何覆盖整块路线信息、绘制工具、未知面板、覆盖层穿透、多选父子去重、保存重开、一次批量撤销和失败保护；真实后台独立浏览器验证单项拖动/边角尺寸、多项移动、保存刷新恢复，390/360/266尺寸截图在`artifacts/screenshots/ui-0231`。浏览器触控模拟不等于Android真机、系统文件选择和锁屏/GPS验收。

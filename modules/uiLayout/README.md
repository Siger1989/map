# 布局调节

0.2.33选择范围：参数中切换「整组 / 组内组件 / 单控件 / 任意元素」。整组取最外侧功能组，组内组件取点击位置最近的独立面板或控件，可分别调按钮、图例、海拔卡片；「外层」返回父组。切换范围不清空当前选择，多选父子去重规则不变。桌面同样提供组内独立组件选项和可搜索清单。

0.2.33贴边适配：移动后自动记录距安全区边缘或中心的偏移，缩放固定当前锚边，靠右/靠下不会因缩小而离边。居中组保留居中；组内独立组件相对父组，编辑整组时已自定义的内部组件会随父组一起调整。参数底部显示参照对象、锚边和边距。原布局CSS继续负责自然尺寸，渲染只补偿translate，不改DOM层级或强制fixed。旋转/尺寸改变、内容高度改变、重新打开面板时重算；JSON version1可选anchor字段保存规则，旧草稿没有该字段仍按原样读取，重新保存会为当前可见项目补入锚边信息。该规则覆盖下文0.2.32的固定对侧/左上角说明。

`anchors.mjs`负责安全区/父组参照、锚边距离、整组子控件换算；`anchorRenderer.mjs`负责依原生响应式布局计算最终偏移，并按DOM深度批量处理父组与子组件。观察器仅处理布局尺寸和新增UI，不轮询业务数据；编辑时不覆盖正在输入的数值。

手机入口：地图右侧「更多 → 布局」。保留已打开的功能页面及当前层级。默认258×40px单行工具条，抓左端拖动位置；下拉切换「移动 / 大小 / 使用」：移动锁定尺寸、大小只允许拖边角、使用让地图照常操作。「多选」点选/再点取消，父子同选仅调整外层一次。默认没有组件列表、空层级栏或展开参数区。

0.2.32默认整体缩放：拖八边角或改宽高时，文字、图标、内边距一起变化，保留内部居中/靠边对齐；拖边角固定对侧，输入尺寸固定左上角。取消「整体缩放」才单独改外框。字号显示首处文字经过缩放的实际px（非容器继承字号）；修改会统一所选文字，清空恢复默认。混合大小的文本以首处为参考。

移动接近其他组件的边缘/中心或屏幕边缘/中心时，显示1px粉色对齐线并轻吸附；参数中可以关闭。「上一层 / 下一层」越过同父级最近的显示层级，不调整DOM父子结构；整组被其他父级遮住时选外层再调整。参数还含选择范围/外层、比例、撤销重做；「更多」内有居中、导入导出和恢复。参数按需展开且内部滚动，总高度不超过178px。

保存后立即使用，重启自动恢复；退出会保存未保存修改，保存失败保持编辑器可用。放弃未保存恢复上次保存。非空布局保留独立的「布局」恢复入口，避免把地图工具移走后无法回来。导出/导入为与桌面一致的JSON，手机通过现有Android文件接口导出；文件选择、系统保存位置仍需手机实测。

模块与接口：

- `LayoutCustomization.tsx`：网页/Android共同生命周期，异步加载编辑视图，应用已保存样式和独立恢复入口。`events.ts`公开打开事件、`isLayoutInteraction`指针路径判断；面板关闭逻辑通过`data-layout-entry`/`data-layout-ignore`标记保护当前页面，不读取地图内部状态。
- `model.mjs`：版本1校验与CSS；手机限定`.observatory`内部，布局不能隐藏编辑器或恢复按钮。
- `selection.mjs`：语义组件自动发现、稳定选择器、整块外框与内部层级、多选去重。具名登记用于易懂标签，不再作为可选组件白名单。
- `geometry.mjs`、`gestures.mjs`：纯移动/缩放计算、父级缩放换算、触控/鼠标、八边角和多选批量调整。
- `alignment.mjs`：拖动时缓存可见同级参照、最近边/中心吸附及辅助线绘制。`layers.mjs`：同父级显示层级升降。二者不持有业务状态。
- `session.mjs`：单独存储键`shantu.ui-layout.v1`、历史、批量提交、本地保存和坏文件保护。不写原路线、标记、天气、离线缓存或定位设置。
- `mobileEditor.mjs`、`uiLayout.css`：独立紧凑DOM视图与样式；功能状态由session接口提供。编辑器是地图的兄弟节点，不改地图组件层级。

桌面控制器复用上述共享模块；原`tools/layout-editor`同名文件保留兼容导出，开发插件以原URL提供共享模块。桌面预览40%–250%、1px视觉线/5px点、可隐藏选框、Shift点选和列表Ctrl/Shift多选；同样分移动/大小模式。JSON格式与现有草稿兼容，缩放写原scale字段，未把用户桌面草稿写入APK。

范围与回滚：应用在`mobile/main.tsx`、`app/layout.tsx`挂载生命周期，`MapActions.tsx`提供事件入口。ControlDock、LayerWindow、PlaceSearch、QuickAdd、RouteDisplayControl、WorkbenchSort及文字建议仅在关闭判断中调用公共事件保护。移除入口/保护即可停用，不需要迁移业务存档；手机也能从参数菜单恢复默认。跨不同宽高屏幕的自定义尺寸可能需重新调节，地图UI结构更新可能使部分旧选择器失效，尚未打开的面板进入功能后才可选。

验证：纯几何/DOM覆盖八边角整体缩放、父级比例补偿、多选共同极限、字号换算、对齐线阈值、层级升降和外部点击保护。0.2.32独立后台浏览器实测当前工具面板保留、模式隔离、图标/文字缩放为80%且两轴居中关系不变、实际字号、数值宽度、吸附、保存重开；390/360/266工具条40px，未选中展开133px、选中不超过178px。桌面200%线/点、多选移动/比例/撤销、单项内容缩放通过。截图在`artifacts/screenshots/ui-0232`；浏览器模拟不等于Android真机、系统文件选择和锁屏/GPS验收。

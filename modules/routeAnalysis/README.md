# 路线分析

- 职责：从有时间/高程的轨迹计算速度、分段坡度及连续50米坡度，生成地图边颜色。
- 入口：`metrics.ts`；`analyzeRoute` 与 `analysisColors` 是纯函数，不读取存储、不请求网络、不改坐标。
- 配置：`config.ts` 集中定义颜色、阈值和采样规则。速度单位 km/h，坡度单位百分比，正负表示上/下坡。
- 依赖：navigation 距离函数和 tracks 类型。地图/记录/详情通过参数调用，分析模块不访问其状态。
- 数据不足：时间缺失、时间倒退、超过120秒、异常速度不着速度色；高程缺失断开，30米以下不推断坡度。灰色表示数据不足。
- 连续50米：以原始采样点为窗口终点，线性插值起点，结果是离散样本估计；跨暂停或缺测不计算。采样稀疏时不能解释为精确最大坡度。
- “陡坡提示”仅基于高程，不能判断落石、冰雪、临崖或可通行性，不能命名为已识别全部危险路段。

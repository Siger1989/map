# 区域离线路由

入口 `provider.ts`；`tryOfflineRoute(stops, mode, signal, preference?)` 按路线模式精确匹配离线图：步行用 `pedestrian`、驾车 (`auto`) 用 `motorcar`、摩托车用 `motorcycle`。`bicycle` 没有离线路网；自动模式下交给原在线规划路径，仅离线模式提示不支持。主导航接入需确保 `motorcycle` 只尝试本地摩托车包，不映射为汽车或自行车在线 costing。在线偏好直接跳过离线引擎，不改变原在线供应商。

离线道路名搜索会跨已下载的图包给出地点建议；建议结果不代表当前出行模式的路网覆盖或可达性，规划时仍按上面的 profile 精确匹配并验证。

下载沿用一次受限 Overpass 区域请求，单区最多100km²；每包最多24MiB、60000节点/150000条有向边，最多8包。不自动重试、不另建凭据、不批量拉取大范围数据。图包 v2 记录 profile、有向道路边的 OSM way ID、via-node 转向限制及 OSM 署名/时间/范围。A* 状态包括当前节点和进入道路，以过滤已知 `no_*`/`only_*` 转向。汽车和摩托车分别下载、保存、导入及匹配，不能互相冒用。

旧 v1 步行图继续按旧格式验证、完整性校验并用于步行；它不能用于汽车/摩托车。任何 v1 中伪装成车辆 profile 的图会被拒绝，车辆需重新下载 v2 对应 profile。新图可导出转移设备。删除图只删除路网存储，不清理地图瓦片或轨迹。

车辆通行与方向读取 OSM 的 `access` 层级、`motorcar` / `motorcycle` 专用值、方向性访问值、`oneway` 与已知经单个 via node 的转向关系。无法解析时间条件时，涉及道路会保守排除。Via-way 或其它不支持的转向关系也会排除关系涉及道路；转向关系的 `except=*` 与 profile-specific 限制分别处理。OSM 未记录的数据不会被补齐；中国各地禁行、禁摩、时段规则、施工、收费/道路等级与实时交通无覆盖保证。估算时间使用固定粗略速度，不含实时交通。使用者须遵守交通标志和现场信息。

车辆离线目前只接受起点和终点，不接受途经点，避免每段搜索重置转向状态。起终点可匹配120米内道路；投影外的接入线按步行估算明确标为虚线，不属于机动车可行道路，也不证明穿过接入区域合法或物理可达。端点应放在已知道路上，或另行核验接入路线。

步行继续保留既有谨慎筛选行为。数据来源 © OpenStreetMap contributors，ODbL 1.0；下载保留署名。公开 Overpass 服务可能限流。离线路网不等于离线地图瓦片。

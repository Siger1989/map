# UI 连续反馈修复与半透明配色 · 2026-11-13

用户连续提出：关闭记录及其它窗口会在顶部闪一下；图层/记录内容贴边；记录内容变长没有动画；打开普通窗口右侧工具栏无理由缩短；导入图源按钮不清楚；下拉框排列不齐；定位提示文字溢出、画线提示位置不一致；画线色块露白框、线宽被箭头挤住；窗口应从所在边进入/退出；锁定界面也要有退出效果。另外明确改为半透明界面，并要求查找经典配色，提供多版本比较。

本轮在隔离 `old-engine-20261105` 工作区施工，默认预览仍为 9174，API 3108；保持既有私人配置。原生地图、羽化、真实GPS与记录数据格式未修改。没有升版、生成新APK、安装、提交或推送；当前 APK 仍是 0.2.202-test/code209。

## 本轮根因与改动

1. **关闭闪跳**：真实逐帧复现记录面板 top 从552px跳到56px、高度241px变272px，然后才退出。`SpringPresence`保留了DOM内容，但页面的实时`data-panel`已回到map，依赖该属性的定位/密度规则提前失效。现在`ControlDock`在面板上保存`data-panel-kind`，所有该面板自身的布局与文字规则改读这份随退出帧保留的属性。收藏分屏变量与CSS按实际存在的收藏面板保留到卸载，使用`:where`维持原选择器优先级。业务状态、关闭回调和inert仍立即生效。
2. **内容变高/变矮**：新增`useSpringPanelSize`观察共享面板自然尺寸，使用约280ms高度过渡，保留底边/顶边锚点，不缩放正文。动画期间取消对自身动画高度的观察，结束恢复自然高度；减少动态效果立即完成。移除记录外框阻止高度动画的`height:auto!important`，原最大高度和可滚动内容限制保留。
3. **动效方向**：新增`panelMotion`统一方向；已知底部记录/工具/画线从下方进入，收藏和顶部窗口从上方进入，独立侧边弹窗按停靠位置推断，关闭沿原方向退出。主/双图图层明确从上方进入。共享入场观察加入画线工具、提示、图层级别和方向面板等实例。
4. **锁定/解锁**：新增`focusLockMotion.css`，160ms透明度和位移过渡，`display`使用离散过渡，解锁使用`@starting-style`。隐藏对象立即禁用点击，地图锁定业务不等待动画；解锁、朝向、标记和跟随等原保留入口继续可用。支持减少动态效果，旧浏览器不支持离散过渡时按原即时显隐退化。
5. **留白和清晰度**：共享面板内容内距10px，图层248px外宽不变；实际CSS检查定位到`globals.css`仍有4px important规则，普通浮窗统一覆盖，收藏保留独立全宽结构。导入图源按钮为13px/600深色文字、明确边界；注记与坐标系使用72px统一标签列，全球境界复选独立占行，两个下拉框同宽同起点。为新增行扩大图源页合理最大高度并保留真实滚动，修正初次验证发现的导入按钮被裁切。
6. **右栏稳定**：仅去掉图源和标记入口依赖`panel===null`的限制。打开普通记录/工具/图层/图源窗口保留入口；绘制、测量、框选、锁定、双图等原任务条件保持。
7. **提示和绘制工具**：定位提示按可用空间换行，文字不再降低透明度，标题栏下8px、左16px，与画线提示对齐。画线色块外壳沿用主题/10px圆角，实际颜色保持，透明原生color input不露白框；线宽下拉80px且为箭头保留20px；绘图工具补共享玻璃表面、18px圆角、10px内距和可读选中文字。
8. **半透明与主题候选**：共享浮窗改为84%主题背景加18px模糊，正文保持完整不透明。补上ID及非嵌入式表面选择器优先级导致记录/图源/路线/绘图面板仍实色的覆盖，保留嵌入式内容的样式。奶油橙继续默认；新增海盐蓝、薄荷绿、雾紫、珊瑚、深琥珀，保留原预设。依据官方设计系统的配色角色与材质原则改编，不把这些值说成官方原样主题。来源与色值见[配色研究](ui-classic-palettes-20261113.md)。

## 后续统一门禁

- 关闭动画验收必须测退出期间的实际位置/尺寸，不能只测打开的静止图和最终卸载。
- 动效保留视觉状态到最后一帧；业务状态与可交互性立即更新。缩放、定位、记录和草稿不得受装饰动画驱动。
- 真实内容尺寸变化要过渡，文字/图表不得随外框压扁；矮屏内容仍要滚动可达。
- 普通窗口不随意删除地图工具入口；必要任务限制保持明确且一致。
- 同类提示共享安全边距；同一表单标签与输入列对齐，值、单位及箭头不得互相遮挡。图片颜色、业务语义色保留。
- 半透明只用于表面，文字不跟着变淡；浅色与深色都要看复杂地图背景上的真实效果。
- 新增窗口根据停靠边选择出入方向，锁定和解锁也走可中断的短过渡，减少动态效果可用。

## 追加：画线重复点击与绘制态右栏（2026-11-13）

根因：底栏画线在ControlDock始终派发track，page的处理器始终tracks.start()，未区分已在绘制；右侧两项入口仍保留!tracks.drawing条件，上一轮普通面板修正没有覆盖绘制态。

- app/page.tsx：绘制中重复点击时先pause、取消选中和选点后返回，草稿/撤销历史不重置，不触发complete；再点沿用start恢复当前草稿。去掉图源与标记的绘制禁显，保留其它任务门禁。绘制工具接入现有SpringPresence。
- modules/controls/ControlDock.tsx：aria-expanded与绘制选中态一致。
- modules/tracks/TrackPanel.tsx：将真实工具条DOM ref、inert和aria-hidden交给SpringPresence，底部进入/退出，不增加布局外壳。
- 本轮无新增功能模块、无删除功能；地图渲染、定位、保存格式、私人天地图配置不改。双图为独立“画线→暂停”流程，保留原流程，本轮仅源码核对，未做双图交互验收。

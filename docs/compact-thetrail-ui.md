# A 方案：紧凑地图 UI

2026-09-07。用户选择 TheTrail 参考，并要求节约空间、紧凑、小字号。本次将其浅色悬浮卡片和蓝色状态应用到山兔现有工作台。

## 实际变化

- 根据用户反馈修正首版过实的白色面板：顶部品牌、右侧工具、图层、底部导航和工具面板采用暖灰半透明表面、真实背景模糊和轻阴影。主要面板 50% 底色/14px 模糊，小控件 52% 底色/16px 模糊；文字本身不模糊。不新增持续动画，不对全屏地图做滤镜。
- 右侧工具改为独立圆形控件，内部操作减少实色块；无 backdrop-filter 支持或系统要求减少透明度时使用清晰的实色回退。手机 GPU 合成成本与静止闪烁关系仍需真机验证。
- 常用标签、地点输入和面板标题为 12–13px。主要按钮保持至少 44px 高度；压缩重复内容和间距，不缩小地图、镜头或位置控件。
- 路线标题右侧直接进入“轨迹管理”，轨迹标题右侧返回“道路规划”，移除独占一行的重复切换栏。原有起终点输入、途经点、排序和路线规划逻辑继续使用。
- 图层窗口先显示图源入口和图层开关；场景预设折叠。卫星模式、地形增强、云雨透明度只在相应图层开启时出现；详细说明与数据来源可展开。
- 通常面板不超过 38dvh / 320px，路线不超过 44dvh / 370px，长内容内部滚动。标记面板收窄并留出右侧工具间隔。
- 标记、照片导入、图源等子面板的硬编码深色背景已适配，保留用户对象颜色与地图色彩语义。
- 追加压缩剖面详情：单位/刻度/宽高横排，坐标数据与精确设置入口同排，重新采样/隐藏/删除同排；仍保留 44px 操作高度。对象操作栏显示三轴旋转数值，见 [旋转与归正](object-rotation.md)。

## 范围与实现

新增 `modules/controls/modern.css`，在 `app/layout.tsx`、`mobile/main.tsx` 末尾共用。结构变化位于 `ControlDock.tsx`、`LayerWindow.tsx`、`LayerPanel.tsx` 和 `app/page.tsx`。无新增依赖、图像素材或字体下载。

原绿色模型与圆环相机、真实地图、轨迹/照片数据格式、定位跟随、剖面、签名和图源配置均未改动。参考图只用于视觉方向，不导入其商标或地形图片，也不做手机外框/静态地图仿制。

## 验证与限制

- TypeScript 与 219/219 逻辑测试通过（含新增旋转与归正测试）。
- 网页和安卓网页资源构建通过；既有包体积与动态导入提示仍在。
- 浏览器检查了路线/轨迹切换、新增途经点、图层参数条件显示、数据来源展开、图源入口、收藏、行程照片和标记。Escape 关闭通过；未操作真实 GPS 或导入用户文件。
- 390×844、360×780 DOM 布局无横向溢出；主要按钮约 44px，路线输入 13px。正常视口截图已查看并修正标记按钮及图层选中状态对比度。
- 手机尺寸截图工具出现约半尺寸内容加空白的捕获异常，因此精确手机视觉与真机触控尚未验收。详情见根目录 `design-qa.md`；本次没有生成或发布 APK。
- 用户反馈的静止地图闪烁仍需要在实际 APK 继续复现。本次 UI 变化不能作为闪烁修复的证据。

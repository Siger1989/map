## 本次修复

选中一条轨迹后，点击顶部「继续绘制」直接沿该轨迹末端继续，不再要求选择第二次。没有选中轨迹时才展开选择列表。「新建轨迹」仍是默认主操作；实走或含时间的原始轨迹继续通过手绘副本修改，保留原始记录。

本包也包含此前尚未进入 0.2.5 APK 的源码更新：

- 底部独立画线入口，新建/续画分开，完成自动存档；默认名称含绘制时间与起点附近位置，便于查找。
- 固定逐点连线，道路与节点吸附默认开启；两点间沿道路曲线连接，按距离匹配已显示道路，移除12级缩放门槛；断路可直线跨越后继续吸附。未加载道路仍需放大，吸附不代表实际可通行。
- 顶部地点搜索、紧凑磨砂面板、统一二级界面、图源逐级返回；保留绿色3D控制器，剖面收进工具，支持对象旋转数值与归正。

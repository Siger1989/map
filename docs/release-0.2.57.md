# 山兔 0.2.57 测试版：框选修复、路线导入、等高距与运动朝向

> 已从包含最新路线编辑、手动终点和启动修复的源码全新构建安装包，并发布到GitHub测试Release。此前同名旧APK已被新包替换，以下大小和哈希对应本次新包。

等高线可在“图层 → 海拔等高线 → 等高线高差间隔”选择30、50、100、200米，默认最细30米。选择会保存；详细地图使用所选等高距，缩小时自动稀疏至100/200/500米以控制计算量和画面密度。普通线也标注海拔；最新视觉反馈后字号11px、沿线标注间距210px、描边1.4px，保留碰撞避让。

路线编辑支持单点颜色/备注/标记和手动设终点，多点编辑相连路段；框选加减整合进原面板，选中为原色细亮边且随地形贴地，点径与线宽可调。新增分叉保留原终点，旧分叉未选终点不再伪标末点；地图、行程点、分享图/二维码、导航读取同一终点。地图在对应路段旁显示小字备注并避让。路线分享及收藏图片使用当前底图/专题图层生成全程俯视图，保留来源署名；不含三维云雨动画和自定义模型。

用户已明确指高差间隔，本版没有提供此前误解的30/60/120米水平精度切换。DEM仍是原最高Z12地形源；成都局部FABDEM约30米，区域外Mapzen/SRTM等来源混合，不宣称全球统一30米，也没有更换为全球GLO30。等高距不等于数据分辨率或测高误差。各档共用一个后台worker及有上限的缓存。

“方向”现在提供自由转向、正北朝上、手机朝向朝上、运动方向朝上。运动模式优先采用有效GPS航向/速度，否则由连续准确定位的位移求方位，加速度只辅助抑制静止漂移；不把手机朝向当运动方向。低速、定位过期或不准确时保持上次方向，首次未确定航向时不乱转。绘制/编辑等直接地图操作暂停自动旋转，锁定模式临时浏览后可恢复运动方向。关闭定位会退出运动方向模式。

Android读取去重力线性加速度，退后台注销、回前台恢复、退出模式停止；没有该传感器时仍可用定位航向。匀速也可能没有加速度，因此不将加速度积分冒充可靠的绝对运动朝向。参考[Android运动传感器](https://developer.android.com/develop/sensors-and-location/sensors/sensors_motion)和[Location航向](https://developer.android.com/reference/android/location/Location#getBearing())。

## 本版同时交付

- 修复路线编辑工具条遮住框选退出按钮。框选提供加选和反选（减选）：多次画框取并集，减选只移除框内已选项、不删除实际点；松手矩形立即消失。退出框选保留点与勾选、返回路线编辑、恢复地图拖动，再次进入可继续增加；批量删除移到上级节点工具，清空选择单独操作。地图对象框选使用相同规则，结果页“继续框选”保留本次勾选，不再因离开收藏页清空。
- 路线与收藏增加导入入口，记录首页移除导入。显示读取进度、错误和预览；确认后加载到地图，保留原有数据。
- 用户L013.ovobj已直接导入：74点，约5.52公里。增加OVOBJ已验证v105结构、OVJSN、FIT、TCX、GeoJSON、CSV/TSV读取器，保留GPX/KML/KMZ/OVKML/OVKMZ/山兔JSON。并非所有私有版本或CAD格式通用，详见[兼容范围](route-format-compatibility.md)。
- Android注册路线文件VIEW/SEND关联，并通过后台读取、分块桥接把文件送至导入预览，供微信“其他应用打开”使用；不同微信/文件提供器的实际行为仍待真机验证。
- 图源增加WGS84/GCJ-02/BD-09对齐选择和记忆，主图源菜单一页显示。标准WebMercator栅格校正不等于支持百度专有瓦片矩阵，GeoTIFF暂不支持该转换。
- 修正图源元数据重载时暂时丢失细节上限的问题，补充瓦片、DEM和WebGL诊断；尚未复现用户真机缩放卡死及局部高程色块，不能宣称根因已经解决。
- 修复用户截图中的地图启动失败：打包后的UMD坐标转换库与主模块形成循环依赖，旧正式网页包可复现`TypeError: t is not a function`；改用等价ESM转换后已在隔离浏览器进入主页。兼容信息显示实际应用版本和错误堆栈，Android UA也使用安装版本，避免误报旧版。
- 收藏整理时未改变可见性的路线保留原hidden可选字段，避免无关改写。没有清理用户轨迹、照片、布局、收藏、缓存或迁移存储键。

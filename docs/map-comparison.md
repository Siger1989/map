## 行为与范围

- 两幅图共用相同高程源及路线、标记、照片、区域等业务数据；中心、缩放、旋转和俯仰双向同步。主地图不重新挂载，第二幅关闭时释放实例及其瓦片协议。
- 来源渲染按实例隔离，避免两幅图抢占 `shantu-map` 协议。同步相机保留目标直到真实移动离开目标，避免 RAF 与 moveend 顺序引起反馈循环。第二幅不写 URL hash 或最后视角存档。
- 主菜单收起，保留紧凑的缩放/三维/朝北/定位/标记/画线工具条和共享摇杆。两幅地图各自中心显示小十字；标记使用地图中心坐标并可编辑名称、备注、颜色。
- 画线使用原轨迹草稿和保存流程，点击任一地图追加点，两边显示同一路线；撤销、保存、暂停保留已有语义。属性修改颜色、0.5–5px 线宽和透明度。暂停或退出不删除草稿。对比拾取不触发普通查询点/高程查询副作用。
- 标记编辑仅保存明确提交的字段；取消不改存档，保存失败保留输入。收藏派生而非原标记存储中的对象不在此直接改写。
- 主标题及选图源行为36px、地图操作44px，底部属性卡限宽280px/高200px并避开摇杆，输入16px；使用既有主题令牌。常规路线卡六按钮统一36px；没有改动路线颜色、几何及存档格式。
- Android 主壳隐藏状态栏和导航栏，支持边缘滑出临时系统栏；既有原生安全区/键盘 inset 继续只消费一次。网页工具及对比标题提供手动全屏入口，预览 iframe 允许全屏。

## 图源与平地问题的核实

- 必应：合集中的 `{$x}{$y}{$z}{4}` 复合模板应转换为 quadkey；修正前同一位置5项HTTP400，修正后5项均HTTP200/JPEG。仅转换精确复合序列，独立 `{4}` 保持字面量。
- 天地图：403正文明确要求浏览器端访问；原先统一后台代理不符合密钥访问方式。官方域名改为浏览器直接HTTPS请求，实际浏览器接受情况尚待复核，不能宣称全部天地图恢复。
- 其他条目仍有连接拒绝、DNS解析失败及超时；不能统称全部图源失效或全部是本应用错误。私有合集、付费地址和密钥不写入文档/测试。
- 用户所示99.82465E/29.97957N地形发平：本地9174的高程请求代理到未运行的3108接口，返回502；同位置提供方DEM正常200。恢复现有desktop API后，9174的z12/3183/1690瓦片返回200/image/png（57209bytes）。不更换DEM，不把山体缺失归咎于影像。

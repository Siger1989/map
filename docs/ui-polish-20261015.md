## 修改及根因

- 交付前追加统一样式：导航原速度浮条、跟随条、运动提示三块合成一张主题卡；独立速度条仅锁定后保留。俯视紧凑卡优先显示错误/偏航/定位质量等正式状态，等待定位不误写跟随中；第一人称外卡不再硬编码蓝色。绘制/吸附与路线编辑复用记录/路线的surface、raised、field及accent；共享frost覆盖导致绘制框半透明，现加入共同不透明任务卡规则，保留业务线条/定位箭头颜色。
- 区域闭合后被路线卡遮住：routeVisible此前只排除划区中，闭合后旧路线选择仍在，路线卡重现并盖住面积/标题。现在区域编辑状态也排除路线卡；面积增加明确文字标签，保留已有几何、属性与单位。390/360区域编辑标题、面积及周长可见，无横向溢出；关闭编辑成功。用户当前页仅做只读核验，没有改动其选点或名称。
- 区域卡顿：区域准星每次移动把上一点传给snapRoad，导致反复同步构建可见路网并求路径。现在预览只做近邻吸附，确认点才求沿路边界；roadPath增加3000输入点和150000端点候选检查预算。超预算回退直线，不会无限求路。白色描边+深色底环显示真实边界点；Escape与取消退出，闭合前先校验无效区域。
- 路线表单：操作排移到起终点下方，定位按钮红色；空输入不显示搜索操作；整行和输入底色表示选择。标题仅路线名，移除加载文件快捷入口及“路线规划”重复文字；导入功能仍有独立菜单入口。
- 结果卡：默认两排六按钮，详情展开保留原功能，无海拔数据不画巨大空图。里程同行新增颜色/粗细快捷控件，真正作用于规划线；已有匹配收藏立即更新，写失败保留旧样式并显示提示。旧路线无style兼容，已有自定义样式保留。
- 分享：操作按钮有底色/边框，JSON/CSV、GPX/KML等按需展开；未实际发送、上传或导出用户数据。
- 锁定位置：旧导航锁定bottom=128、开始记录bottom=116使44px按钮重叠。改为同一底部锚点+60px间距，取消锁定态额外bottom覆盖。
- 定位：导航箭头使用8倍密度的蓝色立体明暗面图像；可信GPS方向+真实净位移、精度门槛、3°死区、大转向连续确认。停下/小范围漂移不乱转，15秒确认窗口兼容6秒间隔新定位。没有借用规划路线方向。
- 配色：分类参考Tableau10，线条预设参考Set1；只投影替换旧默认分类色，不覆盖用户自定义配色。参考：https://d3js.org/d3-scale-chromatic/categorical 。
- 编辑：属性入口改备注，备注内容增加边距；自定义颜色按钮使用主题底色。名称键盘避让区分页面缩小/覆盖，标题和操作可达。
- 功能切换：统一保存守卫覆盖底栏及框选、划区域、剖面、中心标记等快捷入口；有效路线/线稿先保存，失败保留编辑并显示页面提示。编辑界面在其它面板打开时卸载，返回地图可继续。不会自动结束记录或强行提交未闭合区域。
- 比例尺：真实MapLibre刻度继续变化，最大44px；数字在细刻度下方，背景透明。

# 山兔 0.2.86-test：自动地图缓存与路线优先

地图浏览时自动保存成功取得的瓦片，再次查看相同图源和级别时读取本机缓存。选中路线后，优先保留沿线瓦片；地图停稳后单并发补充附近影像和地形瓦片。

- 入口：记录工具 → 离线地图。默认开启“边看边缓存”，路线两侧各1公里，可选500米或2公里。
- 自动缓存上限256MiB、4096项，满额优先淘汰非沿线旧瓦片。关闭自动缓存仍可读取已存数据。
- “清理自动缓存”有确认，只清理新增的独立缓存库；轨迹、照片、图源配置及主动下载的离线包保留。清理会取消补图，旧请求不能写回。
- 补图只在地图停稳且可联网时执行，移动、切后台、换图源、省流、仅缓存模式立即取消。每轮最多24个请求；不主动预取天地图和OSM公共标准瓦片。
- 离线时允许读取已过在线有效期的缓存。浏览过一个级别不等于已下载整条路线的所有级别；首次访问和未缓存区域仍受网络/图源速度影响。

模块、策略和限制详见[自动缓存说明](automatic-map-cache.md)。本轮不修改原生定位/后台轨迹记录、用户存档格式、APK包名和签名；此前记录中断问题未在本版修复。

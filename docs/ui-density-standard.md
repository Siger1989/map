# 地图操作 UI 密度规范（2026-09-09）

用户要求所有地图操作浮窗有统一尺寸上限，禁止用空白占据地图。

- 外框最大高度统一为 `min(28dvh, 200px)`；宽度最多300px，并扣除侧边地图工具占位。由 `modules/controls/compact.css` 的共享变量控制，不允许各模块另行放大。
- 行间/列间间距最多4px；面板内边距4px；标题13px以内、正文/按钮11px、次要数据10px。触控区域保持至少44px，减少装饰、重复文字和空行，不把整块触控区域涂成大圆。
- 常驻面板只保留当前任务、必要数据和直接操作。操作栏不均分无关空白；提示单独一行，长句截断或收进更多选项，不允许挤成竖排。
- 超出上限后内部滚动，标题、关闭和关键操作保持可达。二级设置不再增加第二块常驻浮窗。
- 测量用单一小卡片：点标签/更多/关闭一行，结果紧凑显示，添加/删除/撤销/保存一行。坐标、投影示意及分享放在更多选项；地图水平参考线及投影持续显示。
- 收藏列表全宽、高度与地图分界统一复用上述高度变量，禁止只缩列表而保留旧地图占位。底部工具距离安全边缘4px、17px图标/44px触控，常用操作一行，展开后换行且无滚动条。
- 页面级照片/分享图预览是用户明确打开的内容视图，内容画布可铺满其页面；其操作栏仍遵守本规范，不拿内容画布冒充地图操作浮窗。

适用入口：ControlDock（路线、行程、工具、图层等）、标记摘要/编辑/详情、测量、剖面控制、地图选择工具。新增地图操作浮窗必须复用该上限。

验收：390×844、360×780及用户宿主缩放造成的266×575；检查计算后的外框高度、文字无竖排、无横溢、44px操作目标、滚动后仍可关闭/保存。不能以截图缩放显示代替CSS尺寸测量，也不称作真机验收。

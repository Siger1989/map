# 地图操作 UI 密度规范（2026-09-09）

用户要求所有地图操作浮窗有统一尺寸上限，禁止用空白占据地图。

- 外框最大高度统一为 `min(200px, 可视高度减去上下操作及安全区)`；宽度最多300px，并扣除侧边地图工具占位。由 `modules/controls/compact.css` 的共享变量控制，不允许各模块另行放大。
- 行间/列间间距最多4px；面板内边距4px；标题13px以内、正文/按钮11px、次要数据10px。设置/编辑行参考收藏夹36px，地图直接操作和主要底栏保持44px，减少装饰、重复文字和空行，不把整块触控区域涂成大圆。
- 常驻面板只保留当前任务、必要数据和直接操作。操作栏不均分无关空白；提示单独一行，长句截断或收进更多选项，不允许挤成竖排。
- 超出上限后内部滚动，标题、关闭和关键操作保持可达。二级设置不再增加第二块常驻浮窗。
- 测量控制卡与默认常显的投影图框组成一个垂直布局。投影图框不属于控制卡滚动区，不提供投影开关，不截断坐标标签与投影线；数值/图形/当前线段集中于图框。坐标和分享在更多选项。
- 收藏是内容页面，不套普通浮窗200px限制：目录约占72%，下方地图至少180px，两者共用分界变量。选择目标时按完整几何自适应居中。收藏管理弹窗挂载document根节点，不能受分栏裁剪。底部工具距离安全边缘4px、17px图标/44px触控，常用操作一行，展开后换行且无滚动条。
- 页面级照片/分享图预览是用户明确打开的内容视图，内容画布可铺满其页面；其操作栏仍遵守本规范，不拿内容画布冒充地图操作浮窗。

适用入口：ControlDock（路线、行程、工具、图层等）、标记摘要/编辑/详情、测量、剖面控制、地图选择工具。新增地图操作浮窗必须复用该上限。

验收：390×844、360×780及用户宿主缩放造成的266×575；检查计算后的外框高度、文字无竖排、无横溢、36px内部行与44px地图操作、滚动后仍可关闭/保存。不能以截图缩放显示代替CSS尺寸测量，也不称作真机验收。

2026-09-10补充：用户要求所有间距和文字比例参考收藏夹，重点减少内边距和重复留白；键盘弹出不再用28dvh二次缩小面板。Find X8 Ultra以412×860、393×820、360×780与266×575等CSS视口和键盘缩小视口复核；系统字体放大仍需真机检查，物理3168×1440不能直接当CSS尺寸。

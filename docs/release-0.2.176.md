# 0.2.176 独立私人测试包

本轮沿用WorldWind老引擎，React界面与业务保留，不是Filament版。独立包 `com.shantu.oldengine` / 山兔·优化 / 0.2.176-test / code183；可覆盖安装旧的“山兔·优化”，不覆盖正式山兔。保留175及全部旧包。私人天地图和39源保留，含凭据产物不公开发布。

## 本包修改

- 小窗更新失败保留上一有效会话，增加非敏感服务/主进程退出记录。浮窗MVT在创建坐标与属性对象前检查预算，保留地名额度，降低复杂区域分配峰值。原手机退出根因尚未确认。
- 锁屏地图按可见瓦片公平分配原8000顶点预算，完整路径取舍，避免中心复杂瓦片耗尽邻近道路容量；外圈宽范围渐隐仍保留。网络缺图与系统限制不能由预算算法消除。
- 真实手机罗盘朝上与N；熄屏低频节能；可选锁屏地图常亮。独立开关记忆不变；不主动点亮屏幕、不含AOD、不绕过锁屏认证，手动电源键仍可熄屏。
- 点标记的第一个卡片有“复制导航”，复制信息后打开高德地点，不强制驾驶模式。
- 路线缓存点击即建立同ID准备任务，在收藏可查看准备、进行、暂停和失败状态，再按真实任务继续。
- 固定25米海拔填色，不再被等高线间隔牵动；填色与等高线共同开启时使用实际SDK批量绘图对比色。导航展开移除内层滚动约束。

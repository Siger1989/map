# 气温、起点接入导航和路线分享

## 使用

- 图层 → 气温：当前地图区域的 Open-Meteo 2 米气温预报，按颜色区分，使用时间轴所选时次；显示 ℃、时间和固定色标。25 个约0.32度网格，缺数据处透明。与海拔/地质着色互斥，保持道路地名可读。不是全球同屏实测温度。
- 路线规划：输入起终点后必须选择搜索结果或地图坐标。原先不满足条件直接灰掉，现点击会明确指出待选地点并聚焦输入框。
- 规划、手绘、收藏的开始导航先选择驾车/骑行/步行。路线模式改变时道路路线重算；手绘/记录保留几何，用时估算。GPS准确位置不在起点时，同模式规划到原起点，并将其作为必须经过的检查点，再继续主体线路。室内模式进入导航时切回自动定位；精度不足不推进。
- 各列表和导航卡片有分享：完整路线图片、GPX/KML文件、高德导航链接。导航中图片含到起点的接入段。高德按所选模式重新算路，与原线形可能不同；多途经点按顺序分享每段，保留完整原线形用GPX/KML。
- 图片为独立二维底图，包含整条线、起终点标记/名称/坐标、主要地名、全程距离/预计用时、海拔范围/升降和海拔图。图片不改变正在浏览的地图视角。高程缺失断开，不填海平面或编造累计升降。
- 图片下方离线二维码：工具 → 扫码载入路线，或从分享图片识别；图源扫码也能分流识别路线码。先预览名称/起终点/模式/简化级别，确认后载入本机收藏/轨迹。二维码不含原始轨迹时间和实测高程。
- 二维码超限逐级简化弯道，必要时概括为直线，保留各段起终点、主要范围和途经点；预览/图片明确写“概括路线”和简化阈值，不能认为直线段已验证可通行。原图片和GPX/KML不受简化影响。极多独立分段/地点信息仍可能无法塞入一个码，明确提示分段或附文件。

## 模块边界

| 模块 | 入口与接口 | 依赖 |
| --- | --- | --- |
| weather | TemperatureLayer.update、temperatureFeatures、TemperatureLegend | 现有天气网格/时间；MapLibre |
| guidance | NavigationStart、departure.connectDeparture、useGuidance | navigation.provider、position；检查点限制防止跳过起点或回匹配已过段 |
| routeShare | data适配、mapImage/image、RouteShare、qrCodec、qrImport、RouteQrReader | 地名底图、journey高程、outdoor交换；qrcode生成/jsQR读取、fflate压缩 |
| Android | RouteOutput、RouteShareProvider；NativeBridge.routeOutput/routeLinkShare | 独立缓存和临时只读URI；复用文件选择器，不改变照片Provider |

新增 source=shared/navigationMode 元数据用于断开多段的扫码路线；旧字段/存储键/备份版本兼容，原时间记录不改。压缩包长度/解压输出、点数、坐标和模式有上限与校验。二维码不自动联网，不直接写入存档；只有用户点载入才合并，失败保留原数据。

跨模块通过props、已定义的route类型和NativeBridge调用；回滚可整体撤回本轮提交，保留旧格式数据，旧包不识别新增分享来源时只忽略该新类记录。无业务模块删除；原实走GPS采样/照片/图源协议/签名配置未改变。

## 验证记录

类型、260项全量回归已通过（最终交付数量以Release为准）；二维码测试覆盖编码→jsQR→解码、激进简化与原几何不变、损坏和超限拒绝。接入导航覆盖同模式、原起点检查点、折返重合段、端点偏移拒绝；温度覆盖时间/缺失/色层互斥。

浏览器真实地点搜索：成都东站→春熙路规划10.1km/24分钟成功。390×844/360×780扫码预览及导航模式无横溢；模拟定位/道路服务确认 bicycle 接入到主体起点。真实底图和地形生成图片成功，最终绿色线路与Canvas起终点名称明确可见；从实际分享图片的390px预览截图用jsQR成功还原模式、3个线形点和起终点名称。未连接安卓真机，手机导航效果/物理相机镜头/室内定位精度/道路闪烁仍待实际安装验收。

外部导航按[高德 URI 路径规划文档](https://developer.amap.com/api/uri-api/guide/travel/route)实现；[坐标系说明](https://developer.amap.com/api/uri-api/gettingstarted)采用WGS84，骑行ride、步行walk、驾车car。实际调起取决于手机浏览器与安装的高德客户端，当前未做目标真机验证。

气温样式按后续反馈缩为约60px高，默认只显示时间/色带，数据说明点开查看；填充不透明度提高到0.90，配色更饱和。多剖面说明见 [multiple-sections.md](multiple-sections.md)。

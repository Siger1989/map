# 山兔 0.2.10 独立测试版（2026-09-08）

[下载APK](https://github.com/Siger1989/map/releases/download/v0.2.10-test-standalone/Shantu-0.2.10-test-standalone.apk) · [发行与校验](https://github.com/Siger1989/map/releases/tag/v0.2.10-test-standalone)

## 本版更新

- 扫码载入轨迹图和详情，先查看里程、爬升、高程图及起终点名称坐标；点击导航才选择驾车/骑行/步行。完整精度仍可另附GPX/KML。
- 修复标记名称远离实际坐标。添加标记直接编辑图标、名称与可复用自定义属性；18种图标，字段增删、具体数据列和Excel `.xlsx`导出。
- 统一收藏所有地图对象，按省市分类、紧凑列表、批量JSON/Excel保存或分享，保留原路线分组入口。
- 剖面图片追加平面地图、剖面边框及所有点的坐标表；长表分页输出。
- 新增道路吸附闭合区域，可长按调节边界点；轮廓可拉伸成模型并继续普通几何体操作。轨迹点点击出现选中圈后可直接拖动。
- 地下模型默认局部开挖地表，可关闭；被地形遮挡部分仍半透明可见，亮黄接触面/浅黄侧壁；地表外模型穿入地形也显示交界。真实DEM网格近似，不是CAD精确布尔。
- 收紧划区域、绘制、轨迹编辑浮栏并避让右下控制摇杆；路线规划面板降低高度，保留44px触控按钮。
- 恢复地质图例和地质云来源选择。包含0.2.9气温图层、多剖面、导航接入与分享，以及扫码完整取景/镜头切换、室内网络定位和重复地图刷新修复。

使用、文件变更和模块接口见[完整说明](https://github.com/Siger1989/map/blob/main/docs/markers-areas-and-collections.md)。

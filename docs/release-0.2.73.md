# 山兔 0.2.73 磨砂界面与吸附修复测试版

- 全局无亮边深色磨砂，保留个性化主色；顶栏48px、底栏56px加安全区，底部实心图标。标题、关闭按钮、输入、测量和绘制面板增加安全留白。

# 山兔 0.2.21 多点测量与照片标记测试版

[下载 APK](https://github.com/Siger1989/map/releases/download/v0.2.21-test/Shantu-0.2.21-test.apk)

## 改动

- 统一地图操作浮窗上限：高度min(28dvh,200px)，宽最多300px，间距最多4px，超出内部滚动。测量合为单一卡片，坐标/详细投影/分享按需打开；保留44px触控。规范见docs/ui-density-standard.md。

- 测量可用“＋添加点”连续添加 A/B/C 等点，拖动调整、删除所选点并撤销（删中间点后相邻点顺序连接），或点选已有地点、模型、照片、路线/区域节点取坐标；地面海拔自动读取。每段显示长度、朝向、水平夹角和高差，配水平参考线、垂直投影及非等比示意。
- 可保存多组测量到地图，关闭、重开后保留；打开记录继续编辑并更新保存。可移除并撤销一次移除，重新测量不删除已存记录。
- 新增工程风格测量连线剖面图，含累计距离、海拔、点坐标、分段长度/夹角/朝向；每页10段，生成1200px JPEG供保存和系统分享。注明横纵比例不同及未连续采样地形。
- 照片放在标记摘要的导航/编辑/拍照/详情操作栏下，直接看缩略图。照片和地点标记使用一个地图对象；照片跟随标记坐标，隐藏或删除标记后不会残留地图图片。行程绑定标记不能单独移动。退出/删除标记清空路线选择，避免突然出现选中路线的终点提示。原始照片文件及路线保留。
- 照片保存并行处理元数据/哈希与图像，减少原图重复缩放、取消写完后再次读取整个照片库；存储失败重试复用已处理副本。界面显示读取、生成副本、写入阶段，事务完成才提示保存成功。天气仍在后台查询，不作为保存成功前提。

- 收藏页列表与地图共用高度变量，消除列表变小后旧72%占位造成的空白；底部工具贴安全边缘4px，常用操作一行、更多操作换行，无滚动条，已保存测量随地图区域对齐。

## 验证

382项逻辑检查、类型检查和网页构建通过；浏览器CSS 390×843与360×780无横溢，44px操作目标；用户缩放下实际266×575的布局另行修正并验证，提示独立行、点标签不被挤掉；收藏另外复核393×852、360×780和266×575列表/地图边界相接、底部工具不溢出；该轮截图工具失败，按DOM几何记录验收。实际从模型选C点、多点保存关闭重载重开、JPEG生成、照片保存/解码/摘要展示/无重复pin均通过。截图接口存在缩放加边框，不能替代真机触摸验收。旧版手机十几秒保存最终成功；本次手机相机处理耗时、系统分享及触控仍待真机验证，不宣称已达到某个秒数。

# 山兔 0.2.47：影像层级锁定与道路透明度

- 右侧加减号上方新增图层按钮：自动时显示当前视图的大致层级，锁定后显示“锁N级”。点开可查看当前图源、选择固定影像层级或自动，并进入原有图源选择。
- 固定层级控制当前影像源的瓦片层级和倾斜视角LOD，避免同一画面因旋转、缩放混用不同层级影像。仅控制底图，不替换地图样式或路线、记录、标记。支持内置天地图、地表/云况影像和导入的瓦片图源；单张影像及开源矢量底图不提供影像层级选项。切换图源回到自动。
- **锁定有缩小边界**：到达该层最远可显示范围后停止缩小，保持同一级影像；想看更大范围需切回自动或选择更低层级。高于当前视野的层级显示“先放大”，不擅自跳动镜头。锁定不能消除图源同一级内部已有的拍摄批次/拼接色差。
- 道路/注记不透明度0–100%，右侧小窗和“图层→道路与河流”都可调。开源道路/河流/铁路/路名按原样式比例变淡；天地图透明注记图片整体变淡，天地图矢量底图中已绘制的道路无法单独分离。轨迹线、路线数据和其他专题图透明度不受影响。
- Android返回键可关闭右侧图层小窗。沿用已有签名、包名与存储键，不迁移用户数据。

验证：类型检查、4项定向测试通过，其中使用已安装MapLibre真实瓦片覆盖算法检查27组缩放/倾角/朝向组合，锁定13级时均只选择13级；另测解锁/换源恢复、范围限制和透明度不累计。网页生产构建、APK编译、签名、zipalign、版本及473项地形资源检查通过。

限制：截图现象判断为不同层级影像混用，尚未在用户原地点真机复现；浏览器连接仍返回nodeRepl.fetch失败，未完成390×844/360×780实际截图与触控检查。需覆盖安装后复测同一点旋转、锁定/自动切换和道路透明度。

安装：Android 8.0及以上，`Shantu-0.2.47-test-standalone.apk`，0.2.47-test/code54，沿用独立山兔签名。新增cartography层级控制/适配与测试，修改TerrainMap、MapActions、LayerPanel、app接线和返回处理。HarmonyOS 6.1原生HAP/APP仍未交付，APK不代表原生鸿蒙支持。

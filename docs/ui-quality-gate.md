## 硬性规格

- 顶栏、底栏与工具共用 `--ui-glass-surface` 和 `--ui-glass-filter`，不得单独去掉顶部模糊或改成不透明来遮盖横线。2026-10-02最终方案恢复统一64%透明度及blur18px/saturate1.1，顶部采样区域向上扩展54px并裁回原栏高，地图与控件不偏移。旧“顶栏关闭滤镜”方案已撤销。修改后必须核对浏览器实际加载的CSS与源码一致，不能用陈旧Vite变换结果判断方案有效；390×857、360×780检查computed值、canvas边界、同视角截图及隐藏/解锁。横线未复现时不得宣称所有视角或Android已修。

- 2026-10-01标记UI尺寸例外：按用户要求验证约28–32px控件、11–13px字号与13px输入；不再用原36/44px控件或16px输入作为标记菜单验收条件。检查主图/双图列表、添加类型、完整编辑/属性/图案颜色/模型参数/详情和确认，功能与返回仍需可达。

- 手机预览先通过 APK 一致性检查：记录目标版本/源码与构建变体，核对内置图源和可见入口。用户最新要求预览与后续APK均内置天地图、使用已有Key；`npm run dev:apk-preview` 读取本机Key，`phone-preview.html` 不多出网页全屏。不得为匹配旧公开无Key包而移除用户要求的天地图。核验预览/构建配置一致性时不输出Key；既有安装包需重新构建覆盖后才会更新。屏幕尺寸一致不代表原生能力一致，用户存档差异不得通过清空数据消除；实机未验项如实列出，详见 AGENTS 顶部一致性规则。
- 外框圆角8px，控件圆角4px；有底色的内部圆角不得大于外框；标题安全内距至少10px，返回/改名控件至少8px，输入字号16px。
- 390×857和360×780固定设置内容应完整显示且不出现滚动。真实溢出要调整布局或提供可达的内容滚动，不得用隐藏溢出来冒充通过。
- 390×480矮屏允许内容区滚动，标题保持可见且固定。
- 地图图表和图例避开比例尺、右侧摇杆/工具及开始记录按钮。比例尺位于右上“3D/框选”下方，以44px最大宽度生成真实刻度；不得冻结实际米数。图表贴底栏上方8px、预留右侧80px。首页去掉影像日期与独立i入口，图源/地形/道路署名保留在图源说明。纯速度图例距底栏上方4px。
- 2026-10-01用户最新要求：任务执行中（测量、编辑、绘制、标记、框选、导航、记录）不显示未锁定的隐藏UI入口，普通浏览恢复；已锁定始终保留解锁入口且不丢草稿。地图右侧定位坐标框及其显示开关移除，业务坐标输入保留。3D/框选活动态只有文字变色，不叠底框。道路/路线线段置于地名下方，端点/用户说明/定位注记仍可见；重复同步不无故重排图层。
- 导航子界面在同一卡片中替换原内容，返回后恢复；退出框选直接回地图，不打开结果窗口。
- 曲线图不以非等比缩放压缩文字。外部位置不得标成GPS；不得覆盖或删除真实用户数据。

### 双图轨迹交互门禁（2026-10-02）

2026-10-02用户最新减法要求：撤销编辑窗口独立位置栏与解释文字，仅在路线标题/标记顶部操作行的空位增加一个↕图标按钮；横屏为↔。目标位置仅放aria-label/title，禁止重新增加提示栏、说明行或浮动切换面板。路线按钮44px，标记按既有紧凑例外28px；标记按最新要求省去重复标题，顶部操作必须可达，双图中的返回/分享可仅显示原图标并保留可访问名称。切换只修改宿主停靠位置，不重挂编辑组件，不保存/撤销/清空草稿，不切图源或同步新相机；输入、子页面与选择继续保留。新比较会话默认下图/右图，本会话沿用上次位置。窗口避开图源栏和操作栏，长内容真实滚动；未保存确认覆盖完整双图，禁止嵌在移动窗口中裁切。必测390×857、360×780上下往返、标题/保存可达、子页面与输入保留和关闭返回；组件测试不得代替真实边界/截图。

双图选中路线须有独立44px删除键，确认/取消在双图内完成。复用已有持久化删除；失败保留路线与确认，取消不删除，成功后两图覆盖同步移除；双图会话、视角及关联照片、标记/来源路线不得随之删除。组件验证确认与失败分支，浏览器实际检查入口/取消/返回和两种手机尺寸；不得为验收删除用户路线。

双图性能回归：副图实时相机同步触发的连续moveend不得逐帧全量重算节点；合并到最后一次视角更新后100ms，真实手势结束立即刷新，卸载取消待处理任务。默认不透明的编辑路线分为最多128顶点的小段，仅更新拖动点所在段/共同边界，必须保持全部原始边和闭环/分叉/颜色/命中，禁止以抽稀坐标或降低地图分辨率冒充优化；半透明/弱化路线保留完整特征，避免分段圆帽叠加变深。瞬时预览直接发送到另一图，结束/取消复原且无反馈循环。`tests/dual-edit-performance.test.mjs`覆盖万点路线、边界和取消；渲染模拟不等于Android性能通过。

双图普通浏览必须允许上、下图命中已保存路线和编辑节点；不可用 `pickingActive` 或标记取点逻辑提前截断路线命中。选中路线必须在双图内显示编辑入口；编辑工具栏、保存、退出与未保存确认必须可见可达。克隆第二张地图应保留真实路线/节点/拖动回调，不能只显示路线或以空回调代替编辑。操作影响同一份路线，禁止另存不同步副本；退出双图不能丢失草稿或重置视角。编辑入口触控目标至少44px。

必须用独立测试存档实际走上图选线→编辑→点选/移动节点→保存，以及下图同样操作；检查新增点、撤销和退出恢复。需检查两图节点屏幕投影各自的canvas偏移。DOM组件测试仅证明回调和入口，不代表实际MapLibre命中、坐标投影或Android触控通过。

### 隐藏UI显隐状态门禁（2026-10-01回归）

唯一判定入口为`focusLockVisibility`及page中的当前活动绑定；定位跟随的`follow.blocked`不得作为显隐条件。任务必须对应可见操作面板或真实正在进行的交互，不能把残留布尔标志、保留的草稿或地图上的已保存对象当成任务。

| 状态 | 未锁定入口 | 已锁定入口 |
|---|---|---|
| 普通浏览；仅显示已保存路线/测量/勘探线/标记 | 显示隐藏UI | 始终显示解锁 |
| 画线、区域编辑、测量、勘探、标记取点/编辑、框选 | 隐藏 | 始终显示解锁 |
| 工具/图层/图源/收藏/记录等面板或详情打开 | 隐藏 | 始终显示解锁 |
| 实际导航、记录中/暂停记录、双图操作 | 隐藏 | 始终显示解锁 |
| 绘制暂停且已退出面板，仅保留草稿editing状态 | 显示（如另有路线卡片打开，按卡片状态） | 始终显示解锁 |
| 已结束记录且面板关闭；无路线的残留rallyMode；区域选择已清除 | 显示 | 始终显示解锁 |
| 取消/完成任务、关闭面板后回到普通浏览 | 当次状态更新立即恢复 | 解锁后按当前实际状态恢复 |

必测390×857与360×780：普通浏览→画线→工具（暂停绘制）→关闭→入口恢复→锁定→解锁；另测面板打开/关闭、测量取消、框选退出。验证DOM存在性、computed可见性及按钮边界，并截图。不要靠清空草稿、刷新页面或清本机存储来恢复入口。锁定/解锁不得丢失数据或重置视角。新增阻塞条件须同时有任务入口、可见控件和退出恢复用例；页面`data-focus-lock-blockers`仅输出原因名，供回归定位。

# UI 视觉验收门禁

每次 UI 修改只检查受影响的页面、状态与尺寸。修改前先读 `AGENTS.md` 顶部门禁、`CURRENT_STATE.md`、`docs/agent-handoff.md` 和 `docs/ui-standard.md`，并说明修改范围。

## 硬性规格

- 外框圆角8px，控件圆角4px；有底色的内部圆角不得大于外框；标题安全内距至少10px，返回/改名控件至少8px，输入字号16px。
- 390×857和360×780固定设置内容应完整显示且不出现滚动。真实溢出要调整布局或提供可达的内容滚动，不得用隐藏溢出来冒充通过。
- 390×480矮屏允许内容区滚动，标题保持可见且固定。
- 地图图表和图例避开比例尺、右侧摇杆/工具及开始记录按钮。比例尺位于右上“3D/框选”下方，以44px最大宽度生成真实刻度；不得冻结实际米数。图表贴底栏上方8px、预留右侧80px。首页去掉影像日期与独立i入口，图源/地形/道路署名保留在图源说明。纯速度图例距底栏上方4px。
- 绘制时隐藏UI入口可用，隐藏后恢复不丢草稿。3D/框选活动态只有文字变色，不叠底框。道路/路线线段置于地名下方，端点/用户说明/定位注记仍可见；重复同步不无故重排图层。
- 导航子界面在同一卡片中替换原内容，返回后恢复；退出框选直接回地图，不打开结果窗口。
- 曲线图不以非等比缩放压缩文字。外部位置不得标成GPS；不得覆盖或删除真实用户数据。

## 执行步骤

1. 只改用户指定范围；记录涉及与未涉及模块。
2. 用浏览器开发者工具检查computed尺寸、实际边界、min/max、padding、box-sizing和级联优先级。重复遮挡先检查共享级联和宿主定位，不叠加猜测偏移。
3. 建立受影响页面的尺寸/状态矩阵。至少检查受影响的390×857与360×780；矮屏布局受影响时检查390×480。按功能检查遮挡目标、固定设置、内容滚动、导航替换/返回和框选退出。
4. 截取实际界面，核对边界、文字留白和触控目标。点击关键操作，并实际走一次返回路径。浏览器结果不代表真机验收。
5. 只运行与修改范围相称的定向检查。构建、类型或测试通过只证明对应检查通过，不能代替截图和点击。
6. 对每项记录PASS、FAIL或未验证。失败时记录根因、修复与再次测试条件；必需项失败或未验证，不报告视觉通过，不出包。

快速视觉确认期间不升级版本、不打包、不提交或推送。旧有自动打包/同步要求在该阶段暂缓，用户明确开始交付后再按项目交付规则执行。

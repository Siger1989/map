# 导航常用操作层级（2026-11-10 预览）

按用户当下任务和操作后果决定优先级，未采集使用频率数据。

| 阶段 | 首层 | 次层或条件 |
|---|---|---|
| 填起终点 | 选点、我的位置、途经点 | 站点齐全才显示规划；有可操作的内容才显示清除/反向 |
| 选中线路 | 使用此路线、编辑、回中、更多 | 选中线上点才提供标记；详情、缓存、显示和删除在更多 |
| 收藏路线操作 | 使用此路线排在最前 | 载入确认页；此操作不启动 GPS 导航 |
| 出发确认 | 方式、距离、预计时间；开始导航、看全程、编辑、更多 | 更多替换原卡，固定返回、内容可滚动；清除当前规划需确认，不删除收藏 |
| 行进中 | 跟随、视角、展开 | 确认偏离且可接回时，首行提供接回或查看接回路径；到达首行结束。正常行进的结束操作仍在详情 |

实际 390×857 / 360×780 检查：路线表单、收藏验证线载入、摘要和更多/返回均可操作；390 下还验证清除确认→取消。管理子页由初测 299px 收到 200px，360 下正文可见119px、可滚内容164px，实测横向溢出 0。选线卡与偏航、接回和到达是独立真实组件、合成状态，不代表 Android 实地行驶验证。截图：`artifacts/screenshots/navigation-hierarchy-20261110/`、`artifacts/screenshots/20261110-nav-hierarchy/`。

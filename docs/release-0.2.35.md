# 山兔 0.2.35-test：修复后半段陡坡漏标

0.2.34的陡坡显示只保留最前12个标记，并把连续陡坡（包括上坡转下坡）合成全段最陡的一处。后半段即使有有效坡度数据，也可能没有标记。本版取消这两项限制。

- 每个独立陡坡保留标记，不按路线先后截断。上坡/下坡分别显示「陡上 / 陡下」。
- 长连续陡坡约每200米补一个代表标记，后面的坡度未超过开头峰值也会显示。极长单段超过显示预算时均匀分布到整段，保留后半段覆盖。
- 所有提示圆点进入地图；远景文字自动避让，放大可看分散标签。
- 阈值沿用绝对坡度≥20%，约等于11.3°，不是20°。颜色、点数据和标记共用派生坡度；缺测、断段和过短的无有效坡度部分不会猜测提示。提示不是道路通行或安全判定。

## 模块与布局兼容

新增`modules/routeDisplay/warningMarkers.ts`纯标记派生和`config.ts`密度参数；`useRouteDisplay`删除前12截断与旧峰值合并，`RouteWarnings`调整文字避让，`RouteDisplayControl`明确坡度/角度单位。新增6项回归；版本配置与AndroidManifest提升至0.2.35-test/code42。原坡度计算、地图手势、布局编辑、轨迹存档、离线导航/缓存、GPS和照片模块未改。

沿用`com.guanyun.weather.shantu.preview`、4a94签名、固定页面源和`shantu.ui-layout.v1`/JSON version1。直接覆盖同签名旧山兔独立测试版，继续读取已保存布局和应用数据；不需要卸载或重新调整布局。不同包名应用的数据不自动迁移。

## 实施清单

勾选代表代码实现及下述本地验证完成，不代表真实手机所有硬件和系统权限已验收。

- [x] 主地图：固定紧凑层级；底栏行程/路线/画线/收藏/工具；右侧视角、3D、更多；缩放在路线显示上方；定位独立常驻。去掉布局入口，保留布局存储与备份兼容。
- [x] 更多：框选对象、区域总览、定位设置。区域总览适配当前路线完整几何，不打开世界地图、不被自动跟随立即拉回。
- [x] 记录：独立窗口未开始/记录/暂停/待保存；完整暂停继续结束取消操作；收起不停止；频率命名明确；保存失败保留记录。
- [x] 导航收尾：直接结束行程或结束并保存；等待原生最终状态；保存校验后清理；仅导航时不虚构行程；原有自动记录偏好保持。
- [x] 路线显示：显示方式代替着色；路线无速度；海拔统计与剖面合成紧凑海拔图，曲线按对应海拔色显示；保留海拔来源、坡度/陡坡、线宽/透明度；收起设置保留启用图层。
- [x] 行程：完整轨迹图、点数据、时间速度海拔与照片；转换独立路线成功后可选隐藏原行程；原始数据保留。
- [x] 收藏：隐藏系统文件夹汇集既有隐藏对象；打开不自动取消隐藏；支持恢复/批量恢复；不移动原文件夹归属。
- [x] 照片：先行程时间、后坐标；原生索引查询候选；文件源先元数据后解码；仅显示当前行程；增量去重；缺信息待确认；选地图点手动添加或标记，手动坐标不被重扫覆盖。
- [x] 标记：临时新建预览、取消不留空记录；普通点拖动保留；照片/属性复用；隐藏归系统文件夹。
- [x] 模型：保留精确 ObjectGizmo 与数值调节；钻井归添加模型，圆圈加向下箭头，仅口径/深度等参数，不自由拖动旋转；旧数据兼容。
- [x] 路线编辑：删点不接线；按实际路径删路段，保留边界节点和其他分支；分支歧义必须选择路径；节点框选；吸附仅对齐不偷偷合并档案；保存失败/返回保护草稿。
- [x] 画线起步：名称可选，颜色/线宽/透明度/首段独立备注，开始前可设置。
- [x] 画线主界面：一行绿/橙/蓝/更多/撤销/保存，约292×44；小色板与按需设置；不遮住定位、视角与地图操作。
- [x] 画线路段：换色从末点开始下一段；分段不断线，允许同色独立段；后期改段颜色与备注独立；保留旧色与旧备注、导入导出/QR/编辑兼容。
- [x] 画线保存：唯一保存动作；原路线续画；草稿持久化与恢复；退出保留/放弃/继续；不暗中保存旧草稿；调整节点复用编辑会话。
- [x] 手势与返回：控件操作不穿透地图；保留双指手势；返回一次只处理最上层；窗口关闭后恢复有效上下文。
- [x] 验证：类型/架构/逻辑/构建；390×844、360×780、266×575关键状态截图及尺寸；记录失败/恢复/旧数据回归。

## 数据保护与保留

不改已有包名、签名、存储键和备份版本；原行程、照片、布局草稿保留。没有明确要求的页面、天气/地图资源/测量维持现有功能。测试用构造数据及隔离浏览器，不操作用户正在使用的窗口或真实相册。Android 包核验与浏览器测试不等于真机验收；HarmonyOS 原生包依然需要独立工具链及签名。

## 验证结果与边界

- 525/525逻辑回归、TypeScript、原有架构预算检查、网页与Android构建通过。无提高文件预算，app仍是组合层；新增流程位于所属模块。
- 实际App在390×844、360×780、266×575验收关键状态。画线工具390/360为292×44，266宽时212×92换行；更多色板164×80；地图目标44px。窗口内容内部滚动，无横向页面溢出。见 [设计验收](design-qa.md)。
- 旧照片DB v2到v3升级、原图不丢、索引无Blob、单张预览/原图分开读取在浏览器真实IndexedDB验证。构造JPEG实际读取EXIF时间、时区、GPS和海拔成功。手动修正不会被重复导入覆盖。
- 恢复后的待保存记录可以保存，清理后显示开始记录，行程列表和详情可查看真实时间/速度/海拔；退出绘制保留草稿，重新加载可继续。绘制保存一份档案后再续画，不增加隐式保存副本。
- 地图面板层级修复实际点选复测通过：路线显示的图上信息可点，不误触底下编辑；Escape先收色板/设置，再处理绘制退出；关闭设置保留海拔图。最新页面错误日志为空。
- 未验证真实手机安装、双指/手指触控感受、GPS/后台记录、系统相册授权、拍照/文件分享。预览的部分地图服务502不可用；浏览器截图不能证明联网路网、地形或真实路线正确。
- 未交付HarmonyOS6.1原生HAP/APP。Android安装包不是原生鸿蒙安装包。

## 模块、接口与回滚

详见 [架构](architecture.md) 及 tracks、photos、controls、outdoor、collections、workbench 的README。既有MapLibre渲染/双指桥、ObjectGizmo、轨迹分析与归档转换器保留。新增UI通过类型化props、回调与共享数据模块通信，不引入跨功能全局变量。

回滚以本功能分支的功能提交为单位；请先导出本机数据。旧版不理解新的独立路段备注、隐藏投影与照片索引界面，降级只保证旧原始存档未被本轮删除，不能保证旧版显示新字段。照片DB升级保留原photos表，不要求清空用户数据；旧布局键和JSON版本不变，固定布局不自动套用用户旧的自定义坐标。

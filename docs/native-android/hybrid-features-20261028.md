# 功能保留清单

本清单是迁移前后的比较合同，不是已实现/已验收声明。

| 保留功能 | React原实现继续承担 | 原生地图适配责任 |
|---|---|---|
| 首页/菜单/主题/布局/锁定 | 原组件、CSS、可达性和显隐规则 | 透明宿主、安全区只处理一次、触摸按完整手势流分发 |
| 主图/双图/图源/图层/3D | 原设置、选择、组合及持久化 | 独立mapId、真实原生视图、完整图源与DEM、相机同步 |
| 搜索/定位/导航/记录 | 原业务状态机、菜单与显示 | 真GPS事件、原生相机/箭头、后台服务和地图引导图层 |
| 路线/轨迹/画线/吸附/节点编辑 | 原草稿、撤销、支线、属性、算法与表单 | 屏幕/地理投影、拾取、真实绘制事件、吸附数据与提交渲染确认 |
| 标记/模型/地形相交/开挖/gizmo | 原编辑器与数据合同 | 原生图形、地形遮挡、真实空间拾取与投影；移动预览/保存/取消 |
| 收藏/地区/框选/批量变换 | 原目录、选择、批处理、撤销和存档 | 实际地图拾取/框选和变换预览，不能按包围盒冒充可见选择 |
| 照片/测量/剖面/勘探/CAD | 原导入、业务、表单、图表和导出 | 原生参考图层、真实DEM和相交/投影数据 |
| 行业图件/专业工具 | 原XLSX解析、模板、图件生成/浏览与导出 | 仅涉及地图的定位、叠加、拾取适配；普通图表可继续DOM/Canvas |
| 离线地图/路网/后台下载 | 原管理流程、估算/暂停/恢复/仅缓存显示 | 原生持久缓存/路网/文件图源读取，与原Web缓存的显式迁移 |
| 完整工程/旧备份/权限/分享 | 原数据格式与平台桥接 | 保留原Android服务；跨应用URI授权不虚构继承 |

`TerrainMapProps`全部字段和`MapHandle`全部方法是适配清单，不允许只实现zoom/markers便声称保留完整功能。缺项必须阻止正式替换；内部验证阶段可以明确报告blocked，不能回空成功并让UI误以为完成。

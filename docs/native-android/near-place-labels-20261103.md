## 原因与改动

当前地名样式共用字号规则。固定WorldWind 2.1.1虽然已有逐标签有效缩放级别和碰撞筛选，但重要城市不受小地名的四级zoom偏置影响；远处仍可能保留大量城市名。不能只按整张地图zoom关闭全部地名，也不能依靠改小字号让近景变得更难读。

`NativePlaceLabelLayer`仅替换OpenFreeMap矢量地名层的标签构造入口，继续使用同一份矢量数据、中文优先顺序、字体、颜色、描边、SDK Label/LabelGroup、原有碰撞、去重和预算。每个窗口有自己的候选状态。SDK内部数组不反射读取，全局SDK参数不修改。

在SDK碰撞分配前，按每个标签的位置计算真实相机距离、局部有效zoom及相机到look-at点的距离比。距离比不超过1.5的近景不增加筛选；更远处逐渐增加最多三级zoom门槛，小地名比城市更早退出：

| 原SDK名称层级 | 最大距离比（相机到标签 / 相机到look-at） |
|---|---|
| minzoom ≤ 4，国家/大城市等 | 12 |
| minzoom ≤ 8，城市等 | 6 |
| minzoom ≤ 10，乡镇等 | 4 |
| 其它小地名 | 2.5 |

以上为本项目候选参数，不是行业统一数值。保留原SDK的小地名zoom偏置；退出允许8%距离与0.25级zoom的回滞。缺少有效look-at或距离数据时交回SDK原策略，不整层隐藏。候选只暂时清空被筛掉标签的文字，下一帧可恢复；空文字由SDK在碰撞接受前跳过，避免占用近景碰撞空间。

道路和路线几何、道路名层、标记/定位/用户说明、私人天地图、图源选择、用户存档、签名、React业务和系统服务均未改。天地图CIA/CVA/CTA及自定义栅格图像中已经烘焙的地名不受此矢量策略控制；若原图是这类注记，本候选不能证明已处理该图的问题。

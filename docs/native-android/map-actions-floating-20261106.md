# 173 标记、定位、等高线和悬浮地图修复

用户 2026-11-06 手机反馈：标记偶发无地面；等高线字大、随视角歪斜和瓦片接缝；影像 LOD 硬边；暂停绘线后位置跟随被挡。悬浮入口放工具，无导航也可定位，支持地图缩放及窗口改大小。新增视觉要求为放大青蓝位置符号、荧绿路线柔光。

## 范围和实施

- 仅隔离旧引擎工作树。WorldWind 2.1.1，不称 Filament；正式 166、172及以前 APK、原签名和私人配置保留。
- 标记在原生地图优先调用已有 `unproject` RPC，由实际渲染器射线拾取；不以相机中心或 GPS 猜选点。无真实地面继续明确提示，异步单飞防重复。
- `follow.blocked` 使用当前实际 `tracks.drawing`，暂停草稿 `tracks.editing` 不拦位置跟随；保留草稿、编辑任务和真实 GPS 可信规则。
- 全局拥有悬浮 hook。工具子页提供定位/导航和指北/运动朝上；导航结束只停止路线悬浮，普通定位悬浮独立保留。桥接 v1 新增 kind，缺省仍兼容原 route。
- 原生悬浮窗以同一投影缩放真实 MVT 和路线，窗内 ± 缩放14至18（原数据最高14，以上超放大），右下角拖拽改变窗口；仅保存布局/级别，不保存 GPS。位置青蓝，路线分层低 alpha 光晕，无模糊滤镜、无额外 GL 上下文。
- 等高线拟复用 SDK 已有屏幕曲线文字，核实地理采样边界；不使用近似取整焊点改变真实几何。
- LOD 羽化沿用未发布171实验，先定位 GPU 批处理问题再实际 A/B。172没有羽化，不能把源码/单元检查当可交付视觉结果。

## 必需门禁

390×857 和360×780实际 APK：工具入口/返回，普通定位无路线启动/缩放/改大小/跨 App/关闭，路线悬浮与主导航生命周期；标记地面与真实无地面，暂停绘线后跟随可操作且草稿保留。等高线需多倾角/方位及相邻瓦片实图，羽化需同相机 A/B 且中心清晰无拉伸/黑缝。所有操作完成后清理仅 QA 对象并恢复相机和偏好。

类型、定向 Node/Kotlin、fresh 私人 React、optimized APK、原证书、独立包名/provider、私人天地图种子一致、ZIP CRC/16KiB/SO一致是包门禁。真实手机 GPS/后台/长期稳定性和鸿蒙原生未验证，不扩张电脑端结论。

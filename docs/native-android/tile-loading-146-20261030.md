# 146 地图加载：原因、实施与验证

## 目标与边界

用户授权一次完成加载链优化并交付私人 Android 测试包；2026-10-30 最新指令要求将源码、测试及交接文档同步 GitHub。保留 React 界面与业务、WorldWind 原生地图、原应用身份、私人天地图及历史存档。不开模拟器、不操作 Unreal、不对真实图源做压力测试、不公开私人包或凭据。

## 为什么会慢，如何处理

| 源码证据与影响 | 本轮处理 | 验证边界 |
|---|---|---|
| 原天地图加载器最多 4 个在途请求，启动间隔 250ms；空位也可能等待，普通底图、注记与其它影像链准入不统一。 | 图片网络共用 20 个在途名额，完成即补位；同步调整 WorldWind 图片检索准入。保留 429/Retry-After 冷却。 | 20 是本应用实验配置，不是已核实的天地图账号配额，更不等于每秒 20 张。实际速度由网络、服务器、解码与绘制共同决定。 |
| 拖动后旧请求可能挡住新视野；经纬度中心在倾斜地图中不等于屏幕光标。 | 按引擎投影后的瓦片轮廓到实际光标的屏幕距离重排；同边界瓦片等优先，主/双图共享需求；当前仍需要的同身份旧请求可提升。旧视野仅空闲补取，后台最多 2 个。 | 投影近地平线采用有界网格估计；尚无手机录屏/时间测量。 |
| 同一瓦片的不同 URL/自动层与固定层可能重复下载；重投影的一张输出图也可能需要多张原始瓦片。 | 按源、图层、实际原始 z/x/y、样式与授权命名空间生成身份，合并在途请求并隔离缓存；动态需求提供器不进入纹理身份。 | 保留 URL 旧缓存与既有离线包读取契约，不把不同授权配置混用。 |
| 原固定级别拼图要等整块下载与合成，单张慢会拖住已经下载好的图。 | 每张瓦片独立解码、投影与显示；保留同源清晰过渡块，以既有内存预算做有界淘汰。 | 固定级别画面衔接、GPU/内存与手机体验待真机验证。 |
| 无上限重试会重复占用带宽；只有协程超时却未关闭连接，会造成名义并发与真实连接数不一致。 | 每瓦片/需求代最多 5 次总尝试，每次实际网络限 15 秒，队列等待不计入；瞬态失败重新排队，授权/不可重试错误终止，服务限流先冷却；取消时断开连接，I/O 线程退出才释放名额。 | 可控假传输检查调度/取消；没有真实服务压测，不承诺首屏秒数。 |
| 手机回拖或重开需要持久复用；落盘若挡住显示，会增加已收图后的等待。 | 沿用 145 的 filesDir/shantu-map-browse-cache、8GiB 上限与 SQLite 索引，改为有界异步原子写入；先内存/磁盘命中，过期先显示再合并刷新。 | 8GiB 是上限、按浏览增长；写队列满或空间不足会放弃该次持久写，不使已下载图显示失败。 |

最高源级沿用放大来自 145，本包继续保留：不请求虚构的更高级别，也不因超放大主动显示“该层级没有图源”。放大不会产生源图没有的细节。

## 已查的上游与官方依据

- Android [应用专属存储](https://developer.android.com/training/data-storage/app-specific)：持久文件与系统可回收的 cacheDir 不同。浏览目录放在 filesDir；卸载/清除应用数据仍会删除。
- [WorldWindKotlin 上游](https://github.com/WorldWindEarth/WorldWindKotlin)：以本机精确 2.1.1 源码及 artifact 的 RenderResourceCache / RetrievalLanes 为准，确认 remoteRetrievalQueueSize 控制远程工厂准入，不能只修改外层 HTTP 数字。
- 天地图 [地图服务](https://lbs.tianditu.gov.cn/server/MapService.html)与[授权说明](https://lbs.tianditu.gov.cn/authorization/authorization.html)：未取得当前账号的明确 QPS/批次上限，不把应用的 20 写成官方允许的最大值。145 已用真实能力文档核对最高源级；本轮没有真实瓦片压力测试。

## 文件与诊断

- 网络、身份、优先队列与异步落盘：BoundedTileNetwork.kt、TileRequestQueuePolicy.kt、NativePersistentBrowseCache.kt。
- 实际路径与需求：NativeMapController.kt、NativeCartographyLayers.kt、NativeImageryBasemap.kt、NativeTerrariumCoverage.kt、NativeReactMapHost.kt、TileProjectedPriority.kt、NativeTileLayerVisibility.kt、NativeImageSourceIdentity.kt。
- 增量固定层与预算：NativeRasterDetailLayer.kt、NativeRasterDetailTileState.kt。
- 解码/帧诊断：NativeTileStageTelemetry.kt；有界聚合，不含 URL/Key。网络快照区分缓存、排队、实际网络、错误与重试；解码计时与完成帧分别统计。没有可证明某张瓦片已画出的 SDK 公共回调，perTileDrawCount 明确为 null，不将下载成功冒充绘制成功。
- 对应测试与 hybrid 测试白名单随源码保存。无 CSS/业务菜单改版，不将本轮逻辑测试写成视觉通过。

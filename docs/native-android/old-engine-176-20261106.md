# 176 隔离修改与验证记录

## 目标与功能范围

继续W697的old-engine隔离工程与WorldWind 2.1.1，保留React业务、私人内置天地图、存储格式和正式166。175私人包与源码检查点 `8e6ed0e7b9de479c965acec1fa702eaf61cbdb1b` 保留。目标 `com.shantu.oldengine` / 0.2.176-test / code183，未构建时不能称已交付。

合入用户反馈：低海拔填色更细、填色与等高线共同显示；点标记后的第一个卡片直接“复制导航”，保留复制后打开高德地点；路线缓存有真实准备/下载/失败/续传状态，收藏可查看；悬浮窗与锁屏独立记忆，新增真实罗盘、节能、锁屏常亮；导航展开一次看全。另修锁屏内部缺块/硬边和小窗自行退出，不把外圈羽化当内部缺图修复。

## 施工办法

- 填色改固定25米色带，与等高线间隔分开。等高线叠加填色采用黑白对比色；修改SDK真实批量绘图的颜色拷贝路径，避免仅改已不参与绘制的ShapeAttributes。AAR需可复现、保留上游ABI，核对最终APK包含新setter。
- 点击缓存即持久保存同ID准备任务；完整URL清单生成后替换原任务，几何保存在IndexedDB而非反复写入localStorage；不用假进度。原包兼容，失败/暂停保留内容。
- 高德用限定包名的官方viewMap地点URI，WGS84 `dev=1`，不强制出行方式。不复制照片附件，不伪造高德已开始导航。
- 罗盘只用可信、新鲜的真实传感器；运动模式仍用真实移动方向。屏幕关闭时节能定位降频，亮屏请求新定位，不改RecordingService采样。常亮仅在锁屏Activity真正可见时设窗口标记，不主动点亮屏幕、不含AOD。
- 浮窗Canvas总顶点预算仍8000，按可见瓦片分配并轮转完整路径，保留独立地名预算；不无限提高预算。瓦片解码先扫描字节跨度，选择完整要素后再分配坐标/属性；限制4MiB、1200要素、24k顶点、4800路径及有限候选/属性，为地名预留。主图/地质原decode入口不改。
- 窗口更新失败恢复上一有效会话，不停止既有服务。记录非敏感退出状态；API30+只检查本应用主进程ApplicationExitInfo，不把WebView子进程、USER_REQUESTED代码或OEM行为擅自解释为用户操作/根因。不用无限重启或唤醒抵抗系统。

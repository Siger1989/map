# 0.2.142 / OPPO Find X8 性能故障

用户反馈：进入即不流畅、地图加载慢，随后内存过大退出。目标为最新私人142；用户手机实际安装包的哈希、退出原因与内存曲线尚未取得。本机固定APK仍为原最终142，SHA256 `7833d6fa8c60c52b9b1ee8b76d07e4b24e2ba959c6597249c7e4cd242b2317c4`，本轮未替换。

## 已修源码中的开销

- `NativeTerrariumCoverage.sampleMercatorTile`：每个采样像素原先创建四个Pair、集合和过滤结果，改为标量加权。保留权重阈值、缺失高程与零权重邻居处理。这减少临时分配，不代表已经证实泄漏根因。
- `NativeRasterDetailLayer` / `NativeRenderMemoryBudget`：固定级别拼图原只按8192像素边长控制，2048源瓦片可能组成8192×8192（ARGB约256MiB），纬度转换还同时持有同尺寸IntArray，另有GPU上传和前一张图。现每份按heap/32、最大2048×2048预算计算源瓦片边数（至少一张源瓦片），不改变所选级别与同源外围概览。只影响固定级别功能，不能把它认定为用户启动故障根因。
- `NativeReactMapHost.publishSnapGeometry`：道路/河流吸附均关闭时，仍发布原隐藏状态，但跳过原先每500ms四角地形拾取；开启时保留原逻辑。

没有修改React界面、图源/Key、存储格式、签名、地图画质选项或用户存档。没有增加网络并发或突破天地图限流。

# 项目门禁：功能不删不改

- **来源与数据**：旧React UI、业务模块和存储schema为基准；逐项比较功能入口、输出、失败/取消、撤销和持久化。不得清用户数据、回伪造GPS、补零高程或隐去不支持项。
- **地图真实性**：运行时无隐藏MapLibre/WebGL地图；WorldWind真实帧、真实DEM/遮挡/拾取/截图与主双图分别有证据。网络收到瓦片不等于渲染完成。
- **协议**：严格origin/session/mapId/requestId/revision、有限payload、超时/取消/过期回复、主线程生命周期、资源释放和跨图隔离测试。
- **操作**：UI区域/透明区、双指、长按/自由绘制、画线中断、菜单滚动、键盘、返回、锁定/解锁、方向与GPS跟随、模型拖柄、双图跨边界完整手势流验证。
- **原版完整性**：`MapHandle`全部方法、`TerrainMapProps`全部地图能力及功能清单全覆盖；blocked能力只能用于内部验证，正式切换必需项不得未实现或未验证。
- **视觉**：沿用 `docs/ui-standard.md` 与 `docs/ui-quality-gate.md`；390×857、360×780与390×480适用状态的computed尺寸、实际截图、点击/返回和真实滚动可达性。原React不等于可以免验宿主叠层/安全区。
- **性能**：同区域/图源/画质/视角比较首屏、高清补齐、拖动响应、请求/内存/取消；不能把更换UI或构建通过当性能通过。
- **交付**：私人天地图配置、签名/资源/CRC/16KiB按包核对，预览与APK源码/config一致；原数据/141包保留。公开origin不得上传含凭据包。设备GPS/后台/相机/分享与HarmonyOS支持分开记录。

每项记录 PASS/FAIL/未验证、证据路径和重测条件。未满足全功能门禁，不宣称“功能完全不变且已验收”。

# 山兔 0.2.19 测试版：拍照、测量与路线点编辑

- 标记一级菜单新增“拍照”：Android通过系统相机拍摄，清晰副本和预览保存到本机照片库并关联该标记；标记详情可打开照片，收藏ZIP包含选中标记的照片与元数据。位置是拍照时的标记坐标；缺少EXIF时间时注明相机启动时刻。
- 工具新增“测量”：依次点地图形成折线，显示水平长度、空间长度、起终点坐标和真北顺时针方位角。选择单点可用X/Y/Z箭头及数值调整，经纬度和高度均保存；支持撤销、删点、新测量、关闭重开。未知海拔保留明确提示，空间长度不冒充沿地表行走距离。
- 编辑标记时点击地图空白保留编辑对象和草稿，不再跳回“标记与模型”列表。
- 路线减号删除选中点及其相连线段，不跨缺口补线；单独剩下的点保留，可继续删到空。框选实际路线点，可连续加选、批量删除和撤销。保存空的手绘编辑可删除该路线，实走原始资料保持原样。
- 取消保存草稿时自动拼接笔画，以及分叉落到另一条路线时自动导入/隐藏整条目标路线；节点坐标吸附和用户主动连接入口仍保留。
- 地图缩小时地点标记的可见图标一起缩小，触摸目标保持至少44px，缩放不改变实际地理位置。上一版收藏工作台、网页组件兼容及即时单指手势继续保留。

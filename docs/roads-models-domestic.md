# 道路吸附、地图标记与地下模型

## 手绘吸附地图道路

在“路线 → 手绘轨迹”打开“道路吸附”。放大到道路/山间小路可见的范围，确认“道路与河流”开启并已加载，再按原操作先定起点、拖绿色牵引环画线。

笔尖靠近道路中段也能吸附；沿同一条道路移动时保留中间弯折。拖离道路恢复自由绘制，双指控图继续可用。原有“节点吸附”独立保留，用于已保存轨迹/草稿节点连接。关闭道路吸附后不进行道路查询。

吸附范围为屏幕 14px，已吸附同一路段允许 22px 的脱离缓冲；低于地图 12 级提示放大。仅匹配已加载的 OSM/OpenFreeMap 公路、道路、服务路、路径等线几何，不匹配河流、铁路、自己的墨迹。不能依据底图图片中的线条猜测道路；地图没有记录的小路不能自动吸附。它不是道路导航引擎，不保证道路开放或可通行，也不替用户自动选择复杂路口的路线。

## 标记与几何模型

底部新增“标记”。选择“地点标记 / 长方体 / 圆柱 / 球体”，再点地图放置。模型放置后会放大视角；点击地图标签或列表可重新编辑。

- 名称、颜色、备注可编辑；地图重选位置或输入经纬度可移动。
- 长方体设置宽、长、高；圆柱设置直径、高；球体设置直径。全部以米为单位，不按屏幕尺寸伪放大。
- 朝向以正北为 0°，向东为 90°；另有俯仰、侧倾。朝向针对模型本地长轴，圆柱初始轴线竖直。
- “地表外”：参数为模型最低点相对锚点地面的离地距离。
- “地表内”：参数为模型最高点相对锚点地面的埋深，旋转后仍按新的最高点计算。地下模型以半透明填充和轮廓穿透地表显示，最大填充不透明度限制为 0.45。
- 详情显示尺寸、体积、模型底/顶海拔；“复制用于对比”和“模型参数对比”便于放置多个方案。
- 地面海拔读取自现有 DEM，也可手动填写。读取失败时保留标记和参数，暂不按零海拔绘制实体。起伏增强仅改变视觉地面基准，模型尺寸不跟随放大；精确比例对比建议使用 1× 地形。
- 地形只以锚点采样作为水平基准，模型不会挖开地表或自动贴合整个斜坡。地形精度、坐标精度和手动参数决定参考意义；模型不是实测洞穴或实际开挖结果。

标记最多 80 个，保存在本机浏览器/应用数据中，代码同步不包含这些个人存档。浏览器可导出 JSON 参数文件；Android WebView 提供可选择复制的参数文本。清除应用数据会丢失本机存档。JSON 标明米制和 WGS84 坐标。

## 国内免费图源调查与接入边界

核对日期：2026-09-05。当前不是“所有联网功能必须 VPN”的确定诊断：程序分开请求底图、标注、高程、天气、地质和导航，各个网络的可达性可能不同，本轮没有控制用户的 VPN 开关做完整实网验收。

| 候选 | 查证依据 | 本轮决定 |
| --- | --- | --- |
| 天地图 | [自然资源部新平台建设通知](https://app.www.gov.cn/govdata/gov/202403/13/512938/article.html)说明其公益性；[官方接入手册](https://tianjin.tianditu.gov.cn/static/help/note.html)要求在控制台获取 Key 并确认配额；[官方 WMTS 接口](https://lbs.tianditu.gov.cn/server/MapService.html)、[平台文档中的图源参数](https://heilongjiang.tianditu.gov.cn/iportal/iClient/forJavaScript/docs/openlayers/ol.source.Tianditu.html)列出影像、矢量底图、标注及 3857 网格。 | 已准备官方 WMTS 墨卡托接口适配，不复用他人 Key。作为国内公益服务候选，具体免费额度以自己的控制台为准，不承诺无限调用。 |
| GeoQ | [官网套餐](https://web.geoq.cn/price.html)列基础地图服务免费，但该套餐说明不能单独证明旧切片地址的第三方应用使用范围。 | map.geoq.cn 本机有界连接测试超时；没有把未验证的旧接口换成默认图源。 |
| 高德 | [官方坐标说明](https://developer.amap.com/api/javascript-api-v2/guide/abc/basetype)使用 GCJ-02，[Web 服务说明](https://lbs.amap.com/api/webservice/guide/api/convert)要求应用 Key。 | 不是简单替换 URL：直接叠加现有 WGS84 地形/轨迹会偏移。本轮未混用未转换的坐标。 |

本应用尚无有效天地图 Key，真实国内瓦片、配额和无 VPN 使用仍未验收。没有为用户注册、付费或接受第三方协议，也没有将任何商业套餐作为免费服务接入。

### 配置国内底图

将 `config/domestic-maps.env.example` 的设置加入根目录 `.env.local`，填写自己申请的天地图浏览器应用 Key：

```dotenv
NEXT_PUBLIC_TIANDITU_KEY=
```

重启开发服务/重新构建。存在有效格式的 Key 时启用天地图影像 `img_w`、矢量底图 `vec_w` 与中文注记 `cia_w/cva_w`；没有 Key 时保留国际图源。Key 格式通过只表示可发起请求，不代表服务端授权已通过。该浏览器应用 Key 会存在构建后的网页/APK 请求中，须在控制台为本应用设置适当限制；不能填写服务端私钥或把真实值提交到 Git。

国内模式不自动访问 EOX/NASA 卫星底图或 OpenFreeMap 地名服务，数字等高线字体使用本地字形。最新云况功能显示不可用而不以历史影像冒充实时观测。开启道路吸附时仍按需请求 OpenFreeMap 道路矢量；天气、路线规划、地质和本地高程覆盖外的 DEM 仍沿用原服务，不能说整个应用已完成国内化。

## 模块与验证

- `modules/tracks/roadSnapping.ts`：筛选道路、投影匹配、弯道跟随；`modules/map/roadSnap.ts` 通过地图公共查询接口提供几何。
- `DrawingSession` / `TrackDrawing` / `TrackPanel` / `useManualTracks`：绘制接线和独立开关。
- `modules/annotations/data.ts`：参数校验、尺寸/体积、旋转后的高度边界；`useAnnotations.ts`：本机存档及海拔读取；`AnnotationLayer.ts`：米制 Three.js 模型与地图标签；`AnnotationPanel.tsx`：编辑与对比。
- `modules/cartography/basemaps.ts` / `modules/terrain/terrain.ts` / `LayerPanel`：可配置国内影像和注记；`public/fonts/`：本地数字字形及授权。
- `app/page.tsx` / `TerrainMap` / `ControlDock` 和网页/安卓样式入口：模块组合；Android 返回键支持退出放置状态。
- 无删除业务模块；没有更换天气模型、地形原始数据、已有路线服务、存档格式或重新发布 Sites。旧用户轨迹保持原格式，新模型另用独立存档键。

专项检查覆盖道路中段/弯道/反向/发卡弯/脱离/缺数据，以及几何体体积、旋转埋深、缺失海拔、存档校验和国内样式。最终验证结果见 CURRENT_STATE.md；浏览器/真机视觉、地下效果、触控与性能尚未实测。手机已安装旧 APK 不会自动获得这次源码修改，需后续构建新包。

# 路线规划统一排布方案（2026-09-09，待实施）

用户反馈：点选导航地址后拖图仍关闭窗口；希望规划结果能保存为可编辑轨迹；规划入口没有直接呈现已有导航的详细数据。用户进一步确认“主要是保存可编辑的轨迹”。本轮核实现状并提出排布，不将方案写成已实现，不生成新APK。

## 已核实的现状

1. 选点完成后，`useNavigation.place`结束picking；`app/page.tsx`的`keepOpenOnMapInteraction`随之变为false。`ControlDock`在document pointerdown捕获阶段关闭面板，所以只是拖图就会关闭。390×844实际复现：选择已有标记为起点，拖动地图后规划窗口从DOM消失，原地址仍在。
2. 规划成功及“看全程”调用的`onShow`也会`setPanel(null)`。真实步行规划得到1.6公里/21分钟，结果变为顶部小提示，只提供摘要和“开始导航”。
3. 选点路线与已保存路线最终均可进入`NavigationStart`；海拔图和6项统计已经存在。实际点击“开始导航”后看到了总里程、预计用时、累计爬升/下降、最高/最低海拔。因此主要是入口和层级问题，并非缺少这些数据计算能力。
4. `RoutePanel`的“收藏路线”只写入`useRouteFavorites`的道路收藏，不进入`useManualTracks`的可编辑轨迹库。`RouteViews`中的轨迹摘要、标记、编辑和详情仍是另一条流程。导出图片已存在于`RouteShare`，用户此次主要需要保存可编辑轨迹。

## 建议的信息层级

| 阶段 | 界面位置与内容 | 主要操作 |
| --- | --- | --- |
| 设置地点 | 顶部小面板：出行方式、起终点、途经点。内容较多时内部滚动 | 选点、增删/排序途经点、规划；地图平移缩放保持面板，显式关闭才退出 |
| 查看结果 | 沿用已有轨迹的底部摘要卡，预计160—190px；顶部输入面板收起为可返回的上一步 | 导航、保存轨迹、改地点、详情；地图继续可平移缩放 |
| 查看详情 | 复用已有较大的路线详情窗口；标题/返回固定，内容内部滚动 | 数据、路段、关联内容；返回仍落在同一路线摘要卡 |
| 保存以后 | 同一张摘要卡更新为“已保存”，进入现有轨迹/收藏体系 | 导航、添加标记、编辑、详情，与已有轨迹操作一致 |

底部结果卡从上到下：路线名及“未保存/已保存”状态；总里程、预计用时、爬升、下降四项主要统计；一行四个操作。所有按钮保留至少44px触控高度。显示卡片时采用已有路线工作台的底部占位机制，避免和底部功能导航重叠；沿途进度带保持细窄，避开摘要卡，右侧地图工具仍可达。

详情中集中起终点/途经点、路线缩略图、海拔曲线、最高/最低海拔、道路转向、沿途天气以及关联标记/照片。数据使用同一份当前路线，避免在结果、详情与导航准备中各计算一个不同版本。海拔显示“地形估算”、时间显示“预计”；尚未加载时明确显示加载或暂不可用。

导航准备只承担出发前需要确认的方式、方向和接入规则；路线详情可以从摘要卡直接进入，不必先点击开始导航才能看到。修改地点或模式后使旧规划结果失效，要求重新规划。

## 保存为可编辑轨迹

- 主按钮明确叫“保存轨迹”。首次默认名称为“起点 → 终点”，允许修改名称和颜色，保存完成即选中这条轨迹。
- 保留完整线形、起终点与途经点名称/坐标、出行方式及道路规划数据；来源标为“规划轨迹”。不创建虚假的实走时间或定位样本。
- 保存进入现有地图轨迹与收藏入口，可以重新选择、编辑点线、添加关联标记、再次导航、分享或导出文件。
- 对同一规划重复点击不得反复产生副本。保存失败保留当前结果，允许重试。
- 线形被编辑后，原道路转向和预计时间必须失效或明确重新规划；不能继续用旧转向指导修改后的线形。
- 旧道路收藏继续可读取；实现时为其提供转为可编辑轨迹的兼容入口，不破坏旧备份。

## 实施范围与顺序

1. 面板生命周期：调整`app/page.tsx`与`controls/ControlDock`，将“地图拖动保持打开”和“Escape取消选点”分成独立行为。规划输入、选点完成、查看结果都保持工作上下文，关闭只由显式操作触发。
2. 规划结果转轨迹：新增navigation到tracks的适配模块；扩展`tracks/drawing.ts`、来源标签、解析/备份校验和`useManualTracks`保存入口，保留旧存档兼容。
3. 摘要和详情复用：让`navigation/RoutePanel`负责输入，`tracks/RouteViews`承接通用结果/详情，`journey/RouteElevationSummary`提供同源统计，首页只组装回调。避免把更多跨模块业务塞进首页。
4. 通过明确props和回调连接模块；照片、GPS记录、地图图源、标记绘制/Logo、签名均不需要改变。回滚UI及适配模块时仍须保留已保存“规划轨迹”的读取能力，不回滚删除用户数据。

验收覆盖：选点前/中/后拖图、规划成功与看全程保持结果卡、关闭和Escape、规划失败/重试、连续修改地点、保存后重启重开、重复保存、改线后旧转向失效、旧备份往返；390×844、360×780及长途经点/键盘压缩视口。实施完成后再执行类型/相关回归/构建、新APK与GitHub测试Release。

# 手绘轨迹与收藏导航

在「画线」中，每条已保存轨迹旁有「导航」按钮；选中轨迹后也可点顶部「导航所选轨迹」。「收藏」中，每条路线和轨迹旁均可直接导航，不需要先打开再重新规划。

手绘轨迹使用已保存的坐标线形，默认步行，时间按4km/h估算；不会请求另一条道路规划来替换手绘线。不包含原始转向指令时，仅提供沿线指引、进度、剩余距离及现有偏航接回功能，不生成虚构的路口转向。收藏的规划路线保留原出行方式、途经点和导航步骤。

导航中可以切换到另一条收藏或轨迹；启动函数显式接收所选路线，避免同次点击使用旧规划状态。结束按钮停止本次导航，原收藏和手绘存档保持不变。

仅支持至少20米的连续路线。多个明确相接的线段可合并；包含断开的线段或孤立点时显示原因，需先连接再导航，不能把未保存的缺口当作可通行道路。保存时已画出的跨越线段会原样保留。

需开启系统定位并允许应用获取位置。等待定位、定位超时或精度不足会显示提示，不累计虚假行程。无手机实测时，浏览器入口和算法回归不能代替真实道路上的导航验收。

实现：`guidance/savedRoute`为只读适配器；`useNavigation.restore`恢复原规划；`useGuidance.start`接收明确目标；`app/page`统一启动；`TrackPanel`与`CollectionsPanel`提供入口。不改存储格式、GPS精度、后台记录或地图源。

验证：新增3项回归，覆盖原几何/深拷贝、连通与错误数据、收藏出行方式/途经点/步骤。Chrome中完成手绘导航、收藏导航、结束及1.0公里到1.8公里切换检查。360/390宽度检查无横向溢出。内置浏览器定位后曾出现输入不送达，Chrome对照正常；不据此宣称真机验证通过。

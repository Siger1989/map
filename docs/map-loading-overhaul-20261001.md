# 2026-10-01 图源加载与清晰度修正

用户提供针对0.2.89的外部审计，要求改进到接近奥维的加载体验。以当前0.2.95源码核对：Content-Length精确读取、输入邻片受控并发/在途共享和Worker循环优化已进入0.2.95；图片MIME误拒、Android每瓦片新建连接、在线多层串行合成仍存在。本轮修复后续问题，不恢复自动持久缓存、沿线下载或屏外预取。

## 实现

- Android MapTileProxy：兼容缺失/通用二进制MIME及明确图片别名，继续校验真实图片头、拒绝HTML/不匹配类型和截断正文；HTTP/1.1有界连接池，全局8/单服务4、空闲每服务2，总空闲16、30秒淘汰。完整DNS答案检查、公开IP绑定、原主机TLS验证、12秒总期限和8MiB上限保持。失败/取消不入池；失效空闲连接允许一次新连接重试。本轮未实现HTTP/2或引入OkHttp，不称完全复制奥维内部网络栈。
- 请求取消：前端为代理瓦片生成不含URL的随机ID；AbortSignal经GuanyunNative.cancelMapTile直接关闭对应原生socket/取消DNS等待，不经瓦片请求队列。兼容旧桥接，短期有界取消记录覆盖先取消后注册竞态。
- OVMAP在线显示：底图与每个注记分别建立raster source/layer，沿用主图ID/协议，底图不再等待注记。注记失败独立提示；切换/clear移除全部源和层。GCJ02/BD09校正及级别同步覆盖各层。MBTiles协议坐标capture回归已修复；普通XYZ/MBTiles仍保留datum校正。
- 原始单层图片字节直返；512父瓦片仅在明确subdivide语义下裁成256子瓦片。Worker按实际256/512像素调整采样计划，地址/地理范围保持，不把retina图强制缩成256。DEM仍256；旧多层合成函数保留供显式离线导出调用。
- 下载/校正分开：最多4个有界流水任务可以提前下载，重采样Worker保持最多2个；原始输入并发仍4、队列96。慢输入不再只靠两个下载与处理混合槽推进。20秒从流水槽取得后开始，等待队列不占期限；Worker等待包含在同一任务期限内。
- 动态OVMAP注记纳入地名层排序，路网/路线线段位于注记下，端点/用户标记/定位保持在上方。

## 最新执行思路：先定位，再优化，效果达标后打包

用户要求先想清楚。此阶段只记录方案，不继续性能代码修改、升版或出包。当前判断是“回看复用、请求/处理速度、画面连续替换”三个问题需分别测量，不能用缓存速度一项解释。

### 先建立对照

使用同一图源实际配置、范围、视角与目标级别，分别记录：未看过区域首次进入、同会话回看、重启后回看；俯视/高俯仰；快速缩远、再放大、拖向新区域。记录请求排队、DNS/连接、首字节、完整正文、坐标校正排队/处理、上传纹理；连接复用与内存命中分别统计。诊断仅记录阶段、随机请求标识及数值，不输出私有URL/Key。受控测试可使用独立会话，不清用户存档。

画面指标分为首次全屏有效地理覆盖、目标级别细节完成时间、空白/接缝/明显块状跳变持续时间和帧耗时。必须统计失败与未完成请求；不能只报告成功瓦片均值或tilesLoaded。浏览器原生代理路径不同，Android速度仍需同手机同网络比较；没有奥维实测值时不得称达到其速度。

### 按证据选择改动

1. 首次主要耗时在网络：保留现有共享连接，核对真实并发是否被前端四输入槽限制、慢请求是否阻塞当前视口；调度先满足当前可见覆盖，再补目标细节。取消旧视口时保留仍被当前画面依赖的父瓦片/共享请求。并发调整以整屏时间和错误率为准，不盲目扩大。
2. 主要耗时在校正/解码：优化热点与原始邻片复用，内存按字节预算而非只按张数；键包含图源配置版本、坐标体系、级别和像素尺寸，切换失效。保留正确地理位置与真实目标清晰度，不能跳过GCJ02/BD09校正。
3. 地形画面逐块跳变：先做同源低级别概览覆盖的独立原型，概览只服务当前视口，无屏外预取。细节到达后探索地理区域对齐的父子纹理过渡/局部成组替换，需兼容terrain；不能等全屏所有瓦片齐全才显示，单个失败不拖整屏。当前引擎普通raster渐变在terrain下不启用，因此需要真实原型证明，不承诺仅设置fade即可。地理覆盖和细节完成分别验收。
4. 仅重启回看明显慢：再评估轻量浏览缓存的必要性。现有自动磁盘缓存保持关闭；是否恢复持久缓存是独立范围决定，不自动恢复此前沿线下载/每请求查旧包流程。先确保内存命中不重复下载或重采样；持久写盘若今后授权，应退出首屏关键路径并限制大小/并发。
5. 球面远景：与加载策略分开。先验证球面投影与现有地形/custom layers/轨迹和测量兼容，再决定实现方式；球面效果不能证明下载加速。

### 出包门槛

先在右侧预览复测首次进入、快缩远/再放大、新区域拖动和同会话回看，保存同视角计时和过程画面。要求全屏有效覆盖优先、无持续明显块状跳变、最终细节不降低、地理不偏移，且失败可恢复。给出改前/改后的数值和仍有差距的场景。预览未达目标不出包；预览达标后的候选APK用于手机验收，手机同机奥维对照仍决定最终速度结论，不能把桌面通过当手机已达到。

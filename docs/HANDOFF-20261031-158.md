# 158 线宽、定位箭头与车辆离线规划交接

本轮按已确认的 A+B+C 范围施工：保持用户设置的路线粗细；修正当前定位方向箭头过小；增加真正的汽车、摩托车区域离线规划。名称框、浮窗导航与地图引擎更换不在本轮。手机闪烁沿用157试修状态，不能把158描述为真机闪烁已解决。

## 原因与处理

### 路线突然变粗

源码中导航近景将已行路线宽强制改成14、描边18，盖过用户设置；路线不会因地图缩放主动变宽。已删除这两处强制值，主图、双图共用的场景适配与原有路线层均使用用户线宽，描边为线宽+4；导航提示带恢复普通4/8。颜色、角色、可选中性和用户保存值保留。`app/page.tsx`补齐读取到的`navigationCues.cameraMode`依赖，切换视角能及时更新。

用户参考照片原文件本轮未成功取回；仅凭协调方描述不能确定粉红线是已保存轨迹、规划路线还是导航路线。因此已确认的是源码中的独立加粗缺陷，不能说已查明该照片全部原因。对象类型仍待用户补充。

### 当前定位箭头太小

旧箭头只占32像素纹理内很窄一条，且缩放固定为1.35物理倍率，没有乘手机CSS/物理像素比例。新版使用宽箭头轮廓，按24 CSS像素目标换算到原生；24是实现值，不是用户确认的验收阈值。无可信方向时保持定位圆点。方向仍来自原可信运动策略，不拿路线方向冒充真实航向；跟随策略未改。

### 汽车与摩托车离线规划

旧离线图只支持步行。新版增加相互独立的`motorcar`与`motorcycle`路网，摩托车明确是摩托车，不映射自行车。入口仍为路线面板；摩托车标为“摩托车（离线）”，需事先下载对应区域路网并使用自动/离线偏好。在线驾车、骑行、步行供应商保留。在线失败且离线也失败时，保留最初在线原因；取消不会变成离线重试。

图文件格式v2包含道路ID、有向边与经单个节点的转向限制。汽车、摩托车分别读取访问权限、单行和已知禁止/只准转向；A*状态包含进入道路。未知条件限制和不支持的复杂转向保守排除相关道路。只准转向的目标道路未纳入图包时仍限制其它出口，不能丢掉约束后放行。车辆暂限起点与终点，不接受途经点，以免分段时丢失转向状态。

旧v1步行包继续校验、导入和使用；不能冒充车辆包。IndexedDB名称和版本不变，既有包与用户数据不迁移清空。接入道路外最多120米的连接明确标为步行虚线，不是机动车通行道路。没有路网、不在覆盖区、不支持模式和无可达道路均报具体原因，不用起终点直线替代规划。

OSM道路规则不保证覆盖所有现实禁行、禁摩、时段或施工；估算时间不含实时交通。标准依据：[OSM访问权限](https://wiki.openstreetmap.org/wiki/Key:access)、[摩托车标签](https://wiki.openstreetmap.org/wiki/Key:motorcycle)、[转向限制](https://wiki.openstreetmap.org/wiki/Relation:restriction)。

## 影响速度的设计与可调位置

- 原生箭头只换纹理/显示倍率；路线只换样式计算，未改瓦片并发、缓存、图源、地形、GPU预算或等级判断。
- 离线路网下载一次受限Overpass区域请求，无自动重试、无新供应商/收费/凭据。单区100km²、单包24MiB、总8包、60000节点/150000有向边上限保留；不是全国离线包。调整位置见`modules/offlineRouting/download.ts`和`types.ts`。
- 车辆A*按“节点+进入道路”搜索，比只按节点多状态，才能正确处理转向；转向限制事先索引，避免每展开一条边重扫全部限制。图越大，下载、JSON解析、校验、索引与搜索内存越大，不能只调请求数。
- 图包放应用IndexedDB，来回规划直接读取本地；地图影像瓦片缓存是另一套数据，下载路网不等于下载卫星图。API与资料见`modules/offlineRouting/README.md`。

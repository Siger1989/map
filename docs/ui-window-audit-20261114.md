## 根因

1. `outdoorSurfaces.css` 的 `.glass:not(.guidance-card)` 在 `:is()` 中额外增加特异度，导致后面的外框card圆角规则无法覆盖，甚至非glass同组对象也受影响。将否定条件放进 `:where()` 保持匹配范围，降低无意特异度；实际地点分享圆角由10恢复23px。
2. 输入通用focus选择器堆叠多个`:not`，压过了整行透明输入例外。将类型排除包进`:where()`，保留排除含义，实测名称输入透明、父行加亮。
3. 独立弹窗/旧组件没有覆盖到共享样式，`.layout-mobile-toolbar`、`.selection-tools`、`.section-profile`、`.object-gizmo`等仍白底。按实际外框补材质；物体操控内部actions仅排版，不再重复磨砂。

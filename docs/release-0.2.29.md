# 山兔0.2.29-test：控件避让与坡度高程修正

修正0.2.28地图左右控件重叠和左下角灰色入口。路线卡片移到顶部后，里程条现跟随卡片实际高度向下避让；定位状态移到顶部，底部坐标限制宽度；编辑工具打开时定位入口上移，海拔信息避让方向盘和展开工具。狭小画面、详情和收藏打开时收起地图信息框，设置保留。

定位与海拔显示使用明确的绿色状态。地图编辑中仍可读取当前位置，但暂停镜头跟随保护编辑；海拔显示设置不再随地图编辑被禁用。

坡度分析原先只读取轨迹文件自带高程，缺高程的GPX会一直显示数据不足。现在与地图着色共用地形高程读取，显示地形估算标签，并在缺离线地形、网络失败时提示原因与重试。原始轨迹坐标、时间、高程与存档不变；DEM是有限分辨率采样，不是实地坡面测量。

0.2.28的区域离线步行导航、地图缓存、原路返航、返回点、批量导入和照片混排均保留。离线步行路网和离线地图需分别下载；队伍/SOS送达/PTT因没有通信服务暂缓。奥维文件按实际导出坐标系选择，未知不猜测。

# 户外实用版 0.2.0-test

## 使用
- 地图默认显示免 Key 的 OpenFreeMap / OSM 道路地名与三维地形。工具 → 图层可切换卫星、等高线、天气和地质；视角盘按需展开。剖面保持关闭。
- 行程 → 实走记录：安卓授权精确定位后开始，系统显示持续通知，支持暂停、继续、结束与存入轨迹。GPS 精度超过 80 m、过旧和明显跳点不写入。暂停或超过两分钟无有效点会分段，最多 6000 点 / 100 段。服务不随开机自动启动，进程中断后的存档恢复为暂停。浏览器仅前台记录。
- 行程 → 数据：导入 GPX / KML / 单文档 KMZ / 观云 JSON，检查数量后合并。重复相同存档不增加副本，同 ID 不同内容另存。GPX 保留轨迹点时间与海拔，KML 支持普通点线。JSON 保存标记模型、手绘/实走轨迹和路线收藏；不包含授权 Key、尚未存入轨迹的记录或离线瓦片。Android 使用系统文件选择器读写。导入不执行 XML 实体或 KML 网络链接。
- 行程 → 离线：有选中轨迹则下载该轨迹范围，否则取规划路线，均无时取地图选点周边；边界外扩约 2 km。下载开源矢量至 14 级、地形至 12 级和字体，超过 700 张单类瓦片则要求拆分。最多 8 包，每包 180 MB，并发 3。显示缺失项、暂停/续传、完整性检查及移除缓存。已有包共用的瓦片不会被单包删除。
- 离线包不含卫星、在线路线计算/搜索或实时天气。下载后通过“打开范围”使用开源底图；进入飞行模式核验。系统清理应用存储后需要重新下载。缓存读取失败时回退在线，未下载范围不冒充完整覆盖。
- 规划路线可比较当前出发、提前两小时与推迟两小时的沿途最大时雨量和风速。缺测和超出预报时段明确标示；断网使用标记时间戳的历史预报，最多缓存 8 组。

## 来源
- OpenFreeMap: https://openfreemap.org/ ，免注册/Key，开放服务、代码 MIT；地图源为 OSM / OpenMapTiles，保留署名。服务未承诺国内服务器或可用性 SLA。
- OSM 官方标准瓦片不用于批量离线下载：https://operations.osmfoundation.org/policies/tiles/ 。本应用离线矢量使用 OpenFreeMap。
- 天地图适配保留，通过构建环境 NEXT_PUBLIC_TIANDITU_KEY 配置本应用自己的 Key。未配置时不依赖它，不内置他人凭证。
- 地形沿用成都 FABDEM 与其他区域 Mapzen/SRTM，卫星沿用 EOX / NASA。FABDEM 与部分 EOX 数据含非商业许可，本测试版不宣称商业可售。

## 验证范围
逻辑测试检查 GPS 过滤、断点分段、存档冲突合并/配额回滚和离线请求边界；独立浏览器检查手机布局、标准文件往返和缓存断网渲染。APK 校验清单权限、前台服务、签名和静态资源一致性。未连接真机时，不能据此宣称锁屏定位、厂家省电策略和耗电实测通过。

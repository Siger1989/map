# 山兔 0.2.53-test：修复离线启动、画线长度与测量换位

- 修复0.2.52点击缓存后出现 `Error invoking offlineStart: Java exception` 的线程错误。原接口在JavaScript桥接线程读取WebView页面，现改为异步在UI线程检查页面、启动下载服务；不阻塞等待UI。启动失败保留下载任务，显示中文提示，“继续下载”可以重试；通知权限失败不影响已经启动的下载服务。
- 画线末尾显示累计米数/公里数。加点、撤销和拖动画线同步更新，沿路吸附计入弯曲路径；分叉显示该分叉累计长度，断开的段之间不虚构距离。标签避开放大镜，不拦截地图触摸。
- 测量选择上方A/B/C后，再点地图、已有标记或其他测量点，即替换所选点的位置；后续点击仍更新该点。点ID与相邻连线保持，海拔重新计算。修复换位撤销可能记录新坐标的问题。
- 下方测量剖面显示A到末点的整条测量折线。选中点仍更新相关段的角度/距离，其他段不消失。短图适应面板，长图左右滑动；各段水平参考与垂直投影保留，缺失海拔处不补画虚假连线。它仍是测点连线示意，并非沿线连续采样地形。

- 选中路线上的点或绑定该路线的标记后，下方海拔剖面同步显示绿色游标和里程、海拔、路段坡度角；实走有数据时显示速度。反向路线同步换算里程和坡度方向，缺测显示破折号。

修改范围：NativeBridge与outdoor启动/重试、DrawingSession/TrackDrawing及页面接线、measurement状态/剖面布局、routeAnalysis点统计与routeDisplay选点联动。新增projectionLayout及4个定向测试文件，更新现有默认出行方式的测试期望。没有迁移保存目录、删除缓存或改变原始路线/照片、图源配置、签名、包名及用户布局；测量分享导出分页格式保持原样。

验证：类型检查、58项定向测试、网页/Java/DEX/APK生产构建通过。原生启动测试执行生产方法，模拟UI线程访问限制、服务失败、失去前台、通知权限失败和无效任务；前端验证异常后的任务保留及继续下载。APK版本60、原签名v2/v3、zipalign、543项ZIP/473地形瓦片、24网页与9原生功能标识检查通过。

布局验证：390×857实际页面完整显示ABC，图框300×182；360×780独立真实组件12点剖面图框296×192，内部横向滚动630px可达末端，无面板横溢。末尾距离跟随加点/撤销/移动准星，标签与放大镜不重叠。路线选点在390×857与360×780真实组件检查通过，360窄屏图框264×171无裁切，移动游标/反向坡度/缺测/切换路线已验证。独立截图使用明确标注的示例数据，未修改用户真实测点位置。截图在本地artifacts/screenshots/hotfix-20260922。

# 山兔0.2.41 — PDF主页第二轮与手机适配

按PDF重新实现主页摘要卡、记录窗与控件布局，修复顶部天气框下凸、白框未垂直居中及图层/天气被背景遮挡的问题。仅主页这一层，视觉定稿仍待用户确认。

- 顶部四个白框实际38px高，在50px顶栏内上下各6px；天气与3D按钮间隔14px。
- 路线卡约273×100、记录窗234×98（390视口）；详细点数据保留在详情。已有数据缺失时显示“—”，不伪造天气、GPS或预计耗时。
- 320/360/390/430宽竖屏、844×390横屏、768×1024平板布局检查通过；横屏地图工具横排，主控件无重叠或横向溢出。
- 旧布局v1存储键/格式保留，已知主页选择器和锚点兼容迁移；启动不重置或自动覆盖用户草稿。原地图引擎、轨迹/照片存储、签名与包名不变。
- 类型/架构与508项测试通过。浏览器已检查记录收起/展开、视角/更多、图层/天气入口；未验证真实GPS记录、真机触控/后台。
- Android 8+独立测试APK，0.2.41-test/versionCode48；可覆盖同签名独立测试版。HarmonyOS6.1原生HAP/APP未交付，APK不代表原生鸿蒙支持。

截图、尺寸和差异见源码 `design-qa.md`。同版校验文件和完整性JSON随Release提供。

1. 先检查 `git status`、当前分支和远程；保留其他电脑改动。当前功能在 `codex/rollback-ui-0235-20260921`，不能从 main 判断是否已包含。仅在安全可快进时 pull，不强推、不重置用户工作。
2. 读 `AGENTS.md`、`CURRENT_STATE.md`、本文及 [UI 标准](ui-standard.md)。只处理用户当前问题，保留轨迹、照片、收藏和 `shantu.ui-layout.v1`；不恢复已被否决的旧 UI。
3. 本机预览 `http://127.0.0.1:9174/`，手机框 `http://localhost:9174/phone-preview.html`，默认约390×857 CSS 像素。API/DEM 后端端口3108；若地形变平，先确认后端和瓦片响应，不先归因于图源使用不同 DEM。保留现有服务，进程号需实时查询。
4. Git 不携带 `.openai/`、APK、原始购买文件、日志和忽略截图。证据在本机 `.openai/apk-0285-public-verified.json`、`.openai/github-0285-public-release.json`、`.openai/coordinate-audit/` 等；接续电脑没有这些文件时以已提交记录为证据边界。
5. 依赖按锁文件安装；Node >=22.13，Android SDK35/build-tools35、JDK17。工具链参考 [继续开发](continue-development.md)和 [Android说明](../mobile/README.md)。SDK/JDK 路径可配置，不写死开发机路径。

```powershell
git status --short
git branch --show-current
git remote -v
npx tsc --noEmit
node --experimental-strip-types --test tests/*.test.mjs
npm run build:android:web
# 真正交付新业务版本时才升版并构建；参数按本机工具链设置
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-android.ps1 -StandaloneTest -SdkRoot "<Android SDK>" -JdkRoot "<JDK 17>"
```

**公开构建与私有构建务必分开**：默认构建可能读取本机 `.env.local`，不能仅不传图源文件就假定没有凭据。本次公开构建未传 `-DefaultMapSources`，仅构建子进程将 `NEXT_PUBLIC_TIANDITU_KEY` 设为空白，经应用 trim 后为空；没有修改本机 env。私有构建显式传入本机忽略的图源文件，不能公开上传。脚本默认产物名会与私有 APK 同名，公开构建前需保留原私有产物，完成后分名并核对哈希。发布前检查最终包及所有附件，不能将旧包当作新源码构建。

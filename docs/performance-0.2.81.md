# 0.2.81 屏幕内吸附候选

用户明确吸附只针对屏幕内目标。旧分叉候选取所有未隐藏路线坐标，没有视野预筛；本版保留屏幕内中间点可吸附的语义，先地理索引筛选，再精确屏幕投影。普通绘制与分叉共用此路径，原14 CSS px吸附距离及等距目标顺序不变。

- 地理索引按候选数组身份缓存，结束输入不丢弃无关相机的索引；候选变化重建一次。宽视野预先判断格子数量，超过上限直接经纬度扫描，避免创建百万格子。
- 视野按中心/缩放/俯仰/旋转/尺寸/地形设置缓存，活动DEM数据变更失效。getBounds结合扩14px视口边缘采样与额外余量，反投影/投影往返校验异常、极区或高俯仰>=75°回退旧完整投影；不降低DPR，不改底图。
- 地形采样范围与20%余量不是任意崎岖地形的数学包络，手机场景仍需实测。MapLibre真实MercatorTransform测试覆盖0/40/60/74°、45°旋转、跨180°/多world副本，不能替代真实DEM/OPPO验证。
- 保存路线候选展平与当前编辑路线拆开memo；仍会为变更后的候选数组重新构建地理索引，没有宣称完全不扫描坐标。

验证PASS：719测试、tsc、APK构建/原签名/zipalign、543网页及496PNG与fresh stage一致。合成60000坐标集中1°地区，视野预筛后607次投影（原60000）；带合成投影成本的桌面中位25.62ms→7.26ms（包括6.13ms索引创建、1.13ms查询/投影），非手机或真实MapLibre时长。脚本/结果`.openai/viewport-snap-bench.*`。

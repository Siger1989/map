# 山兔0.2.31-test：手机边用边调

从地图右侧「更多 → 布局」打开。默认只有一行40px高的工具条，可抓左端拖动；「使用」恢复地图操作，「选择」拖动界面，「多选」一起移动/缩放。参数按需展开，没有常驻组件清单，多选不保留空层级栏。保存后重启继续使用，可导出JSON给后续统一布局优化。

修复桌面控制器只能选到内层图例、绘制工具不能选的问题：整个组件选择整块外框，内层用「外框/内容」和「选外层」切换。预览最高250%，细线和5px控制点不随预览放大，支持Shift/Ctrl多选、整批撤销、临时隐藏选框。

## 模块与兼容

新增独立`modules/uiLayout`，桌面与手机共享选择、几何、草稿模型和手势。应用入口/更多按钮最小接入，删除手机常驻列表、大参数区及重复共享实现；原桌面导入路径保留兼容出口。原始轨迹、海拔派生、离线导航/地图缓存、标记/测量/模型、GPS与存档键未改。详见[模块接口](../modules/uiLayout/README.md)。

## 平台与安装

- Android 8及以上：`Shantu-0.2.31-test-standalone.apk`，versionCode38，原独立系列包名`com.guanyun.weather.shantu.preview`和4a94签名，可覆盖同签名0.2.30。与原观云系列并存，数据不自动迁移。
- 手机布局写入设备本地；桌面草稿不会默认带进安装包。导出的`shantu-layout-draft.json`可回到桌面控制器导入。
- HarmonyOS6.1原生HAP/APP尚未交付，本APK不代表原生鸿蒙安装支持。

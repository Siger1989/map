# 静止地图闪烁：本轮证据与已修复问题（2026-09-08）

用户再次反馈地图仍闪烁。本轮没有复现用户描述的闪烁瞬间，**不能宣称闪烁已彻底解决**；需要补充出现于电脑网页还是手机APK，以及全图变白/变黑还是局部线条闪动。

## 已确认并修复：Android原生记录无变化也刷新

`useRecording`每1.5秒读取一次原生记录。原实现每次JSON解析都会产生新记录及新segments，即使返回字符串完全相同；上层据此重算轨迹与定位覆盖层并提交地图数据。静止、暂停、完成和未记录状态都可能发生无效工作。

新增`nativeRecordingSnapshot`缓存最近一次成功读取的原始字符串与解析结果，相同快照复用同一对象；仅有新定位点、记录状态或精度提示变化时更新。读取失败保留既有数据，重复失败不重复刷新，恢复时重新显示正常快照。原生轮询频率、定位精度门槛、权限、存储内容和记录点均不改变。

3项新增回归覆盖四种记录状态的重复轮询、新定位/命令/提示、损坏数据重试和恢复；全量233项通过。这是确定的刷新优化，**未证明它就是用户此次闪烁的唯一原因**。

## 路线：直接输入、添加途经点、拖动排序

1. 打开“路线 → 道路规划”，选择驾车、骑行或步行。
2. 直接点起点或终点栏输入名称。输入停顿后显示候选结果，选择结果才能确认坐标；中文输入法组词期间不发起搜索。也可以用地点旁图钉在地图选点，或把当前位置设为起点。
3. 点击“途经点”添加地点，新增行位于终点之前，最多 **8 个途经点 / 10 个地点**。选中途经点栏可清空、重新搜索或删除。
4. 按住地点右侧拖柄上下拖动，起点、途经点和终点都能调整顺序；拖到列表边缘会自动滚动。“反向”倒转整个地点列表。键盘用户可聚焦拖柄后按上下方向键。
5. 确认每行地点后点击“规划路线”。修改地点、交通方式或顺序后需要重新规划，旧路线不会被当作新结果保留。
6. 结果显示道路线路、距离、预计耗时和分段转向；地图按顺序编号途经点。收藏会保存地点顺序，旧两点收藏仍兼容。

相邻地点至少相距 20 米，直线分段总长不超过 500 km。路线由 Valhalla 公共服务按地点顺序计算；搜索使用 Photon。搜索结果完整性和道路可达性取决于上游数据；本版不含实时路况、语音导航或离线道路计算。详细实现见 [路线与行程条](route-stops-and-scrub.md)。

## 左侧行程条：沿线浏览与天气

完成道路规划后，左侧显示温度/降水双色行程条。可点按或上下连续拖动，地图中心与“览”游标同步到线路位置，弹出对应里程、预计抵达时间和附近采样预报。

- 可见色带宽 12 px，触摸区域宽 44 px，高度约为手机可视区的 48%，便于细调而不占用大块地图。
- 白色预览位置与绿色 GPS 进度独立，拖动不会改写真实定位或实走记录。关闭预览移除游标，地图保留当前浏览位置。
- 键盘方向键调整 1%，配合 Shift 调整 10%，Home/End 到起点/终点。展开工具面板时暂时隐藏色带，减少重叠。
- 天气来自附近模型采样点，并按预计抵达时间匹配；渐变用于阅读，不代表逐米实测或更高预报精度。可比较当前出发、提前两小时、推迟两小时的沿途雨量与风速。
- 断网可读取已有缓存预报并显示时间戳；缺测或超出预报范围保留缺失状态，缓存不是实时更新。

## 地图与原 3D 控制器

单指平移地图，双指缩放、旋转与调整俯仰；右下绿色模型上下拖动调俯仰，沿圆环滑动调方向。“工具”内可临时收起视角盘。地图视角保存在 URL hash。

默认显示开源道路地名与三维地形。卫星影像、等高线、云雨和地质等图层通过“工具 → 图层”按需开启。点击温度/海拔入口查看天气，时间轴位于工具中。

**地形裁切剖面已停用**，不显示入口、不启用地形裁切；手绘轨迹的高程统计图和爬升下降分析仍保留。地图标记与米制几何模型仍可编辑，已保存路线节点或模型可长按移动。相关操作见 [标记与节点编辑](selection-and-node-editing.md)。

## 行程：记录、文件与离线

| 入口 | 操作 | 当前边界 |
|---|---|---|
| 实走记录 | 开始 → 暂停/继续 → 结束 → 保存到轨迹；也可导出 GPX | Android 使用带持续通知的定位前台服务；网页版仅前台记录。过滤低精度、过旧和明显跳点，最多 6000 点 / 100 段；中断后恢复为暂停 |
| 数据 | 导入 GPX、KML、单文档 KMZ 或观云 JSON，预览后合并；导出 GPX/KML/JSON | GPX 保留点时间与海拔，KML 支持普通点线；不执行 XML 实体或 KML 网络链接。JSON 备份已存轨迹、标记模型及路线收藏 |
| 离线 | 按所选轨迹、规划路线或地图选点周边创建包，下载后检查完整性，可暂停/续传 | 包含指定范围开源矢量、地形和字体；不含卫星、在线搜索/路线计算或新的天气数据 |

离线范围外扩约 2 km，矢量至 14 级、地形至 12 级；单类瓦片最多 700 张，最多 8 包、每包 180 MB。过大范围需拆分，缺失项目会提示。用“打开范围”查看已下载区域，可在出发前切到飞行模式核对缓存覆盖。应用存储被清理后需要重新下载。

JSON 不包含离线瓦片、服务 Key 或尚未“保存到轨迹”的记录。数据存于本机，GitHub 源码同步不会同步手机路线和定位记录；换设备需通过导出/导入迁移。完整说明见 [户外功能](outdoor.md)。

## 免费开源图源与联网范围

默认使用免 Key 的 OpenFreeMap / OpenStreetMap，不需要用户申请地图 Key。**开源来源不等于国内服务器**，当前未完成全部服务在国内各网络环境的稳定性验证。

| 用途 | 本版来源与限制 |
|---|---|
| 默认道路与地名 | OpenFreeMap / OSM，保留来源署名；不使用 OSM 官方标准栅格服务器批量下载 |
| 国内底图选项 | 保留天地图适配，需要本应用自己的 Key；当前默认不依赖它 |
| 地形 | 内置成都区域 473 张地形瓦片，其他区域仍需获取对应数据；不是全国内置离线地图 |
| 搜索与道路路线 | Photon / Valhalla 公共服务，联网请求，无生产可用性承诺 |
| 天气与可选影像 | Open-Meteo、EOX / NASA；预报、年度合成影像与卫星观测各有不同时间含义 |

现有 FABDEM、部分 EOX 影像及天气免费服务仍有非商业使用限制；公开源码或免 Key 不代表所有数据已经具备商用授权。1∶20 万地质云仍缺有效授权，现有世界地质概览不能替代该精度。各来源资料见 [数据来源调查](data-sources.md) 与 [国内图源说明](roads-models-domestic.md)。

## 验证记录与尚待验收

0.2.2 发布时已通过 TypeScript、**122/122 逻辑测试**、网页及 Android 构建。390×844 与 360×780 浏览器检查直接输入、地图选点、触摸排序、行程条拖动、收藏恢复及 460 px 压缩视口。自动交互测试使用固定服务响应；另有真实 Valhalla 三点请求验证。

APK v2/v3 签名通过，与此前测试签名一致；548 项打包静态资源逐项哈希匹配，含 473 张内置地形瓦片。既有离线模块已做断网缓存渲染与缺失项检查。

未连接 Android 真机，因此系统输入法、真实触控手感、锁屏持续定位、厂商省电策略与耗电仍待设备验收。Android 已加入 IME inset/adjustResize，但浏览器缩小视口不能替代真实输入法测试。

# 山兔 0.2.48：路线卡片直接改名

- 地图上选中路线后，点击卡片标题或标题旁“改名”，原卡片切换为名称输入、取消与保存名称；不再需要寻找其他详情页。输入最长60字，空名称不覆盖原名，保存失败保留输入。
- 已保存路线写回原存档，收藏列表读取同一名称；草稿自定名称随后续路线保存保留。只更新名称和修改时间，不改变路线点位、节点、样式及创建时间。
- 切换选中路线时重置改名界面，避免把上一条路线的输入带到下一条。输入时暂时收起卡片指标和其他操作，保持紧凑。

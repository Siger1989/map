# 山兔 0.2.28-test：离线步行导航、海拔显示与本地行程功能

地图下方提供定位跟随与显示入口。选定路线可按海拔、速度或坡度着色；颜色图例、海拔/爬升、剖面、陡坡提示和定位坐标分别选择并保存。原始高程优先，缺失时只生成地形估算显示副本，缺测灰色。地图按钮保留44px触控，缩小文字、图标、间距，窄屏信息避让工具。

## 离线与返航

- 区域步行路网下载、导入、导出、SHA256/拓扑校验；A*沿真实连接计算，边上吸附，支持途经点。可选仅离线/优先离线/在线；仅离线不会回退在线算路，支持包内道路名搜索。
- 地图缓存单独下载，支持暂停、续传、完整性检查、仅缓存读取、申请持久存储。路线和点高程、分享地图共用缓存；启动恢复开源缓存底图。道路/地名至14级、地形至12级。卫星、天气和在线搜索不在包内。
- 专门返航入口：选择一个连续轨迹段倒序返回，保留循环，不连接暂停缺口。车位/营地/撤退点复用原标记存储，可靠GPS显示直线距离/真北方位，并可使用本地路网规划返程。手动地图中心保存需明确勾选。

## 文件与分享

- OVKML/OVKMZ中的标准点线可与GPX/KML/KMZ/JSON批量导入。奥维坐标系明确选择CGCS2000地理坐标或GCJ02；后者近似转换为GPS坐标。未知不猜测，投影坐标需先转换；普通GPX/KML仍按标准。
- 图源管理新增天地图官方申请说明入口。
- 路线详情→分享可选最多8张关联照片；横竖自动混排、重点照片独行放大，保留完整画面及已有旋转/标绘。长图和ZIP复用同一图片生成器。

## 结构与验证

新增routeDisplay、offlineRouting、returnHome及独立photoLayout/photoCollage、coordinateSystem模块。组合入口通过props/接口接入，原轨迹不改写。移除右侧重复定位入口、提取RoutePanel来源说明；没有删除用户功能或数据。缓存下载容量先预留，进度写入每250ms节流。主页面2862非空行，TerrainMap维持1231；历史大文件仍需后续逐流程拆分。

## 边界

离线路由当前仅步行，区域最多100km²，单包24MB、最多8包；保守排除禁行、条件不明和高难山径。地图缓存不是路网，二者需分别准备。路网来自OSM，实际通行需现场核验；接驳虚线非已确认道路。奥维扩展名不能自动识别坐标系，尚缺用户原生文件验收。

无Android真机安装/GPS/锁屏耗电/手指触控验收。HarmonyOS6.1原生HAP/APP未交付，APK不等于鸿蒙原生包。队伍实时位置、SOS、对讲依用户“暂无服务器，先本地”暂缓。旧数据源许可边界沿用项目说明。

此APK在布局窗口开发之前构建；布局窗口将是后续本地调节工具，不将其说成本APK已有功能。实际源码推送分支`codex/huawei-webview-touch`，未合main。

# 山兔 0.2.87-test：沿线浏览缓存、删路线清理、导入图源下载

0.2.86 的停稳沿线补图已取消。自动缓存现在只保存已画路线附近实际浏览取得的瓦片，不新增预取请求；范围包含已存路线和当前草稿，与路线是否选中无关。默认两侧各1公里，可选500米/2公里。

删除路线或清空草稿时，删除其独占的浏览缓存，重叠路线需要的瓦片保留。保存草稿为正式路线不清掉对应缓存。主动离线包仍单独管理，不随路线删除。旧版无坐标归属的资源不猜测删除，可用“清理自动缓存”清理。

主动下载只支持已导入到“我的图源”的在线图源、只下载路线附近。级别逐级列出，包括图源声明支持的19级；默认选择14级，不把18作为固定上限。先选图源和路线，再在“下载沿线地图”中查看范围、最高级别和请求数量，手动开始。支持受支持的XYZ/TMS与OVMAP模板，坐标校正所需相邻瓦片计入数量。导入/购买不代表无限额；授权、配额或限流错误停止下载。

导入图源主动下载使用前台任务，请保持应用打开。已有内置图源离线包可打开和删除；新的下载/续传只开放导入图源。天地图批量暂停延续，OSM公共标准瓦片不开放批量下载。主动包按原图源URL读取，打开包会选择回对应图源，不替换成开源底图。

首次浏览或放大、切换图源、缓存过期仍可能产生正常显示所需的网络请求。仅缓存模式不补图。自动缓存上限256MiB/4096项；主动包沿用2万资源/1GiB上限。不同图源/级别不混用，地图按整张瓦片缓存，边缘范围会略超出所选距离。

本轮涉及outdoor缓存/下载模块、mapSources瓦片读取和坐标提示、地图与主界面接线、离线包列表。移除RouteCacheWarmup及其测试，新增沿线路由清理、导入模板/下载计划回归；不改原生定位记录、用户轨迹/照片格式、APK包名和签名。后台记录中断尚未在本轮修复。

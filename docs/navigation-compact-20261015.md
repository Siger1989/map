# 2026-10-15 导航位置、速度栏与锁定布局快速预览

活动源码：项目根目录，`codex/place-address-search-20261011`，基线 `3751115` 加本轮未提交修改。目标配置沿用128自用包的本机天地图Key与内置图源；未修改配置、用户存档、原生权限或签名。现有APK/EXE仍为0.2.128，本轮未升版、打包、提交或推送。

## 根因和修改

- `forwardCamera.ts`：原定位锚点在可用地图高度88%，隐藏界面时尤其靠底；改为68%，仍计算可用区域、保留缩放及用户调整的俯仰/旋转。`TerrainMap.tsx` 将顶部实时栏纳入避让。
- `useNavigationTelemetry.ts`：原实时速度仅通过两个定位估算，未用设备速度，又被偏航/质量状态屏蔽；均速被持久`gap`永久屏蔽。现在优先新鲜设备速度，缺失时采用可信相邻定位位移，拒绝网络/IP、过期和不合理速度。均速用已有有效里程除以导航耗时（含停留，断点间未知距离不补算），有累计里程时不会因定位间断被清空。
- `app/page.tsx`、`NavigationTelemetry.tsx`、新增`telemetry.css`：最新`position.fix`供实时速度，避免导航保留的旧`session.last`成为速度输入。约38px含边框顶部栏在普通/第一人称/锁定导航中显示，未知实时值说明“等待定位/等待速度”；删除导航锁定时的底部大速度框。原详情时间与高程仍保留。
- `homeMap.css`、`guidance.css`：删除导航锁定前后不同left/bottom规则；导航锁定/解锁共享左安全边与底部128px锚点。实测先发现标题继续导航按钮被旧高优先级32px样式覆盖，再修正为44px触控范围；不是仅凭声明验收。
- `GuidanceCard.tsx`：收起时保留文字跟随入口与一个44px详情按钮，视角/显示/分享/结束在详情。下一转向距离为主、全程剩余为辅；只有终点或没有逐转向数据时，明确沿路线前往目的地/途经点，不编造转弯或重复两次终点里程。标题仍可直接继续导航。正常俯视无蓝色转向大框。

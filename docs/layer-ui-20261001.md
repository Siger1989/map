# 2026-10-01 图层面板按规范优化

用户截图中的图层面板过高，最新明确要求按规范优化，并继续此前已授权的APK交付。改动限定 `LayerPanel.tsx`、`LayerWindow.tsx`、`layerWindow.css`，新增真正渲染的 `tests/layer-window.test.mjs`。图源网络逻辑、用户数据和标记专用尺寸例外没有扩大到图层。

## 根因与改法

- 道路透明度原本始终在列表内展开，长说明和44px滑杆使道路行远高于普通行。现将全部原显示参数收进默认闭合的“显示参数”，各图层开关维持单列36px热区；说明及场景预设置于同行的“说明与场景”，所有原参数/说明/预设保留。
- 共享皮肤把开关按钮画成整块36px底板。限定本窗口的开关按钮底板透明，保留36×36点击区、28×16轨道、开关状态和焦点环；颜色使用原主题令牌。
- 窗口宽248px、贴左8px，外圆角8、内控件4；标题14px且安全内距实测约15px，图层正文/入口12px。显示参数输入16px、次级操作36px。图层浏览仍用原最高480px/62dvh/可用高度约束，不用标记28px例外。
- 正常内容布局的末尾状态和margin塌陷导致约1px溢出，修正内容宿主为flex列、状态行16px及底部4px安全内距；默认没有隐藏溢出或隐藏滚动条。长说明/参数展开及矮屏保留真实正文滚动。

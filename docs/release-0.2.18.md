# 山兔0.2.18独立测试版

本版把最新收藏栏、鸿蒙4.2启动兼容和单指/双指操作一起交付，替代仅在本机提供的0.2.17中间包。

- 收藏正式采用上方约72%列表、下方原地图。文件夹原位展开，点击文件夹不移动镜头；点击条目定位并保持收藏打开。包括分类/地区TAG、搜索、排序、新建与子文件夹、颜色、多选滑选、长按拖动和插入位置提示。
- 移动、删除、解散文件夹和撤销使用真实收藏。解散保留内容；删除需核对范围后确认。整理与分享保留路线/实走轨迹来源、几何、时间、标记参数和备份目录，提供实际路线图片与数据导出，原高级ZIP/Excel入口保留。
- 去掉0.2.17的120ms手势等待。单指落下和移动立即响应；第二指优先接管，取消本次未提交笔画，交还地图缩放。所有手指抬起后恢复单指，已提交的线段保留。
- 保留鸿蒙4.2兼容修复：移除按厂商WebView包版本首段<120禁止启动的判断，补齐旧组件接口，按真实WebGL2/Worker能力加载。网页和地图worker按Chrome99编译，保留旧CSS/视口兼容，不要求升级手机系统或安装谷歌组件。

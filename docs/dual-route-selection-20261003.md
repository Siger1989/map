# 2026-10-03 双图蓝线选择与编辑改名（预览）

用户反馈双图点蓝色规划路线无反应，要求编辑标题直接成为名称输入栏、上下换位键贴右。工作目录 D:\天气地图，分支 codex/rollback-ui-0235-20260921；保留原有未提交改动。现有 APK 仍为 0.2.103-test/code110，本轮仅更新相同私有图源配置的预览源码，未重新打包、升版或推送。

## 根因与修复

- 主界面的路线规划面板被双图布局隐藏。MapComparisonHost 增加双图内规划路线操作卡；上/下图共享选择事件，清除图层/样式遮挡。可看全程、直接编辑线点；更多操作返回原完整规划面板。
- 浏览时先拾取已保存轨迹，再拾取规划路线。360 实际复现重叠蓝线被旧轨迹抢走；现在保留标记优先，在轨迹之前拾取规划路线。编辑状态仍先选当前节点/线，未命中才交给蓝线；分叉绘制路径保持原逻辑。切换通过现有未保存确认门，不能直接丢弃编辑。
- RouteEditToolbar 原来只有静态标题。现在直接显示路线名称输入框，支持中文输入，失焦/回车提交，空白恢复，Escape 取消当前输入；改名作为一次可撤销编辑。保存、退出和另存副本携带当前缓冲值，页面读取 useRouteEditor 的即时会话，避免 React 失焦更新和按钮点击之间丢名。
- editedRouteRecord 在普通路线、仅改名称的实测路线、几何副本和组合路线中保留自定义名称；原始来源和实测采样不被改名流程删除。
- 名称与换位按钮在第一行，保存/退出在第二行。处理 outdoorSurfaces 的共享 header padding 覆盖，浮窗约 300×197 CSS px；名称字号16px，换位44×44px，距浮窗右边约9px。

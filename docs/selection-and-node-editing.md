# 路线与标记编辑

## 使用方式

1. 手绘后点击“完成”。点地图上的线路或圆形节点，打开对应线路详情并高亮。草稿也能选中。
2. 详情可查看里程、段数、节点数、创建时间、高程统计及沿途天气；已保存线路可改名/样式、续画和调整节点。
3. 点击“调整节点”收起详情，在地图上按住节点约 0.48 秒，出现调整提示后拖动。也可以直接长按地图上已有的圆形节点。放大后会显示更多平滑线路的控制节点。
4. 松手提交位置。已保存线路自动写入本机；草稿仍需在详情中“保存到本机”或“保存整条线路”。工具条和详情提供撤销；已保存线路保留本次会话最近 20 次节点移动记录。
5. 点击标记名称或三维模型实体打开参数编辑。长按标记名称可拖动锚点；模型尺寸、朝向、埋深不随平移改变。松手保存后重新读取该处地面海拔；失败时可在详情手动填写或重试。标记位置也支持最近 20 次移动的撤销。

短按仍用于选择，快速划动仍交给地图。第二根手指加入、Esc、系统取消触摸或窗口失焦会放弃当前移动，保留原数据。拖出地图或松手落在无法对应地面的天空区域也不会提交。正在绘制、放置标记或选择规划路线起终点时，长按移动暂停，先完成/退出当前操作。

图层隐藏时无法从地图选中，仍可在列表中查看。点击空白地图清除当前选择。移动一个路线接点会同步调整该线路中完全相同坐标的连接点，不改变邻近独立点或其他线路。撤销移动保留后来修改的名称和样式；续画/反向/合并会结束已保存线路的旧移动撤销序列。标记通过“地图重选位置”开始新的位置编辑序列。

## 模块与数据

- `tracks/editing.ts`：不可变节点坐标变更、共享接点及随地图放大的编辑节点。
- `tracks/TrackLayer.ts`：业务 ID、选中高亮、10px 线条/14px 节点拾取容差，原始坐标读取与临时预览。
- `tracks/draft.ts` / `useManualTracks.ts`：草稿撤销、存档移动/撤销、改名、续画节点保留。
- `map/FeatureDragBridge.ts`：独立长按状态、临时禁用/还原原生地图控制、取消/提交与抑制拖动后的误点击。
- `annotations/AnnotationLayer.ts`：模型射线拾取、选中轮廓，拖动时保留 DOM 标记及几何体，只更新位置。
- `annotations/useAnnotations.ts`：标记位置写入与撤销，移动后更新地面海拔。
- `app/page.tsx`、地图接口、两类详情面板与 CSS：选择、临时预览和编辑工具接线。网页和 Android 静态入口共用。

存档格式和存储键不变，无需迁移旧路线/标记。没有删除业务功能；天气、地形、道路匹配及国内底图配置保持。未发布 Sites，未重新生成 APK。关闭详情中的选择或退出绘制即可回到浏览；代码回滚时按本次 Git 提交还原上述模块，不需删除本机存档。

## 验证

专项测试在 `tests/selection-editing.test.mjs`，覆盖拾取标识/精确坐标、模型实体拾取、节点与共用接点移动、续画/撤销、长按阈值、短按/平移不写入、拖动锚点偏移、双指切换、取消、失焦、离开地图、无效地面与地图控制恢复。模型测试使用 DOM/地图适配替身及实际 Three.js 几何运算；没有进行浏览器截图、真实地图触控或设备性能验证。

完整类型检查、测试和网页/Android 静态入口构建结果记录在 `CURRENT_STATE.md`，详细日志留在 `.openai/`，不提交日志。

# 山兔 0.2.27-test：结构整理、记录模式、轨迹分析和批量导入

## 这版改了什么

- 地图增加开始/暂停/继续记录与设置入口，地图编辑时隐藏以免遮挡。行程拆为记录、数据、离线、照片独立组件。
- 记录增加省电、标准、高频、自定义模式；可按距离记点。Android支持静止60秒后降频、检测可靠移动后恢复。用户可开启“开始导航时自动开始新记录”，默认关闭，不覆盖未保存记录。
- 实走轨迹增加速度/坡度着色，保存保留时间、高程和可选样式，地图与分享地图使用同一分析逻辑。路线详情增加最高区间速度、采样最大坡度、连续50米坡度和陡坡段数；无时间/高程不猜测。
- GPX/KML/KMZ/JSON支持一次选择或拖入最多10个文件，整批≤32MB、单文件≤8MB。整批在隔离内存校验，确认后按当时本机数据一次合并；坏文件会阻止整批写入，原有记录保留。
- 数据交换拆为解析、验证、存储事务、导出、下载，旧exchange入口兼容；导航启动与定位生命周期、轨迹覆盖层组合从主页面分离。
- 记录拒绝采样不再复制全部轨迹，质量提示更新复用几何；后台页面停止快照轮询；Android缓存未变快照，查询记录阶段不再将整条轨迹JSON反复编码/解析。仍按原子检查点保存，不延迟落盘。
- 新增结构检查和模块接口说明，旧进度完整归档。本机默认APK命令遇到旧PowerShell缺少Get-FileHash，改为共享.NET流式SHA256实现，最终默认构建命令已通过。

## 文件与边界

新模块：`modules/dataTransfer/`、`modules/routeAnalysis/`、`modules/workbench/`。记录模块新增独立面板、采样设置和投影；Android新增`SamplingPolicy`/`SamplingPreferences`，修改记录服务/存储/桥。入口修改`app/page.tsx`、轨迹样式/地图层/详情、分享地图、构建脚本、版本配置。

删除的是重复轨迹拼装和旧单文件内已迁出的实现，没有删除用户功能或存档。完整历史迁至`docs/history/progress-through-0.2.26.md`并核对与基线一致。未改变包名/签名/Logo/存储键、测量与勘探几何、模型精确操作、地图手势、天气和地形数据。

主页面仍有2831非空行，后续按完整流程继续拆分；本次不是全项目重写。入口和接入顺序见 [结构说明](architecture.md)及[附图逐项对照](upgrade-plan-20260914.md)。

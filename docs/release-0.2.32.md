# 山兔0.2.32-test：保留当前页面，分开移动与缩放

从「更多 → 布局」进入时保留当前打开的功能页面；点击调节工具条不会再触发面板的外部关闭。手机仍是一行40px工具条，可拖左端移动，参数按需展开，没有常驻组件清单。

- 「移动 / 大小 / 使用」分开：移动时不显示缩放点，大小模式拖组件主体不会移动；使用模式继续操作地图。
- 默认整体缩放：拖任意边角或输入宽高时，文字、图标和间距同步缩放，保留内部原来的居中/左右对齐；拖边角固定另一侧。取消整体缩放才单独改变外框。
- 字号显示所选组件首处文字的实际显示像素，随比例更新。修改统一所选文字，清空恢复默认。
- 移动时显示细粉色边缘/中心对齐线并轻吸附，可以在参数中关闭。
- 「上一层 / 下一层」调整同父级的显示顺序；整组被其他父级遮住时先选外层。保存、撤销、导入/导出JSON格式与旧版兼容；手机「参数 → 更多 → 导出布局」。

共享实现位于`modules/uiLayout`；新增alignment、layers两个小模块，修改geometry/gestures/session/mobileEditor/CSS及桌面控制器。现有面板只接入公共事件保护，删除布局入口的强制收起行为。原始路线/高程、离线导航与缓存、GPS、测量和模型数据逻辑未修改。

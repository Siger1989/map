## 必应行程加载

0.2.218 的手机主图用 Android 原生瓦片网络和浏览缓存。行程继承同一图源，经 WebView 的瓦片网关另外请求影像和高程。行程在网关仍等待时，网页端会于 3.5 秒取消影像。多段轨迹的首段若无有效长度，也可能使相机在起点无法建立方向并报路段不可用。

Android 行程影像现在给原生网关留出完整请求时间。先绘制可用高程，卫星影像返回后替换地形贴图。分开限制高程与影像任务，切图源清除旧影像，播放时跳过孤立点和零长度段。轨迹分段和原始存档不改。

# 当前界面对象调节与搜索尺寸（2026-11-14）

用户追加：搜索条目贴近窗口边缘，应该能调尺寸；左侧应显示当前打开界面的内容，选择后右侧提示对应对象，再修改参数。保留当前配色与用户正在调的圆角，不打包。

## 当前入口与边界

右侧恢复 `http://127.0.0.1:9174/phone-preview.html`，明确标注网页调色、非安卓实际画面。低频PNG桥服务已停止；`native-preview.html` 改成手动截图检查，默认不连续刷新，未接通参数时显示原因及返回网页入口，不再摆出整套禁用调色控件。现有203与旧助手缺少热调色通道，安卓实时交互/共用参数仍未交付，不能把网页验证当手机验收。

## 实现

- `mobile/phonePreviewMaterialTargets.js`：识别当前窗口，列出外框、标题、按钮、输入与开关；按DOM对象稳定标识选中，右侧单个蓝框及名称提示。选择只定位，不执行原按钮操作；内部滚动对象可定位到可见区域。窗口关闭/切换后刷新列表，旧选择不遗留。无菜单时展示地图工具。
- `mobile/phonePreviewMaterial.js/.css`：对象列表作为主要入口，全局类别折叠保留；打开新窗口默认定位外框。明确提示颜色/圆角仍影响同类共用控件，不能把单个蓝框误解为只修改一个元素。
- `modules/appearance/materialDimensions.js`：四个有范围的共用尺寸令牌，宽度上限240–360px，内边距4–20px，条目间距0–12px，条目最小高度44–64px。先接地点/路线搜索浮窗，不宣称所有菜单尺寸均已可调。
- `modules/input/FloatingSearch.tsx` 与 `suggestions.css`、`modules/navigation/search.css`、`modules/controls/PlaceSearch.tsx`：实际App CSS消费令牌，宽度继续避让右侧工具与视口；历史高度同步内边距、行高、间距和分隔边线，内容超过上限保持真实滚动。
- `modules/appearance/roundedSpring.css`：修正后加载的旧36px标题规则，统一为44px标题槽，避免抵消搜索布局修复。
- `materialRuntime.js` 和测试助手白名单：加入尺寸令牌及像素范围校验，供后续App开发组件使用；本轮没有更新安装组件。

根因：搜索外框原内距仅4px，改变圆角不会增加留白；旧历史高度按固定行高估算，参数变化后会裁边。对象识别最初漏掉SpringPresence的Web Animations开窗：动画期间opacity=0而结束不会发CSS animationend；现订阅动画finished后重新识别，并合并事件刷新，无空闲轮询。

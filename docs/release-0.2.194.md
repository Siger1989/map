## 本包变化

- 工具→照片标记：读取EXIF GPS/WGS84，不依赖轨迹或当前定位；50米固定标记中心范围合并近照，自动归入收藏“照片”，同图重导入跳过；无可用GPS明确跳过。未知拍摄时间显示未记录，Android预处理副本保留可读取GPS字段，原片不改。地图同组照片可翻页，原拍摄坐标保留。保存失败回滚本次标记与目录，保护其它记录。
- 地图照片最大32CSS像素，常用级别连续缩放；Native和Web使用稳定对象/图片源，图片更新保留旧图直至新纹理就绪，减少空白或占位闪烁；原生图片密度与地形遮挡保留。
- 锁屏/悬浮罗盘不再等待GPS后才给方向：无定位显示标注的磁北，再随定位校正；服务存活期间最多10分钟方向缓存以“上次方向，正在更新”呈现，熄屏仍停传感器。缺位置可显示独立罗盘，不生成虚拟定位或GPS运动方向。
- 图源体检→全部测试/停止全部/重试全部：同一中心与zoom顺序逐项检测，分类显示成功、无覆盖、授权、网络和超时等结果，不切换实际图源或视角。未测图源不声称正常。
- 图层开关透明输入框漏入原生UI触摸区域已补齐，隐藏/禁用行仍不拦地图。已证实源码缺口，用户手机当次故障未实机复现。
- 共享普通浮窗4px内边距，标题返回/关闭与正文对齐；390/360指定窗口已实测，超出内容区滚动，保留标题操作与原有内容页例外。

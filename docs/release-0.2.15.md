# 山兔 0.2.15 独立测试版（2026-09-09）

本版完成确认的标记窗口与兔子山路Logo。安装包使用本机已有独立测试版签名。

## 使用变化

- 点击标记先看紧凑摘要：名称、位置、海拔，以及导航、编辑、详情；删除带确认。
- 编辑统一为“返回 / 基本 / 位置 / 资料 / 保存”。基本页集中名称、图标、颜色；资料集中自定义属性与备注，内容多时内部滚动。
- 模型位置以X红/Y绿/Z蓝显示位移米和旋转度，每个数值独立回正，保留原3D控制器。普通地点保留X/Y控制，不显示不适用的Z/旋转项。
- 编辑内容及控制器调整先进入草稿；保存失败可重试，返回或切换标记可保存/放弃/继续。其他窗口改动或删除同一对象时保留草稿，避免覆盖。
- 输入时适应键盘压缩，当前字段自动滚动可见；返回/保存固定。修复地图更新期间窗口与控制器使用相同组件标识造成的重复面板。
- 应用内品牌、网页图标与Android桌面图标采用用户指定的深绿兔子山路原图，保持比例。

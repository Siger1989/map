# 山兔 0.2.14 测试版（2026-09-09）

本版整理路线操作层级，并修复节点分叉、路线组合和导航方案的一致性。

## 使用变化

- 点路线统一打开一级卡：导航、添加标记、编辑、详情。再点线只更新绿色位置点；返回上一级保留位置。
- 导航准备直接选择出行方式、原路/备选、起终点与交换方向；新增路线缩略地图，绿色“起”、红色“终”与选择框对应。下方是实际地形海拔曲线与六项统计，缺失数据显示“—”。
- 编辑时选中节点直接拖动移点；＋插入中间节点，−删除节点并连接前后点。分叉统一使用原画线手势：准星定点、松手连线、双指控图。可接回旧节点闭环，或吸附其他可见路线节点。
- 连入其他路线后保存为新组合，收起来源路线；原路线、照片和标记保留。几何、颜色、线宽和透明度先暂存；保存失败留在编辑，返回可保存、放弃或继续。沿道路的一段连线按一次撤销处理。
- 详情只显示基本资料、起终点、路线组成、沿途标记和关联照片；顶部返回与分享，底部删除路线并显示名称确认。删除仅移除该路线，照片、标记及来源路线保留。
- 一级卡压紧，左侧进度轨道细化并上移，避免底部菜单遮挡。拖动导航天气进度条时显示左侧约164×124px小卡，里程、预计到达和天气紧凑排列；说明放入图例。
- 原路/备选同步驱动地图、进度、导航预览和统计；反向保留所选线形，改端点仅延伸连通路段。保持最近接入、只在相连分叉切换、终点不变。

## 数据与模块

新增 tracks/routeEdit、useRouteEditor、RouteViews、routeInfo、routeWindows、useRouteDialogFocus；guidance/preferredPath、RouteMiniMap；journey/RouteElevationSummary。调整地图事件、轨迹覆盖层、导航准备/匹配、分享存档与来源照片读取。路线新增可选 hidden/sourceTrackIds，旧存档兼容；组合通过关联读取原始内容，导入冲突时重映射来源ID。

没有删除业务模块、引入依赖或修改包名、签名、定位记录与照片存储键。APK不包含临时QA页面。

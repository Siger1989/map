# 规划路线导航与偏航接回

规划路线后，直接点地图上方或路线面板里的“开始导航”，允许定位即可。导航卡片常驻显示本次已走距离、剩余距离和前方转向；地图自动跟随经过质量检查的位置。手动浏览地图会暂停跟随，可点“恢复跟随”。点卡片右上角叉号结束导航。

蓝线保留原规划路线；连续可靠定位确认偏航后，按原步行、骑行或驾车方式计算通往原路线的道路路径，以橙线显示，圆点指示接回位置。“看接回路线”查看连接段全程；回到原路线后橙线自动移除，继续原导航。尚未到达的途经点不会被接回目标跳过。没有可接入道路、服务失败或断网时显示原因，不用直线冒充可通行道路。

## 进度与定位规则

- 已走距离从本次开始后的首个有效定位起算，过滤小幅抖动与异常跳点；倒退和偏航后实际走出的有效距离仍累加。沿路线进度单独计算，倒退时剩余距离可增加。
- 导航接受20秒以内、精度不差于50米的定位；定位精度不足、过期或拒权时提示等待。地图跟随和定位点使用同一套被接受的位置，异常跳点不拉走视角。
- 相邻有效定位间隔超过30秒，或经过定位中断/精度不足，重新建立距离起算点，不把中间未知行程连成已走距离。卡片明确提示这段距离没有累加。
- 偏航阈值按定位精度变化，至少35米；两次不同定位相隔至少3秒持续偏离才确认。重复的旧定位和计时器不会充当新定位，回归阈值更小，减少临界点反复切换。
- 转向来自规划服务的路段指示；原路线投影限制连续进度范围，交叉/环线路口优先保留上一进度。接回目标限制在下一未到达途经点之前。距离均为估算，复杂平行道路仍受GPS与地图数据精度影响。
- 接近终点且原路线进度到末端，连续两次定位相隔至少3秒确认到达，保留里程卡片，直到主动结束。

## 查询与生命周期

接回路径复用现有FOSSGIS / Valhalla服务，保留原出行方式和其道路通行约束。官方API允许把输入坐标匹配到附近道路，`radius`也不是严格的匹配距离上限，因此返回后另行核对几何端点：起点距离不超过20米或GPS报告精度，终点距离原路线目标不超过20米。参考[Valhalla路线API](https://valhalla.github.io/valhalla/api/route/api-reference/)。

同一时间只有一个接回请求；自动请求至少间隔30秒，失败后至少等待60秒再随新定位重试，也可主动“重新计算”。已经沿接回线移动时不反复重算；再次持续偏离接回线才触发。沿用提供方的1.1秒请求间隔、15分钟/24条缓存和25秒超时。

结束导航、修改/清除规划路线、回到原路线、定位失效或断网会取消不适用的请求。晚到结果不能恢复已结束的导航；查询期间人已离开返回路径时丢弃旧结果。导航单独开启的定位在结束时关闭，之前已开启的定位保留。导航与实走记录可同时使用，导航不会清除记录。

导航中暂时收起路线天气条，结束后恢复；天气数据与设置不变。编辑标记/轨迹或选点时其操作提示优先，退出编辑后导航卡片恢复。

## 模块、接口与回滚

| 文件 | 职责与接口 |
| --- | --- |
| `modules/guidance/geometry.ts` | 预计算路线距离，限定区间投影与路段提示；`pathOf/project/nextInstruction`，依赖已有经纬度/距离类型。 |
| `modules/guidance/session.ts` | 纯导航状态与GPS过滤；`createSession/advance/rejoinTarget`，不联网、不写存档。 |
| `modules/guidance/rejoin.ts` | 接回道路查询、端点匹配校验；`calculateRejoin`接受AbortSignal，复用原provider。 |
| `modules/guidance/useGuidance.ts` | React会话、网络状态、取消、限频、旧结果丢弃；公开`start/stop/retry`与显示状态。 |
| `modules/guidance/GuidanceCard.tsx`、`guidance.css` | 常驻卡片及开始入口样式；44px操作目标、内部滚动，最高38dvh/320px。 |
| `modules/guidance/GuidanceLayer.ts` | 独立`route-guidance`数据源绘制橙色接回路径；`sync`，不修改原规划线。 |
| `modules/map/TerrainMap.tsx` | 装配独立导航叠加层，接受`guidanceOverlay`公共prop。 |
| `modules/navigation/RoutePanel.tsx`、`app/page.tsx` | 开始入口、显示状态、定位所有权及跟随接线。 |

没有修改或迁移轨迹、照片、标记及收藏存档；没有新依赖或业务文件删除。回滚可撤销新增guidance模块与入口/props，原路线规划和记录继续工作。

## 验证与边界

`tests/guidance.test.mjs`覆盖进度、倒退、定位质量/漂移/时序、间断距离、环线/交叉路口、途经点上限、跨日期变更线、到达及独立图层。与原导航、路线操作、定位跟随测试一起运行。

`node --experimental-strip-types scripts/verify-guidance-browser.mjs`使用独立浏览器上下文和合成GPS/道路，在390×844和360×780验证规划开始、拒权恢复、有效里程、连续偏航、原路线保持、接回、断网/失败/重试、晚到响应取消、到达、结束与修改计划时释放定位，以及控件遮挡/溢出。截图位于`artifacts/screenshots/guidance-*.png`，不操作用户当前页面的存档。真实道路服务另用柏林公开道路样点确认1908.169米步行路线及846米接回查询、11条路段指示。

这是前台定位导航，尚未做Android真机步行与触控验收；没有新增锁屏后台导航或语音播报。导航会话与里程不自动存为轨迹，刷新页面会结束；要保存实际轨迹可同时开启实走记录。接回需要联网和可路由道路，原地图数据许可及服务限制保持。本机只能完成未签名APK验证，仍缺原签名私钥，本轮没有可安装新版或新Release。

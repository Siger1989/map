## 更新

- 新增室内网络定位：右侧「更多 → 室内」，调用系统基站/Wi-Fi网络定位，显示来源和估计误差；可切回自动GPS+网络。属于大致位置，不提供楼层/房间定位。
- 修复扫码预览裁切：完整取景、加高扫码面板，提供镜头选择和重试，支持设备可用的缩放复位/连续对焦；修正权限弹窗和后台切换时的处理。
- 消除路线/轨迹/位置覆盖层无变化时的重复数据提交和反复层序调整；减少定位小幅漂移带动地图移动。电脑山区静止约109秒无新增渲染/道路源加载事件；用户手机道路闪烁仍待X8 Ultra实测，不能宣称全面解决。
- 包含此前已完成、尚未进入0.2.7 APK的「开始实走记录前选择颜色与线宽」。轨迹存档、原始GPS样本、精度门槛、天气、地图服务及备份格式保持兼容。

详细使用、模块和验证见仓库 [室内定位与扫码说明](https://github.com/Siger1989/map/blob/main/docs/indoor-position-and-camera.md)。

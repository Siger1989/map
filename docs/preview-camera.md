# 路线预览中的镜头操作

右下角绿色模型上下拖动调俯仰、左右拖动旋转，斜向拖动同时调整两者。外圈保留单独旋转操作。上下/左右方向键对应微调，Home 俯视、End 最大倾斜。路线预览仍保留当前里程与预览点；手动调整镜头时暂停位置跟随，点“跟随当前位置”恢复。

入口与职责：`modules/controls/CameraGizmo.tsx` 管理手势与 SVG 捕获；`cameraGesture.ts` 计算角度；`workspace.css` 提示可拖动；`app/page.tsx` 通过公共回调暂停自动跟随并更新镜头。没有修改路线/轨迹/标记/照片存档或地形算法。

修复前绿色模型只处理纵向移动，横向拖动没有作用。本轮同时给拖动会话补上失焦、隐藏页面、指针取消/丢失捕获与第二根手指的清理；捕获由稳定 SVG 根节点持有，拖出模型范围仍可继续。没有新增依赖、删掉功能或重置预览路线。

验证：`tests/camera-gesture.test.mjs` 检查双轴、角度边界与跨北向；`scripts/verify-route-stops.mjs` 调用 `camera-gesture-checks.mjs`，在两手机尺寸的路线预览内执行真实鼠标/Chromium 触摸、外圈、取消/失焦恢复、键盘与预览保留检查。隔离浏览器验证不等于安卓真机触控验收。回滚上述控件与 app 单行跟随回调即可恢复原行为。

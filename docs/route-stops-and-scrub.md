# 地点输入、途经点与行程预览

- 打开路线，在起点或终点栏直接输入，停顿后显示搜索结果；中文输入法组词期间不搜索。选中结果才确认坐标，也可用旁边的定位图标地图选点。
- “+ 途经点”在终点之前添加一行，最多 8 个。每个途经点行末常驻“×”删除按钮（44px 触控区），无需先点输入框，空白或已选地点均可删除；起终点保留，已收藏路线不受影响。点输入框仍可清空或搜索；所有地点均可拖右侧手柄排序，也支持手柄上的上下方向键。拖到列表滚动区边缘会自动滚动。“反向”倒转完整行程，修改地点或顺序后重新规划。
- Valhalla locations 按列表顺序发送，途经点使用 break，分段抵达提示区分途经点和终点。相邻地点至少 20 米，最多 10 个地点；客户端 500 公里上限已移除。仍是公共测试道路服务，是否能完成长途计算取决于服务响应，不含实时路况。
- 收藏与 JSON 备份在 route.stops 保留有序地点；旧版没有 stops 的两点收藏继续可读。地图按实际途经点位置编号。
- 左侧行程条下方为起点（0 km）、上方为终点（全程公里数），向上拖动前进，天气渐变方向一致。键盘上/下方向键前进/后退每次 1%，Shift 配合每次 10%，Home/End 到起终点。视觉双色轨道 12 px，触摸区 44 px；高度随屏幕变化，手机约 48dvh。
- 滑块旁的小公里数表示沿路线距起点的位置，不是累计实走总里程。点定位开启持续定位后，进度自动随有效 GPS 更新；手动浏览显示白色“览”公里数，真实定位绿点继续更新，关闭预览或恢复跟随可回到实时进度。定位缺失、超过 60 秒、精度不足或明显偏离时不显示虚构里程。进入导航时沿用导航卡片显示已走/剩余距离，天气带暂时隐藏。
- 拖动按线路实际几何定位游标、同步地图中心，显示里程、预估抵达时间和附近采样预报。温度/雨量渐变只改善浏览，不宣称新增空间采样精度。预览游标与真实定位进度分离；关闭预览移除游标，地图仍停留在浏览位置。展开工具面板时暂时隐藏行程条，减少遮挡。
- Android 键盘弹出时为 IME 留出空间；手机压缩视口检查不能替代真机输入法验证。

涉及 navigation、journey、TerrainMap 预览接口及 app 组合；不修改手绘/标记、记录服务、离线缓存或地形算法。原 3D 控制器保持，剖面关闭。

验证：122 项逻辑测试；真实三点道路服务返回正确数量；390×844 / 360×780 的直接输入、地图选点、CDP 真实触摸排序/色带拖动、收藏恢复及 460px 视口检查。验证脚本 scripts/verify-route-stops.mjs 对搜索/天气/路线使用固定响应，真实服务验证另有本机日志。APK 签名、静态资源与构建检查见 CURRENT_STATE。

进度带方向与公里数回归由 scripts/rail-progress-checks.mjs 补充：向上触摸/方向键前进、紧凑标签与窗口不重叠、通过 geolocation.watchPosition 注入连续位置推进、预览与真实定位分离、无效位置不显示里程。浏览器模拟位置不代替手机实地 GPS 验收；最新执行结果见 CURRENT_STATE。

接口依据：https://valhalla.github.io/valhalla/api/route/api-reference/ （ordered locations / break）。

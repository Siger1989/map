# 地点输入、途经点与行程预览

- 打开路线，在起点或终点栏直接输入，停顿后显示搜索结果；中文输入法组词期间不搜索。选中结果才确认坐标，也可用旁边的定位图标地图选点。
- “+ 途经点”在终点之前添加一行，最多 8 个。点途经点栏可清空、搜索或删除；所有地点均可拖右侧手柄排序，也支持手柄上的上下方向键。拖到列表滚动区边缘会自动滚动。“反向”倒转完整行程，修改地点或顺序后重新规划。
- Valhalla locations 按列表顺序发送，途经点使用 break，分段抵达提示区分途经点和终点。相邻地点至少 20 米，最多 10 个地点，直线分段总长不超过 500 km。仍是公共测试道路服务，不含实时路况。
- 收藏与 JSON 备份在 route.stops 保留有序地点；旧版没有 stops 的两点收藏继续可读。地图按实际途经点位置编号。
- 左侧行程条可点按或上下拖动，键盘方向键每次 1%，Shift 配合每次 10%，Home/End 到起终点。视觉双色轨道 12 px，触摸区 44 px；高度随屏幕变化，手机约 48dvh。
- 拖动按线路实际几何定位游标、同步地图中心，显示里程、预估抵达时间和附近采样预报。温度/雨量渐变只改善浏览，不宣称新增空间采样精度。预览游标与真实定位进度分离；关闭预览移除游标，地图仍停留在浏览位置。展开工具面板时暂时隐藏行程条，减少遮挡。
- Android 键盘弹出时为 IME 留出空间；手机压缩视口检查不能替代真机输入法验证。

涉及 navigation、journey、TerrainMap 预览接口及 app 组合；不修改手绘/标记、记录服务、离线缓存或地形算法。原 3D 控制器保持，剖面关闭。

验证：122 项逻辑测试；真实三点道路服务返回正确数量；390×844 / 360×780 的直接输入、地图选点、CDP 真实触摸排序/色带拖动、收藏恢复及 460px 视口检查。验证脚本 scripts/verify-route-stops.mjs 对搜索/天气/路线使用固定响应，真实服务验证另有本机日志。APK 签名、静态资源与构建检查见 CURRENT_STATE。

接口依据：https://valhalla.github.io/valhalla/api/route/api-reference/ （ordered locations / break）。

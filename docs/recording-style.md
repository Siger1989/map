# 实走记录开始前选样式

在「行程 → 实走记录」里，开始前即可选择六种预设颜色、自定义颜色，以及0.5–5px线宽。线条预览随选择更新；顶部蓝色「开始记录」按钮与里程并排，较矮窗口也不需要先滚到下面。

选择会保存在本机，下次打开仍沿用。记录中也可调整当前整条实走轨迹的外观；实时地图、保存到轨迹后的颜色与线宽一致，JSON轨迹备份保留样式。GPX交换只保留既有点线数据，不承诺其他地图软件识别颜色。已保存的其他轨迹和手绘默认样式不受影响。

样式使用独立设置键，与安卓原生GPS快照分开，后台记录轮询不会覆盖选择。定位采集、精度门槛、时间与海拔样本、暂停分段均不改变。

验证：239项回归、类型检查、网页构建通过。Chrome验证蓝色3px选择及刷新后恢复；应用内浏览器验证自定义紫色预览；390/360宽度无横向溢出、顶部开始按钮可见，44px高。截图`artifacts/screenshots/recording-style-panel-final.png`记录最终面板。Chrome截图接口两次超时，应用内浏览器窄屏截图存在画布缩放异常，因此窄屏主要采用DOM尺寸与交互验证，不能等同真机验收。

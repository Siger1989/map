# 山兔 0.2.221 私人 Android 测试版

- 主图「工具 → 地形打印」可框选矩形或圆形，按选区读取 NASA/NSIDC 8 米 DEM，以 1 倍真实比例生成封闭网格并导出 STL。数据缺测时会提示，下载受保护瓦片时可能需要 Earthdata 令牌。
- 生成的地形可直接加入收藏。「收藏 → 模型」支持纯黑背景、旋转缩放和切换影像图源。「底座设置」可选择平底或外围包边，并调节底厚和包边宽度。
- FBX 导出包含所选影像贴图和独立底座材质。贡嘎附近的真实 8 米 DEM 样本已通过浏览器操作和 Blender 回读，验证了必应和天地图影像以及修改后的包边底座。

Android 8.0 及以上，包名 `com.shantu.oldengine`，版本 `0.2.221-test`，构建号 228。覆盖安装前请保存记录和草稿。Android 真机操作及系统文件保存待验。HarmonyOS 6.1 原生 HAP 目前未交付。

沿用既有签名。APK 完整性、16 KiB 对齐、1,968 项网页资源、39 项私人图源和已注册天地图通过核验。TypeScript、15 项定向测试和 Android 的 FBX/STL 文件传输检查通过。

从签名 APK 提取的网页资源在 Chromium 中验证了黑底旋转、底座编辑与保存、FBX 工作线程及 7400 格式导出。

# 精确绘制、吸附与整线分析

更新：2026-09-05，0.1.2-test。网页与安卓共用本轮实现。

## 使用

打开“路线 → 手绘轨迹”。默认“精定位＋平滑画”：单指按下，准星位于手指上方约 44px，侧边 3 倍放大镜取当前地图实际画面。拖到准确位置后松手确认起点；再从旁边绿色牵引环拖动，笔尖从这个精确坐标开始画。牵引杆吸收轻微手抖，松手不补线到手指。下一笔沿上次笔尖终点续画；“另起一段”可重新定点。

“逐点连线”每次松手确认一个节点。两种方式可切换，点选线和自由笔画通过相同地理坐标连接。设置可调整杆长 24–80px、线宽 0.5–5px（默认 1.5px）、六种预设色和任意颜色，已保存线路也可改色/宽度。

绘制时双指直接移动、缩放、旋转和上下滑动调俯仰。第二根手指落下时：尚未确认的定位点取消；已有有效墨迹结束这一笔。双指变回单指后须全部抬起才能重新画，防止残留手指产生误点。手机视角控件仍可用，无需“暂停绘制”切换界面。

吸附默认开启，以屏幕距离 14px 选择附近已有节点/端点，显示绿色吸附圈，松手使用节点的精确坐标。候选包括当前草稿端点、逐点节点、已保存线路端点及新版本保留的逐点节点；旧存档仍可读，缺少节点元数据时至少支持端点。

保存时把唯一相接的端点拼接为连续线路，处理反向笔画与闭环；不会跨越空隙或擅自选择分岔。已保存线路可以“续画”，在原记录上保存，本次续画未保存前可放弃；撤销只撤本次操作。详情的“交换起终点”调整线路方向；“合并相接线路”将相接的已保存线路合为当前记录并移除参与合并的其他记录，保留当前名称和样式，仅在能够连成一条且无分岔时执行。

每条最多 6000 坐标、草稿最多 100 笔、最多保存 20 条。遇草稿笔数上限可先保存自动合并后再续画。本机存储失败保留草稿；卸载或清除数据会丢失存档。手绘线没有匹配道路，不能据此认定可通行。

## 统计和天气

草稿或已保存线路点“统计 / 天气”。详情按需出现在原小浮窗，不新增常驻大面板；手机浮窗宽上限 252px、高上限 44dvh。

- 总里程：WGS84 经纬度相邻点球面距离之和，空隙不计入，不含垂直距离。
- 海拔：与地图同源的原始 Terrarium DEM，最高/最低/起点/终点、起终净高差、累计爬升/下降及剖面。独立读取真实高程，不取夸张后的三维显示高度。常规最多 192 采样点，分段较多时保留各段端点（最高 200），界面标明最大采样间隔；不是每个地形像素的极值。爬升累加缓坡变化、抑制小于 3m 的反向波动。缺高程不按 0m；曲线断开，完整爬升/下降暂不提供。
- 沿途天气：连续线路按距离选 2–6 个点，包含起终点；点击“获取沿途天气”才请求。按北京时间出发和可调平均速度估算各点到达时间，未计休息/路况/坡度。步行4、骑行15、驾车50 km/h 是可改的估算预设，未执行手绘线道路匹配。
- 天气使用 [Open-Meteo Forecast API](https://open-meteo.com/en/docs) 多位置批量请求，7 天逐小时预报、UTC epoch，界面显示北京时间。选到达时间最近整点（最多偏离30分钟），明确列出预报时刻。降水是该时刻前一小时的总量（包含雨雪），不是整趟累计雨量；缺测保留空值，超出时间范围明确提示。整线有空隙/分岔时不猜测到达时间。
- 预报按点缓存15分钟、最多12组，调整出发时间/速度可直接重新匹配已有预报。路线改变或关闭详情取消请求，旧回复不覆盖新线路。地形瓦片按位置分组、最多3个并发、缓存24张解码图，失败可单独重试。稀疏模型预报不代表每处山谷天气；沿用原型免费非商业接口，不代表新增商用授权。

本轮沿途天气入口针对手绘线路；道路规划仍保留原距离/预计耗时/转向列表，其路段时序接口可后续交给同一分析模块。

## 模块边界

| 文件/模块 | 职责和接口 |
| --- | --- |
| `tracks/DrawingGestureBridge.ts` | MapLibre 公共触摸/鼠标事件与绘制输入仲裁；真实双指事件交给原生相机处理，不合成转发触摸、不访问私有处理器。 |
| `tracks/DrawingSession.ts` | 纯输入状态机：精确定点、确认起点、平滑牵引、吸附、手势中断。输入 DrawingInput/投影函数，输出预览/点/笔画。 |
| `tracks/TrackDrawing.tsx`, `PointMagnifier.tsx`, `precision.ts` | 非拦截式 SVG 显示、偏移准星、牵引环和放大镜布局。 |
| `map/magnifier.ts` | 在 MapLibre render 事件中复制当前 WebGL 帧，避免默认缓冲被丢弃后得到空白画面。 |
| `tracks/snapping.ts`, `draft.ts` | 节点选择、唯一端点拼接、相接记录集合；原始操作历史与保存后的完整线独立，保留撤销语义。 |
| `tracks/useManualTracks.ts`, `drawing.ts`, `style.ts` | 草稿/存档/续画/合并/样式状态及校验；兼容原有 v1 本机存档。 |
| `tracks/TrackLayer.ts`, `TrackPanel.tsx`, `TrackStyleControls.tsx`, `tracks.css` | 地图线/节点、工具与详情入口；不向地图提交单顶点 LineString。 |
| `journey/metrics.ts` | 按实际路段采样、里程与高程统计，不跨断点。 |
| `journey/elevationProvider.ts`, `weatherProvider.ts` | 独立高程/天气读取适配器，未来可替换数据源。 |
| `journey/JourneyPanel.tsx`, `journey.css` | 按需统计、剖面、时间/速度、各点天气及地图定位回调。 |
| `map/TerrainMap.tsx`, `app/page.tsx` | MapHandle 增加 toScreen/magnify，props 接入手势与节点，页面组合模块。 |

网页 `app/layout.tsx` 与安卓 `mobile/main.tsx` 导入同一 CSS；`controls/workspace.css` 缩小浮窗。安卓仅升版本代码3/0.1.2-test及UA；权限、数据网关与签名不变。

移除旧 SVG 捕获全部触摸、绘制时禁用相机控件、强制暂停才能移图的流程。保留路线规划、地图与地质/卫星/天气图层的数据逻辑。回滚本轮恢复 tracks 原实现及地图手势/放大接口，移除 journey 入口与样式，并恢复浮窗尺寸；地形与其他数据模块不需回滚。APK 回退版本需要安卓允许降级，不能当作普通覆盖更新；日常使用保留新版和存档。

# 标记窗口与事务编辑

标记模块在地图上提供摘要、编辑、详情三个层级。一级摘要只显示名称、简短位置、海拔和导航/编辑/详情；删除需确认。编辑顶部固定返回、基本/位置/资料和保存，正文内部滚动，最大高度为38dvh/320px。

## 模块入口与接口

- `modules/annotations/AnnotationWorkspace.tsx`：窗口层级、返回/保存/放弃、删除确认、键盘焦点与输入可见性。通过`AnnotationsState`及导航/分享回调连接主页面。
- `AnnotationFields.tsx`：名称与样式、坐标海拔、属性备注、位置数值输入。普通地点保留X/Y，模型显示XYZ位移及旋转；模型尺寸、地表内外与剖切显示放在基本页可展开分组。
- `editorSession.ts`：编辑快照、有效参数合并、相对位移与逐轴回正、提交冲突检查。依赖现有`data`校验、`objectTransform/math`与Three数学运算。
- `useAnnotations.ts`：保留原`guanyun.annotations.v1`存档，编辑期间给地图提供草稿，只有保存成功才写入存档并退出。其他标签页改变或删除同一标记时保留草稿并拒绝覆盖；其他标记的新改动会保留。
- `markerWorkspace.css`：窗口专用样式。资料多时内部滚动；返回和保存不随正文滚走。键盘压缩视口时正在输入的字段自动滚动到可见区域。
- `app/page.tsx`通过props连接地图、标记窗口和原有控制器。两个同级组件的React key分别以`annotation-workspace:`与`annotation-gizmo:`开头，防止地图更新时键冲突导致重复面板。

## 编辑规则

位移以打开编辑时的位置为起点，使用控制器相同局部轴方向，以米显示；某轴回正只恢复该轴零偏移，不把经纬度设为0。旋转以度显示，某轴回正只将该轴设为0°。跨180°经线使用最短偏移。

普通地点贴地，只开放X/Y；未查到真实地面海拔时仍可平面移动。模型需地面海拔或已有绝对中心高度才绘制和调整。旧地表内外/离地或埋深参数保持支持，不以假海拔代替缺失数据。

选中地点直接拖动会开启草稿。3D控制器的移动、旋转与缩放在草稿内预览，保存失败留在编辑页；返回或切换标记可保存、放弃或继续。地图手势期间收起浮窗，松手后恢复。

## 兼容与验证

未改路线、照片、定位记录、原存储键或备份格式。原`AnnotationPanel`保留新建/列表入口；新的选中对象窗口替代原混合编辑入口，没有删除业务模块或引入依赖。回滚可回退本轮标记/主页面/控制器接线提交，存档无需迁移。

9项编辑逻辑回归涵盖提交、冲突与删除、逐轴回正、旋转、跨经线及无海拔地点；全量341项通过。390×844/360×780和360×430键盘压缩视口完成浏览器检查，正式构建确认面板和控制器各一个。截图与对比见根目录`design-qa.md`。Android真机触控、GPS、性能仍待设备验证。

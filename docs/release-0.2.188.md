## Source findings and implementation

- Native transport previously disabled redirects. A real humanitarian-map sample returns a redirect and then a valid PNG; the native client stopped on the first3xx. The new client follows at most3 validated hops with one deadline/cancellation, permits HTTP→HTTPS and rejects downgrade/invalid/looping targets. Old supported initial URLs, including underscore DNS names, remain accepted. Location resolution does not append the old query to a new origin.
- A Tencent old canonical OVMAP template requests XYZ rows although that direct endpoint uses reversed rows. The original sample was HTTP200 but a971B dark-blue logo placeholder. Changing only the row and its16-tile group at the same origin produced15473B real Chengdu-area imagery. Compatibility is restricted to the exact direct `p0..p3.map.gtimg.com/sateTiles` canonical template, at request time in main/dual/offline address generation. Original files and stored fields are not rewritten; proxies, unknown paths, explicitTMS and existing reverse-row variables retain their prior contract. This is not generic provider guessing or replacement with a different source.

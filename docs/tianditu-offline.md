# 天地图图源与沿线离线下载（2026-09-22）

## 当前下载策略（2026-09-25）

按用户要求，为保护天地图额度，暂停天地图离线新建、下载和旧包继续/补齐。下载计划、网页下载器与原生桥接入口均执行同一守卫；应用发现已有天地图后台队列时暂停队列，保留已有数据。旧包仍可打开、检查完整性或删除，正常在线地图浏览不变。

所有新下载入口只准备 OpenFreeMap 免费道路/地名及勾选的地形，窗口明确提示不包含天地图或卫星影像；即使当前正在看天地图，也不会下载天地图瓦片或自动更换当前在线底图。Sentinel-2 卫星影像尚未接入离线下载。以下天地图下载接入记录为历史实现说明，不能当作当前可用功能。

## 已核实并接入

依据 [官方地图服务目录](https://lbs.tianditu.gov.cn/server/MapService.html)，本轮用本机配置的 Key 请求 GetCapabilities，并对下列七类服务分别请求一张瓦片：全部 HTTP 200、有效 PNG/JPEG、256×256，允许跨域。独立 Chrome 中实际下载并写入 Cache API 后，禁止 fetch 网络调用，七类均能按不同子域请求命中离线缓存。

| 图层 | 内容 | 服务最大级别 |
| --- | --- | --- |
| vec | 矢量底图（栅格 WMTS） | 18 |
| img | 卫星影像 | 18 |
| ter | 地形晕渲（不是高程数据） | 14 |
| cva | 矢量注记 | 19 |
| cia | 影像注记 | 18 |
| cta | 地形注记 | 18 |
| ibo | 全球境界 | 18 |

使用 `_w` Web Mercator 与当前 MapLibre 坐标体系匹配。`_c` 是同内容的另一投影，不列成重复图源。默认注记随底图匹配，允许单独选择/关闭，境界可叠加。道路透明度对天地图独立注记整层生效，已烘焙进底图的道路不能单独分离。

官方目录的三维地名 GetTiles、三维地形 swdx 指向 [三维服务文档](https://lbs.tianditu.gov.cn/docs/#/sanwei/) 和 Cesium 扩展接口，不属于 MapLibre 可直接使用的栅格 WMTS / Terrarium DEM。本版未接入这两个三维服务；三维地形仍用现有 FABDEM 局部增强与 Mapzen/SRTM，并保留原有地域覆盖及署名。额外探测的 eva/eia 返回 HTTP 418，不列为可用来源，不绕过服务限制。

## 使用

- 下载当前所见底图：图层 → 地图图源 → 下载当前地图范围。范围取打开下载窗时的地图边界，移动地图不会暗中改已选范围；要换区域需关闭后重新打开。
- 下载路线区域：选中路线 → 缓存当前路线；规划路线页面同样有“缓存当前路线”。详情与记录→离线入口仍保留。默认路线两侧各10公里，可选各5/10/20公里。按真实分段走向计算瓦片并集，包含尾段和各分支，不把断开的段之间当成道路。
- 选择概览12级、标准14级、清晰16级、精细18级；地形晕渲最高14级。当前底图、注记、可选境界一起下载；开启三维地形时同时缓存地形至12级。
- 下载后点“在收藏夹查看”，或直接打开收藏→离线地图。文件夹显示进度、大小、继续/补齐、检查完整性和移除缓存。“打开范围”恢复包的底图、注记、透明度和已下载缩放上限；高于下载级别使用已有瓦片放大，不保证无限放大仍清晰。
- 新包元数据只保存图层/坐标，不保存 Key。缓存身份不含 Key 或服务器子域，共享瓦片只下载一次；移除一个包会保留其他包引用的资源。旧开源离线包仍可读。
- 默认最多8包、单包2万资源/1GB，预估容量和剩余空间先校验。天地图最多两路并发，每次新下载后间隔350ms；授权、配额、异常瓦片或连接错误暂停，用户可联网后续传。下载需要应用留在前台。
- 可启用“地图仅使用已缓存数据”检查范围；关闭此选项解除离线缩放上限。清理应用数据会删除离线缓存。

本机按瓦片缓存，不是天地图官方整省/路线离线包接口。官方 [授权说明](https://lbs.tianditu.gov.cn/authorization/authorization.html) 有 Key 与配额管理；[服务条款](https://www.tianditu.gov.cn/about/service) 和 [版权声明](https://www.tianditu.gov.cn/about/copyright) 要求遵守用途与署名。未找到面向此功能的无限批量离线授权，不能把当前技术可缓存说成官方承诺可无限下载或再分发。保留署名，不随包分享天地图瓦片数据。

离线地图只负责地图显示；天气更新、在线搜索和实时重新规划不随底图下载，离线路网沿用独立入口。

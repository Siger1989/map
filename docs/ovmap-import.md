# OVMAP 合集适配（2026-09-29，本地预览）

入口：地图图源 → 我的图源 → 添加图源 → 导入地图文件。先预览、勾选，再保存；文件不修改，图源地址只保存本机。支持名称搜索、在线/离线筛选；我的图源按原顺序36px单行连续滚动，选中原位置高亮，不分页、不置顶。配置容量100项，重复配置默认不选。

## 当前实现

- OviO v104/type100普通zlib封装、type37/revision102图源帧；兼容压缩流之后16字节尾部。验证Adler、声明长度、最大解压量和逐条边界。
- 保留XYZ模板参数，支持子域轮询、x/y/z有限整数运算、Galileo变量。512像素父瓦片按z-1、x/2、y/2寻址并按奇偶坐标裁切。
- 中国墨卡托配置默认使用现有GCJ-02栅格校正，用户可在坐标选项调整；镜头、轨迹和标记数据不变。保存原coordType与声明tileSize；tileSize=0用256网格输出并保留原值，尚无原始格式对齐验收。
- bUseLayer控制叠加；同包引用加入栅格组合，未找到的叠加ID保留，仍可显示底图。原大/小图层ID及flags保留，未把未证实的flags当作级别掩码。
- 可选叠加注记请求/解码失败时保留底图；单层注记等待最多2.5秒。底图请求失败与用户取消不被吞掉，也不拿单独路网冒充成功底图。
- 本地Node/Vite/桌面网页瓦片通道支持HTTP与HTTPS、已核实的非标准服务端口。逐跳验证公开地址，DNS固定到已验证IP；不转发Cookie/用户请求头；12秒、8MiB上限，按图片签名确定类型，不回显含凭据的地址。

## 验证边界

真实购入合集共43条，42项是瓦片配置，另一条不是瓦片地址；5项配置完全重复，空图库默认勾选37项。42项中7项保留包内组合层；部分外部叠加层未随文件提供。单一地点/级别抽查有18项返回图片；服务可达性与购买授权不等同于格式兼容，不能承诺所有图源持续在线。

类型检查、网页构建及合成样本测试覆盖：容器损坏、尾部校验、跨帧长度、模板运算、512四象限裁切、组合层、重复导入和代理地址约束。真实文件、名称/凭据/URL未用作仓库测试样本。

扩展前版本做过实际浏览器读取、确认、搜索和切换；42项版本的视觉复核尚未完成，后续浏览器工具被安全策略拦截。预览服务停止后已重启，HTTP200确认不等于屏幕截图确认。此前截图只代表当时2项版本。

**Android原生传输尚未完成，本轮没有生成APK。** 当前HTTP与跨域瓦片代理运行在本机网页服务；Android不具备此Node服务，不能直接把网页构建当作可交付手机功能。后续需原生适配与设备验证，再提升版本、构建和发布。不得以放宽WebView全局混合内容作为修复。

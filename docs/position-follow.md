# 0.2.3-test：实走记录与地图位置跟随

用户在 0.2.2 记录轨迹时，GPS 点会保存，但视角不会随行移动。原因是记录模块未向相机传递新位置；原定位按钮只居中一次。本版接通持续跟随，同时让地图位置点和道路行程进度使用记录点。

## 使用

1. “行程 → 实走记录 → 开始记录”或“继续记录”：成功进入记录状态后自动开启位置跟随，收到有效位置时移动地图。
2. 右侧定位图标显示“跟随”。视角保留当前缩放、俯仰与方向；原绿色模型/圆环控制器仍默认显示，可继续调整。位置跟随和“跟随手机方向”是独立设置，位置跟随不会强制旋转地图。
3. 拖动地图后显示“浏览”，后续记录点继续保存，视角不会被拉回。点击该定位按钮恢复跟随。跟随时再次点击也可暂停相机跟随，记录继续。
4. 查看全程、定位到其他地点或拖动左侧行程条会暂停跟随。恢复跟随后退出行程预览；地图选点、手绘编辑或移动模型期间禁用跟随，结束编辑后可点按钮恢复。
5. 暂停或结束记录会关闭自动跟随。不在记录时，点击定位按钮也能开启普通位置跟随；“更多地图操作 → 停定位”停止普通持续定位，不结束实走记录。
6. 按钮显示“等待”时，相机等待有效新位置或地图加载，不使用过旧数据强行移动。关闭相机跟随不会删除轨迹。

## 数据与性能边界

- 记录期间直接使用已经通过过滤的轨迹点；安卓从原生记录快照读取，浏览器从记录状态读取，不额外开启相机专用 GPS 请求。相机更新频率受 GPS、记录采样和原生快照读取周期约 1.5 秒影响，不保证逐帧定位。
- 相机只接受精度不超过 80 米、最近 20 秒且时间有效的位置。记录本身还保留距离/时间采样与异常跳点过滤，停留时可能等待下一次记录点；不通过插值伪造 GPS 行走。
- 重复快照不重复启动动画。隐藏页面不移动相机，回到前台后读取最新有效位置；地图尚未就绪时重试。跟随平移避免重复同步整条轨迹，天气区域仍按原距离阈值更新。
- 原生记录服务、存档格式、离线缓存与地形算法未修改；原 3D 控制器保留，地形裁切剖面仍停用。

## 验证与安装

专项测试覆盖记录首点、继续记录的空分段、过旧/未来/低精度点。浏览器验证使用可控 GPS 和模拟 Android 记录桥，覆盖自动跟随、连续移动、触摸移图暂停、一键恢复、重复快照、记录暂停/继续/结束、普通定位、保留相机角度与缩放，以及高频罗盘与位置同时跟随。

浏览器在 390×844 和 360×780 检查布局及原控制器可见性；模拟原生桥不等于 Android 真机验证。手机上的真实 GPS、触控手感、锁屏定位、厂商省电策略与耗电仍需设备实测。最终构建与发布结果见 [当前状态](../CURRENT_STATE.md)。

## 根因与改动

- 实测外窗 rgba(24,32,31,.64)，图源/参数/X/说明项却被共享皮肤刷成实色 #252e2b，形成与地图透入的灰绿面板割裂的深色块。参数展开色还被广域按钮规则覆盖。

- `outdoorSurfaces.css` 修正共享普通按钮底色及图层行例外；图源和说明透明、参数收起透明、展开使用柔和底及强调文字。`mapPanelHeader.css` 全部同类X使用柔和底，暖黄图标/36px命中不变；二级返回保留独立底板及父级提示。`mapSwitch.css` 共享开启色柔化，保持位置+色彩双重状态。
- `layerParameters.css` 展开底色改为共享柔和令牌。几何、功能、业务语义色、图源、定位、记录与存储保持原实现。

# 第三人称行程在影像限流时继续播放

0.2.215 的行程依赖卫星影像和高程同时可用。天地图返回 HTTP 429 时，高细节和父级影像都可能缺失，即使已有可用高程也无法进入播放。天气动画还会在起播前等待较慢的预报请求。

本轮把高程与影像就绪分开。路线、箭头与镜头仍使用同一份真实高程。有真实影像时优先使用相应影像，其次使用覆盖同一地区的低层级影像。没有影像时根据真实高程绘出明确标注的地形预览。摄像机及当前路线缺少真实高程时继续提示缺测。远景地形暂缺时可以先显示已准备好的路段。

行程只对本功能的影像请求设置短等待窗口。天地图处于限流冷却时仍读现有缓存，未命中即转到地形预览。保留已注册天地图、普通地图与既有离线包的读图规则。可点「重试加载」重新尝试得到影像。

第三人称模拟内的天气动画和沿途天气入口暂时移除。播放和录像不再等待天气。保留主图实时天气及其他流程的既有天气功能，用户之前的设置没有被清空。

## 行程继承主图图源与预览切换

0.2.216 的三维场景自行构造天地图影像地址，行程入口也未传入主图选择。因此主图已经使用「必应卫星图（19级）」时，行程依旧请求天地图，遇到 429 就转到地形预览。当前源码从主图传入实际来源。独立行程预览会先读取本机图源和主图偏好，再以同样的规则确定初始图源。

顶部「图源」可切换已导入的在线栅格、已注册的天地图、公共栅格或仅地形。切换取消旧请求并清除旧纹理，保留真实高程、时间与里程，播放中切换会在新路段可绘制后继续。选择只在本次行程中生效。缺少细节时使用同图源低级别影像，缺少影像时展示地形。MBTiles、地理配准图片和矢量样式暂无行程贴图支持，继承这类选择时会提示地形预览。三维视野仍按镜头需要选择瓦片层级，「19级」沿用用户原有的图源名称。

私人网页使用「必应卫星图（19级）」播放青城山 8.25 公里示例，15 秒回放从起点推进至 100%，约 3.30 秒开始推进，18.45 秒完成（含预载）。收到 126 次必应成功响应，全程天地图和天气请求均为 0，终点显示四块 z17 细节瓦片。切换至已注册天地图影像时，实网返回 429 并显示真实地形。定向测试 28 项、TypeScript 与隔离私人网页构建均通过。手机真机待验，未生成新安装包。

# 静止闪烁调查与 UI 参考（2026-09-07）

## 本轮结论

用户补充：地图不动时也闪。当前只确认并修复开发预览加载错误，尚未确认手机 APK 静止闪烁根因，不宣称修复闪烁。本轮未重做 UI、未更换图源、未生成 APK。

## 确认事实和最小修复

- Git main 从 77b6354 开始，pull --ff-only 无新提交；本机缺少公司新增的 geotiff/jsqr/proj4/sql.js 等依赖，已按现有 package.json 安装。锁文件保持公司版本。
- 旧开发日志显示从 public/terrain/repairs-v1/coverage.json 直接导入导致 Vite 报错，GET / 为 HTTP 500。改为模块内 repair-coverage.json；生成脚本同步输出模块清单和原 Android 资产清单，测试断言两份内容一致。
- 该修复恢复开发预览；地形像素、覆盖范围、Android 资产路径/签名/存档、路线和 UI 保持。开发 HMR/HTTP 500 与 APK 运行时闪烁是不同问题。
- 验证 PASS：5/5 地形测试、npx tsc --noEmit、npm run build；旧进程重新启动后页面 HTTP 200，地图就绪。
- 采样：世界地图 8 帧仅覆盖约 0.18 秒，不能用作长期无闪烁证明。倾斜山体两帧相隔约 100.5 秒，像素完全一致；中间没有连续录像，不能排除短暂闪烁。当前云雨/卫星/剖面关闭、未定位跟随；不能外推到用户开启其他功能的 APK。

## 下一轮排查顺序（尚未证实的候选原因）

1. 手机开启位置跟随时，useFollowPosition 以时间戳+坐标去重。同坐标的新时间戳仍会进入 650 ms easeTo；应确认静止 GPS 抖动/方向传感器是否不断驱动镜头，再决定增加静止范围或角度滤波。不能通过停止实走记录掩盖问题。
2. WeatherLayer 的降雨存在约 33 ms 重绘计时器，天气播放每 1600 ms 换时次；TerrainMap 的统一 sync 同时同步多个无关图层。应测每一层的重绘、GPU/内存，再拆分必要更新，确认隐藏动画不占用渲染。
3. syncSatellite 刷新时先删除旧卫星 layer/source，随后检测新日期和覆盖。此处存在明确的旧图消失窗口，建议保留旧图直至新图可用，并在同日期时避免重建；主要影响最新云况模式，不能解释本轮关闭卫星的静止场景。
4. Three.js 图层共用地图 WebGL；现有三个活动自定义层均设置 autoClear=false/resetState，不能仅凭共用上下文就断言它们清空底图。需要在受影响设备检查 contextlost/contextrestored、深度冲突和帧间变化。
5. 避免把历史 MapLibre 缩放问题直接认定为当前版本根因。官方示例：https://maplibre.org/maplibre-gl-js/docs/examples/adding-3d-models-using-threejs-on-terrain/ 。

下一次手机复现需记录实际 APK 版本、是否跟随/罗盘/天气播放、图层组合及闪的是整张地图还是局部文字/山体。当前没有连接手机，不将浏览器采样说成真机验收。

## 用户可选的真实产品参考

这些是原产品官方宣传图/帮助页，属于布局参考，不是山兔已经实现的效果，也不代表其地图或服务可直接免费接入。

### A：Organic Maps——简洁、地图优先
- 官方：https://organicmaps.app/
- 官方截图：https://organicmaps.app/images/screenshots/hiking.jpg
- 建议借鉴：浅色地形图、少量悬浮圆按钮、底部紧凑距离/时间/海拔卡片。最符合节约空间；山兔专业功能仍需按任务打开。

### B：Komoot——路线规划和底部抽屉（优先参考）
- 官方近期设计：https://www.komoot.com/whats-new
- 路线流程：https://support.komoot.com/hc/en-us/articles/10206792140826-Plan-routes-in-the-app
- 官方安卓截图：https://images.ctfassets.net/ich3of0ase5q/6QfX3vcEgyqNIVA1kahY2L/7376dd06c47b8ee6bc948604f828d885/android_planner_revamp.png?fm=avif&q=60&w=1856
- 建议借鉴：底部直接输入起终点，非编辑状态收起成数据卡片，地图上编号途经点；路线、海拔信息分层显示。

### C：Gaia GPS——专业户外工作台
- 官方界面说明：https://help.gaiagps.com/hc/en-us/articles/4409332168727-Using-the-Main-Map-on-Android
- 官方标注截图：https://help.gaiagps.com/hc/article_attachments/40398927698455
- 建议借鉴：记录状态条、跟随/3D/图层清晰分工、一键全屏。更接近山兔的专业工具，但常驻按钮密度不宜全盘照搬。

补充：MapOut 官方 https://mapout.app/ ，手绘路线参考 https://mapout.app/image/TourDraw.jpg 。其配色/细等高线/直接画线值得参考，宣传图不是完整手机控件布局。

推荐组合：A 的主地图密度 + B 的路线抽屉 + C 的专业图层组织，保留山兔原绿色 3D 控制器。等待用户选择后再做整体 UI。

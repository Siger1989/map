# 节点路线网络与收藏文件夹

2026-09-08更新，已包含在[0.2.12 APK](release-0.2.12.md)中；0.2.11历史包不包含本次改动。

## 使用

- 每次打开首页显示精细卫星影像；仍能手动切换图源，已添加的自定义图源保留。默认只作用于首页，不改变路线/剖面导出图的独立底图设置。
- 在画线列表点“调整节点”，或直接点选地图节点，显示“＋节点 / −节点 / 拉分叉 / 连接”。加号在所选节点后一段插入中点，可拖动调整；在线段上点选临时绿点后按加号，可在该处插入。
- 减号删除选中节点，前后相邻点直接连接，支持撤销。每段至少保留两个节点。实走时间点受保护，可先复制为手绘。
- 选中节点后点“拉分叉”，在地图上逐点绘制，完成后保存到同一线路，主线与分叉共享该节点。
- “连接”中选目标路线和节点，生成一条组合路线。重合节点直接相接，否则明确增加一段直线；两条原线及关联照片/标记保留。连接直线不代表已核实可通行。
- 导航准备窗口显示起终点，支持交换方向和选择分叉端点，里程随选择更新。道路规划反向时重新规划，不倒放旧转向指令；手绘使用已有线形，闭环保留完整几何。
- 手绘导航从最近相连路段接入，保持所选终点。可靠定位表明走入另一分叉时，沿实际行进方向切换，显示“已切换相连分叉 · 终点不变”。只匹配已连接且能到达终点的网络，不跳到附近无关收藏；只有画面交叉、没有共同节点不视为相连。定位不准、过期、异常跳点不触发切换，路口附近按误差范围保留当前方向，避免抖动。
- 收藏默认显示原有文件夹和管理入口，分类无需迁移；标签与条目按分类颜色铺底，顶部固定“关闭 ×”。“全部收藏 · 省市分类”保留所有对象的省市筛选和批量功能，也可返回文件夹或直接关闭。

## 实现与兼容

`tracks/nodeOperations`提供纯节点插入、删除和连接；`TrackNodeTools`和`useManualTracks`接入原存档、撤销与绘制草稿。分叉复用多段segments，无新存档键。连接生成新对象，避免破坏来源对象的照片/标记引用。

`guidance/network`按真实共同顶点建立邻接关系，最近路段匹配和终点反向最短路径分开计算；实际行进分叉能继续到终点时优先沿该方向。缓存图与终点树，使用稀疏堆搜索。`networkSession`先复用定位质量/速度校验再决定切换，保留实际已走距离；`direction`处理方向及闭环。可选trackNetwork有格式和数量校验，旧无此字段的规划收藏保持原逻辑。

未改动原生GPS、原始记录样本、照片存储、服务授权、签名、包名和版本号。网页与Android网页入口共用功能。

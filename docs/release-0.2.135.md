## 修改及原因

- 19级可选但开始按钮不可点，原因是路线两侧各4km在高级别超过旧2万请求/1GiB预算。导入图源路线缓存改为最多25万项/8GiB，仍检查真实可用存储，不自动缩窄范围或降低级别。级别遵从图源元数据：名字含“19级”而maxzoom实际18的源仍显示18为上限；Bing卫星混合图元数据支持19。
- 用Worker估算和生成大任务；超过1000项的URL清单放IndexedDB，小索引保留进度，兼容已有缓存包。
- 用户要求最高速，导入图源最终默认8路，Android同主机及全局传输上限均8，连接复用、已有瓦片复用、每500ms合并进度，预算写入前预留。401/403/429暂停并保留进度，不反复请求。
- 新建Android任务通过v2分块清单桥接进入dataSync前台服务，通知有暂停/取消，状态和瓦片原子写入。先启动前台通知再在工作线程读大清单，防止启动超时。8线程请求/写入检查任务代际，停止旧任务不能污染新任务。系统后台时限结束则保留进度并暂停。
- 缓存地图通过仅缓存端点读取原生瓦片，未命中不联网。独立删除保留其他包共用瓦片及原路线。已有部分下载的旧网页包保持原存储继续前台下载；新建包使用原生后台服务。

涉及 `modules/outdoor/` 缓存规划、清单、下载、列表和读取，Android OfflineStore/OfflineDownloadService/NativeBridge/MapTileProxy/LocalGateway，以及相应测试。不改导航/GPS/原路线数据或图源凭据。

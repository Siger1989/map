## 本次修改

- 测量使用第三版紧凑布局；A/B 可拖动或选已有地点、模型标记，显示坐标、自动地面海拔、水平面夹角、朝向和高差。
- 地点和模型缩小时显示小标记；路线规划等任务窗口在拖动地图时保留。
- 道路外起终点/途经点以虚线接入附近道路；接入距离、估算时间及实际途经点纳入导航。
- 名称、备注、属性等输入增加统一半透明小字号联想。
- 修复测试版相机 Provider 打包地址错误，选点时照片缩略图不再抢走标记点击。

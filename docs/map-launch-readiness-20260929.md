# 上线图源准备交接（2026-09-29）

## 结论与适用范围

当前仓库仍是带原型图源的天气地图应用，不能仅凭“已经配置服务 Key”“接口能返回瓦片”或“数据可公开访问”就认定可以面向目标市场收费上线。数据集许可、地图服务/API 使用条款、瓦片缓存与再分发权限、署名要求、服务额度，以及应用在销售地区的地图与测绘合规，是不同问题，需要分别核实。

本交接记录代码实际接入情况和目前已核验的官方材料，供确定上线方案。它不构成法律意见，也不替代服务商书面授权或目标市场的专业合规审查。审计没有读取或写入真实 Key。

## 缓存、离线与再分发边界

现有离线地图包的主要目标是 OpenFreeMap 地图资源和本应用的 DEM 瓦片，保存样式/瓦片/字形与对应显示设置，见 `modules/outdoor/offline.ts`。运行时先查本应用缓存；“仅使用已缓存数据”模式遇到缺失资源会提示联网补齐，不会把所有在线功能自动变成离线功能，见 `modules/outdoor/tileCache.ts`。

项目文档说明：天气、道路叠加和未缓存的三维高程仍需网络；网页端需先打开应用并加载读取模块后才能断网继续使用。天地图离线下载目前暂停以保护账号额度，既有天地图离线包仍可查看或删除，见 `modules/outdoor/offlineDownloadPolicy.ts`。因此当前不能承诺整款应用全离线，也不能把能写入浏览器/设备缓存等同于获得批量缓存或再分发权。每个数据商都要单独确认：应用内临时缓存、用户离线下载、服务端缓存、安装包内置数据、向用户再次分发数据，各自是否被允许以及保留时长和署名要求。

## 国内地图与资质事项

应用面向中国境内提供地图服务时，地图内容来源、地图审核/审图要求、互联网地图服务资质或其他适用义务，需要结合实际功能、运营主体和发布方式，由熟悉测绘与地图管理要求的专业人士确认。仓库代码已经集成天地图接口或具备一个有效 Key，不能据此断言单个 Key 足以覆盖所有地图展示、加工、缓存、离线下载、收费分发或经营资质要求。

本轮给出的法规页面用于交由专业人士判断适用条款：[《地图管理条例》官方页面](https://www.gov.cn/zhengce/zhengceku/2015-12/14/content_10403.htm)。高德官方平台有独立的使用条款，也不能从注册或拿到 Key 推定所有用途都已获许可：[高德开放平台使用条款](https://developer.amap.com/pages/terms/)。天地图官方条款页本轮无法稳定读取，相关授权状态保持“待核实”，不引用为已证实的商用许可。

## Google 图源状态

本项目当前审计到的底图接线和项目数据源文档没有交付 Google 地图瓦片接入方案。Google 不应被当作当前已交付服务，也不应默认免费或默认允许缓存、离线使用、代理转发及再分发。若以后考虑接入，需先按目标产品、销售地区、平台和缓存方式核对 Google 当前产品条款、价格和许可，再决定是否实现；本交接不授权购买、注册或接入。

## 最小下一步

1. 先确定首发地区/国家、应用是否收费或含广告/订阅、预计用户和流量，以及是否必须支持离线地图。
2. 按上表只对拟保留的来源取得当前官方书面条款或服务商确认，分别记录商业用途、署名、缓存、离线、再分发、额度和 SLA；保留页面版本/日期和授权凭证位置，但不要把密钥提交进仓库。
3. 对国内发布安排专业地图/测绘合规评估，并确认图层、数据处理和分发形态需要履行的具体义务。
4. 根据核验结果再做最小图源决定：保留并取得适用授权、购买合适服务，或替换/关闭有冲突的层。当前阶段不擅自联系供应商、不购买服务、不改换图源，也不宣称已经具备商业上线条件。

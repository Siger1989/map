# 沿线浏览缓存与主动下载

0.2.87 起，自动缓存仅保存画线路线附近实际浏览取得的瓦片，不再停稳补图，也不会自动下载整条路线。没有路线时不新增浏览缓存；已有缓存仍可读取。默认两侧各1公里，可选500米或2公里。

缓存范围取已保存路线和当前画线草稿的合并范围，不依赖选中状态。分段之间不会虚连；隐藏/取消选择路线不视为删除。至少形成一段线后才有沿线范围。瓦片按整张保存，边缘覆盖会略超出所选距离。

删除路线时，清理这条路线附近、其他现存路线或草稿不再需要的自动缓存；共用瓦片保留。清空草稿同样清理独占部分；保存草稿为正式路线时保留对应瓦片。旧版本没有位置标记的共享资源不自动猜测归属，可在“清理自动缓存”中清理。

入口：记录工具 → 离线地图。可关闭新增自动缓存、调整距离、查看占用、单独清理自动缓存。清理只影响独立的浏览缓存库，不删除轨迹、照片、图源配置和主动下载的离线包。容量上限256MiB/4096项，系统配额可能更低。

浏览缓存不产生额外下载请求，但第一次查看、放大到未缓存级别、换图源或缓存过期时，地图正常显示仍需要向服务方请求瓦片。是否计费、计额度或限速取决于图源服务；导入或购买图源不代表无限额。缓存命中时复用本机内容；“仅缓存”模式不联网补图。

## 主动下载

只支持已经导入到“我的图源”的在线图源，只下载路线附近。先选择导入图源和路线，再打开“下载沿线地图”，手动选择两侧范围和最高级别，查看预计请求数量后点击下载。没有路线、内置图源、已在本机的MBTiles/图片不能开始新的沿线下载。

XYZ/TMS和受支持的OVMAP栅格图源按原始URL保存瓦片；离线查看沿用原图源，不替换为开源底图。天地图批量下载继续暂停，OSM公共标准瓦片不开放批量下载。第三方授权或配额错误应停止下载，已取得内容保留。

主动包和浏览缓存分开管理。主动包不参加256MiB自动淘汰，也不随路线删除而删除；可在离线包列表中检查、继续或移除。旧版本内置图源离线包仍可打开和删除，新主动下载限定导入图源。导入图源下载使用前台任务，请保持应用打开；不承诺切后台继续。

缓存过某处不代表所有图源、区域和缩放级别均已离线可用。出发前用“仅缓存”或飞行模式逐段检查路线和所需缩放级别。天气、搜索和原生定位记录不属于本轮改动。

实现入口：browseCache负责读写/淘汰/选择性清理，browseCacheRoute负责路线范围和删除生命周期，browseTileSources解析导入图源模板坐标；tileCache/tileTransport接入实际请求。主动下载实现见importedRouteDownload和OfflineDownload。浏览器/Android实际性能和磁盘行为需设备验收。

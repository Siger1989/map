# 自动地图缓存与路线附近优先

0.2.86 起，地图浏览中成功下载的影像、地形和相关地图资源会自动保存在本机。再次查看相同图源/级别时优先读取缓存；缓存写入失败不阻止显示在线地图。

入口：记录工具 → 离线地图 → 自动地图缓存。可关闭新增自动缓存、选择路线两侧500米/1公里/2公里范围、查看自动缓存占用并清理。清理前有确认，只影响自动缓存，不删除轨迹、照片、图源配置或主动下载的离线包。

默认开启，空间上限256MiB、最多4096项；满额优先移除非当前路线附近的旧瓦片，然后才淘汰沿线旧瓦片。选择已存路线后以该路线为优先；未选中时采用当前规划路线。多段轨迹不跨缺口连线。

当前地图加载完成并停稳1.5秒后，以单请求逐步补充视野附近的沿线影像/地形瓦片，只处理当前级别与图源支持的级别。每轮最多24次请求、每个来源最多12个候选，候选限定在视野中心附近25km加所选缓冲范围内。移动、切后台、换图源、离线/仅缓存模式、关闭自动缓存或清理时取消补图；省流/2G连接不主动补图。清理后在下一次移动前不自动补回。

沿线预取延续现有天地图批量下载暂停规则；天地图仍可缓存实际浏览取得的瓦片。OSM公共标准瓦片不主动预取。双图中两幅图的实际浏览都可缓存，空闲补图只由主图执行，避免两幅图争抢网络。

缓存按原请求区分图源、坐标、级别及版本/日期参数。自动缓存独立于原有离线包数据库和下载队列；不会扫描或删除其他应用缓存。缓存容量是应用目标上限，系统存储配额可能更小，未获得存储权限/空间时可继续在线查看。

看过某处只表示缓存过当时实际请求的级别，不表示整条路线/全部清晰度均已离线可用。完整出行准备仍使用明确的区域/沿线下载并做飞行模式检查。天气预报接口不进入本次地图瓦片缓存；时效图层按日期URL和缓存有效期更新。

实现入口：browseCache负责独立存储与淘汰，routeCachePolicy负责走廊判定，RouteCacheWarmup负责低优先级补图；tileCache、tileTransport接入实际请求。原生包复用WebView IndexedDB，原生定位记录、签名与包名保持兼容。

验证结果见CURRENT_STATE及对应发行说明；浏览器显示与Android磁盘配额/后台回收需要真机检查，逻辑测试不能代替设备验收。

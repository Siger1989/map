# 对象旋转数值与归正

2026-09-07。剖面或标记模型进入对象操作状态后，左下角显示 X / Y / Z 旋转角度（度），保留一位小数。拖动圆环时读数更新；也可输入 -360 至 360 范围的数值，回车或离开输入框提交。

- 输入无效、留空或超出范围时恢复原值；Esc 取消该输入。提交一次形成一条既有撤销记录。
- “归正”：矩形剖面恢复竖直朝北，宽度沿东西方向；模型恢复三个世界轴角度为零。位置、海拔、尺寸保持不变，归正也可撤销。
- “回到对象”只调整地图镜头；“归正”调整对象朝向，两者用途不同。
- 三轴采用局部地图坐标中的 ZYX 欧拉角，与剖面详情的方向、倾角、面内转角不是逐项相同的表示。竖直朝北的剖面读数为 X=90°、Y=0°、Z=0°。接近欧拉角奇异位置时可能出现等价读数变化，内部仍保存四元数姿态转换后的原有剖面参数。

实现位于 `modules/objectTransform/{ObjectGizmo.tsx,math.ts,objectTransform.css}`，沿用既有 onBegin/onCommit、剖面历史和模型撤销流程。临时拖动读数不单独保存，不改变存储格式。

验证：数学测试覆盖数值旋转后的平面几何一致性、无效值、归正后的方位/倾角和位置尺寸保持；219 项全量测试、TypeScript、网页/安卓网页构建通过。浏览器测试 X 从107.5改为45.5并单次撤销，归正到90/0/0再撤销，无效500不提交，测试结束恢复原姿态。

390/360 DOM 布局不溢出；360下操作栏约228×147px，与绿色相机水平间隔约6px。手机截图工具缩放异常仍未解决，真机触控与GPU模糊开销待验收；未生成新APK。

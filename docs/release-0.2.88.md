# 山兔0.2.88-test：移除地图缓存功能

根据使用反馈，移除自动浏览缓存、路线附近主动下载、地图区域选取下载、仅缓存地图、缓存容量/清理和收藏中的离线地图包入口。取消保存/删除路线时的缓存扫描与清理，也取消离线下载状态轮询。

普通地图、坐标校正、组合图源、导航小图和分享截图走正常联网请求，不再先查应用自建IndexedDB、CacheStorage或Android离线包文件。旧“仅缓存”开关与离线包最大级别不再阻断联网或限制图源细节。保留正常浏览器/系统HTTP缓存与渲染内存复用，不承诺特定网络下提速幅度。

Android不再注册地图下载服务，也不允许旧页面启动下载；地图请求不再查询旧离线文件。旧缓存数据不自动清空。用户路线、照片、导入图源、MBTiles/影像文件、离线路网、内置地形和定位记录功能保留；本轮不修复此前轨迹中断问题。

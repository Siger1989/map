## 已实现及主审验证

- 桌面版以单个 `EXE/山兔桌面.exe` 运行文件交付，直接复制即可启动；依赖可用的 Microsoft Edge WebView2 Runtime。PNG 渲染还依赖系统安装 Microsoft Edge 或 Google Chrome。具体平台限制见 `EXE/README.txt`。
- 手机和桌面可使用完整工程 JSON 往返迁移。主审已在真实 UI 完成手机→PC→手机：发送端相同 ID 覆盖接收端对应对象，接收端独有对象保留；验证范围包括照片、图源、CAD 原文件、行业 Excel/项目和设置。该流程是完整工程存档，不等同旧 v1 备份格式；旧 v1 的兼容导入单独保留。
- CAD 模块可导入常见 DWG / ASCII DXF 图元作为地图参考，保留原始文件、图层和工程对象信息；地图叠加使用 WGS84 几何。已有显式 CRS 可识别，缺失或未知时要求手动选择。北京54、西安80参数未知时拒绝擅自跨基准转换；2D投影保留原Z值，不执行垂直基准改正。模块限制及许可见 `modules/cad/README.md`。
- 路线草稿实测：地图点选3次形成含5个顶点的草稿，无GPS输入，使用已采样DEM高程，在390×857进入分享并选择GK105导出工程JSON和GPX；GPX有5个高程值、无时间戳。两手机尺寸的记录隐藏/解锁另行核验。
- PC顶部平移控制器和底部视角控件均居中；平移44×44px，松开/失焦/切到行业页即停止，画线时可平移且不追加点，锁定不移动。PC取消新记录入口，保留已有轨迹查看；同窗地图/行业页切换保留草稿和生图结果，F11全屏。
- 主图与双图准星增加4px实心点，pointer-events:none；手机记录能力保留。天地图搜索请求扩至300条、Photon20条，按当前地图中心距离排序并显示距离/行政区，移动地图只重排现有结果，不反复请求；牛背山天地图实际返回267条。
- 工程坐标支持WGS84/CGCS2000、高斯3/6度、UTM、北京54/西安80及自定义定义；项目坐标用于工程交换，内部地图几何仍WGS84。工程JSON/CSV可选目标坐标系，GPX/KML使用标准WGS84。CAD已识别的完整WKT保留≤8192字符，超限或缺失提示手动选择；不按数字大小猜测源坐标。
- 隐藏UI本轮适用例外：录制中或暂停状态即使没有控制台，也允许隐藏UI，不因此暂停录制；存在阻塞面板任务或处于锁定状态时，解锁入口必须可达。既有状态规则仍见 `AGENTS.md` 和 UI质量门禁。

# 山兔 0.2.222 私人 Android 测试版

- 地形打印选区创建后可以移动和调整。拖中心移动，矩形拖边或角，圆形拖外圈控制点改半径。选区外可拖动地图。
- 当选区超过原 8 米采样预算时，从同一 DEM 自动抽稀，保持实际宽深和 1 倍真实高差。小范围优先保留 8 米采样。单边最多 64 公里，实际覆盖和下载预算仍受 NASA 数据限制。
- 面板显示实际地面尺寸。矩形以模型长边统一缩放，纵向拉长时可保持预期打印尺寸。

Android 8.0 及以上，包名 `com.shantu.oldengine`，版本 `0.2.222-test`，构建号 229。覆盖安装前请保存记录和草稿。Android 真机触感及受保护 DEM 在线下载待验，HarmonyOS 6.1 原生 HAP 目前未交付。

浏览器三种手机尺寸均已实测。18 项地形相关检查、32 项原生 UI 区域路由与投影检查通过。

# 双图标记编辑器与删除残留修复

用户提供 0.2.91 手机截图：完整地点菜单仍过大，添加自定义条目看似无效，删除后留下空色框。本轮仅修复双图编辑器宿主与布局；PinEditor / useAnnotations 原存储及自动保存逻辑经实际 React 交互回归未发现问题，保持其原行为与用户存档。二维码与图源网络问题没有在本轮修改。

根因：MapComparisonHost 判断 markerEditor 回调存在后总创建 slot，即使当前选中标记消失、回调返回空节点，外壳仍留在地图上。现在先求实际工作区节点，非空才渲染宿主。原高度上限少扣 32px 图源栏，内部百分比高度以不同包含块求值，新增属性会挤到图源栏/裁切区；新的高度按视口可用空间计算，正文及条目各自可收缩/滚动，至少保留一行属性。原布局绑定 outdoor 皮肤，修正为所有皮肤的双图宿主规则，保留颜色个性化；该手机具体保存皮肤未经读取，不宣称其实际根因已完全确认。

文件：`modules/mapComparison/MapComparisonHost.tsx`、`mapComparison.css`；定向回归 `tests/map-comparison.test.mjs`、`tests/annotation-editor.test.mjs`。未删除功能或改变标记数据格式。地点菜单仍包含坐标、海拔、图案、颜色、照片、分享及属性；宽232px/左8px/外圆角8px，输入16px，内部控件沿用共享4px规则。

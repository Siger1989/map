## 施工与根因

- 搜索历史旧44px控件和子标题造成过厚，且清空/关闭/删除不同内距：默认行32px、子标题28px、右列36px统一，窗口按内容计算高度。尺寸控制仍可调，保留用户既有宽度/内距/间距草稿。
- 路线模式与端点条圆角、下一步提示和“我的位置”内距统一；剖面新建28px与关闭36px分开，标题右侧5px间隔，行操作28px。
- 输入焦点的模块描边和收藏父容器描边不一致：共享有效文本字段使用路线式24%强调色混合底色，边框透明、无装饰焦点线；错误字段和按钮键盘焦点不覆盖。收藏/标记实际焦点检查通过。
- 记录按钮原先额外减3px，其他按钮使用可调圆角，输入又固定8px：现在普通按钮、输入、历史条目共用内部圆角。按用户记录参考设10px；主预览外框24px保留。savedMaterialPreset仅三处内部半径20→10，全部颜色、RGB小数、透明度、阴影等原值保留。旧radiusInput草稿忽略独立值但不删除存档；控制器说明/复制值同步。
- 收藏原渐变在实色条目背后，不能消除条目边线；现内容容器左右8px透明羽化，滚动视口上下8/12px渐隐和12px圆角。两层分开避免右侧羽化被滚动条占用。文字不做blur，列表仍可滚动；增加上下留白8/12px。
- 收藏选中用全行弱强调色柔光，保留分类色；修复workbenchLayout旧硬左线的高优先级覆盖。拖放插入提示优先，不被柔光伪元素覆盖。
- 通用滚动条使用6px槽、半透明中性灰滑块、透明轨道和圆角，无两端箭头；不再借用黄色强调/文字色。图层、收藏、搜索/主双图同源CSS。
- 右栏旧canAddCenterMarker按panel状态卸载入口：现普通面板不影响按钮挂载。真实编辑任务只禁用动作、仍占原位置；起点选点索引0使用显式null判断。记录/路线/工具/图层及选点状态实测7入口、50×326px。
- 定位提示改浅色，权限/IP文案缩为“未授权定位 · IP估计，可能偏离”，保留运动朝向限制提示；可自然换行但不截断。
- 路线拖动行抬起缩放、阴影与指针位移，行间插入提示，释放回落，减少动态效果时取消缩放过渡。目标索引按移除源行后的列表算，修复末尾偏一和重复提示；拖动中间点到末尾、末尾到开头实际排序正确。动画手感尚需用户观察，不能等同真机通过。

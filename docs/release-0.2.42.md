# 山兔 0.2.42 测试版

- Android：`Shantu-0.2.42-test-standalone.apk`，versionCode 49，Android 8.0及以上；沿用山兔独立测试版包名和签名，可覆盖同系列安装。下载APK后在手机文件管理器打开安装，勿为绕过签名错误卸载旧版。
- 当前源码重新构建：导航与拉力路书布局、路线编辑退出/保存、选点层级、进度带与图例、底部海拔、视角控制、收藏与框选结果窗口、图源列表展开调整。
- 天地图矢量、影像及中文注记接入。浏览器应用Key由本机构建配置提供，未提交源代码；客户端请求会携带该应用Key。四种图层瓦片请求验证成功。
- 保留既有路线、记录、收藏存储键与原始轨迹。离线仍是行程范围道路/地名/地形缓存，以及MBTiles/GeoTIFF导入；尚无省市/框选地区下载，天地图影像未加入离线包。

## 本轮功能

- 绘线/编辑双指平移改密度相关门槛，保留连续小步输入，兼容捏合、旋转与抬指；浏览手势继续原控制器规则。
- 编辑节点真实接入道路/河流坐标吸附，提供可见反馈，节点吸附仍优先。修复Host 500ms节流丢失后续更新，避免道路开关看似选中但geometry revision一直过期。
- 统一颜色选择器，常用色点选或有效HEX输入后应用并关闭，取消不改颜色；导航线宽单一焦点框。
- 沿线缓存按真实Java链路处理HTTP缺瓦片、Bing no-tile、网络错误；只对实际落盘内容计数，不伪报完成。
- 新增跨App基础悬浮导航：深绿底/荧绿路线，指北与运动朝上，真实活动路线与系统GPS，原生Canvas道路、水系、建筑轮廓，拖动、返回主App、关闭。

## 安装与使用

直接安装APK更新已有“山兔·优化”，无需卸载。它不会替换正式山兔的包名、provider或私有数据目录。旧正式166及167/168/169/170/171候选保留；171含未通过视觉门禁的羽化实验，不交付安装。

悬浮入口：开始导航 → 展开导航详情 → 选“指北”或“运动朝上” → “开启悬浮”。首次按系统提示允许定位、通知及悬浮窗。切换到其他App后显示约184×216dp小窗，回到山兔隐藏。拖动标题移动，左箭头返回山兔，模式文字切换方向，右上×关闭小窗；主导航保持。结束主导航也会停止小窗并取消尚未完成的权限启动。

无可信移动方向时不以路线方向冒充，显示等待移动方向并保持最近可信朝向；无GPS/低精度时不伪造定位/剩余距离。

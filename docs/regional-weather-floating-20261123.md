# 2026-11-23 区域天气与悬浮小地图

## 区域天气

之前整幅地图使用中心点的天气。现在从地图可见范围批量获取最多 32 个区域的模型值，使用地图投影裁剪雨、雪和云，缺测区域留空。拖动、缩放和旋转使用同一地图投影。视野过宽时引导放大。单格正常值缓存 12 分钟，主界面通过「工具 → 实时天气」默认关闭，主动选择后记住开关。 [Open-Meteo 当前与多点数据](https://open-meteo.com/en/docs)

## 悬浮小地图

普通 Android 跨应用小窗使用左侧地图与右侧列表。左边保留方向、轨迹、当前位置和放大缩小，右边把前方距离放在天气或标记名上方，并在底部显示当前位置状态。首次布局为 248×184 dp，已保存尺寸继续生效。信息栏的雨段使用同一个实时天气开关，数据来自预计到达时间对应的沿途预报。记录时增加青色实心箭头尺寸与深色描边，方向缺测时增强位置圆点。保留原有锁屏无信息栏布局，以及原生返回、朝向、关闭、记录、拖动和缩放操作。

路线事件由 `FloatingNavigationBridge` 向支持该能力的原生服务附加到版本 1 payload。右栏以前方沿线距离排序，过滤已过及过期预报。GPS 可信且贴线后才计算距离，离线或缺测时保留有效标记。预览使用示例提示及路线，独立于用户悬浮权限和真实位置。

## 悬浮窗里程与地图面积复测

右栏把事件的路线里程换算成距当前位置的前方距离，去除已通过事件和已过期雨情后按数值排序。地图内放置返回、朝向、记录和关闭，底部只显示进度条和已走、剩余里程。Android 使用可靠 GPS 在当前路线上的投影，偏离或等待定位时用状态和横线，纯定位时地图使用整列高度。

390×857、360×780、390×480 的浏览器预览均通过。实际地图高 175 CSS px，顶部图标、缩放控件和底部里程无重叠。示例为 8.25 km 路线中的已走 3.12 km、剩余 5.13 km，右栏实际显示 0.8、1.5、2.4 公里。逐项点击朝向、放大、天气过滤、关闭和重开均通过。TypeScript 检查通过。定稿截图见 `artifacts/screenshots/floating-progress-20261123/`。

默认 248×184 dp 原生小窗的地图视口按布局由约 113 dp 增至 156 dp。最新 Android Kotlin 定向编译通过，本次跳过 CAD JNI 准备。真机合成、触控和 GPS 更新待实测。

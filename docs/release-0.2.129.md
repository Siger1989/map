# 山兔 0.2.129 界面与区域编辑修复

本轮用户确认结束快速预览，要求打包最新APK并上传GitHub。Android版本0.2.129-test、构建号136，沿用com.guanyun.weather.shantu.preview及原4a94证书，覆盖安装同系列时保留原存档。本轮只交付Android APK，固定PC EXE仍为0.2.128。

## 本轮内容

- 区域闭合后不再被旧路线卡盖住；标题明确显示面积、可换单位，周长保持可见。边界节点白边增强，地图预览不逐帧求路，超预算直连；取消和Escape可退出。
- 路线表单精简标题和重复入口；空输入不出现搜索栏，整行底色表示焦点，底部操作有按钮底框，定位按钮红色。
- 路线结果精简为两排操作，新增颜色/粗细快捷设置；详情和分享按需展开，按钮边界清楚。
- 第一人称提示、速度栏与定位箭头更新；高密度蓝色立体箭头，运动方向结合精度、速度、实际净位移和连续确认，抑制停下时的方向抖动。
- 锁定/记录入口使用共同定位基准，锁定与解锁位置一致；比例尺数字放细刻度下方，移除黑底。
- 分类颜色与鲜艳线条预设更新，保留已有自定义配色；备注入口和间距、名称输入键盘避让改进。
- 功能切换先保存有效线稿与路线编辑，失败保留编辑内容并提示；实际功能面板互斥，已有区域/记录不会被自动结束或删除。
- 用户交付前追加截图反馈已纳入：导航速度、跟随和定位提示合成单卡，展开按钮不溢出；第一人称、吸附、画线和路线编辑统一记录/路线主题。定位异常与偏航等重要状态优先显示，锁定后保留独立速度栏；共享半透明覆盖已修正。

具体模块、根因、截图、状态矩阵见[UI记录](ui-polish-20261015.md)和[导航紧凑布局记录](navigation-compact-20261015.md)。

## 验证与边界

58项相关定向测试、TypeScript检查通过；390×857/360×780实际面板、区域节点/退出、面积编辑/关闭、键盘/备注、路线表单，以及明确模拟GPS的导航锁定/箭头复核通过。APK网页资源实际启动，内置天地图影像入口与加载已检查。

Android两种构建分别使用fresh网页目录，核验原签名、版本、ZIP CRC、网页资源逐文件一致、优化PNG像素一致及图源配置。没有用网页预览冒充手机安装验收：真实GPS/低速转向、原生输入法、后台与触控仍需装包复测。网页API3108此前启动异常，不据此保证预览在线搜索/规划已恢复；APK使用自身LocalGateway。

更宽route-edit-feedback测试中的两项既有mock缺少off/getContainer问题仍记录在UI检查说明，本轮未扩大修复；本轮相关58项全部通过。

# 第一人称导航与路线预览（2026-10-12）

用户先确认当前位置偏下、倾斜朝前、看清后续路线弯道，随后明确去掉路书模式，将原入口替换成第一人称。施工位于独立分支 `codex/place-address-search-20261011`、基线 `48c80e0`，快速预览，不升版、不打包、不提交或推送。

## 实现与文件

- `modules/guidance/forwardCamera.ts`：55°前视、可用地图区65%处的屏幕点位，俯视0°；上下留8px安全边，矮屏允许向上移以避卡。可靠运动朝向优先，否则使用真实路线前方45米切线；无有效方向保留当前bearing，最短角转向；不写zoom或padding，不提供GPS。
- `modules/map/TerrainMap.tsx`：独立导航跟随和路线预览接口；实测可见导航卡、路线面板、底栏与图例占位。offset为单次相机选项，不设置永久padding；已安装MapLibre不支持Mapbox的retainPadding字段，未采用该字段。
- `app/page.tsx`：导航默认前视，可切俯视；有效定位才跟随，拖图仍暂停、继续导航恢复。接回路线优先，偏离无接回路线不拿原路线伪装运动方向。退出导航恢复进入前中心/倾角/朝向，保留实时缩放。删除可达路书模式与挂载入口，底层既有辅助数据保留。
- `modules/guidance/GuidanceCard.tsx`、`guidance.css`：原路书入口改第一人称；展开详情提供俯视切换，动作保留44px。
- `modules/navigation/RoutePanel.tsx`、`RouteResultSummary.tsx`、`routeCompact.css`：规划后可显式第一人称预览，标注“非定位导航”，不启动定位、跟随、导航或记录。初次主动查看zoom16，模式切换和退出保留实时缩放。预览只渲染状态、视角切换、退出、必要虚线说明与开始导航，退出恢复完整摘要。布局提交后才测量相机安全区域。
- `mobile/ui-corners-qa.tsx`：同步旧onRally夹具属性为onFirstPerson，修复类型检查。既有签名、存储格式、轨迹/照片、内置地图与私有Key配置保留。

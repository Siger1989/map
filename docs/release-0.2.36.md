## 本次更新

- 紧凑主地图：定位独立常驻；3D/视角/更多右侧归类；缩放位于路线显示上方；区域总览适配当前完整路线。固定布局，旧布局数据及备份保留。
- 画线：开始前设置线条；主界面绿色/橙色/蓝色直接换色，小色板展开；颜色与路段备注独立；可按真实路径删除连接段且不自动接线；新建与续画共用唯一保存，退出保留/放弃/继续，草稿可恢复。
- 记录与行程：独立记录窗口、暂停/继续/结束/取消；导航直接结束或结束并保存；行程完整时间/速度/海拔图与沿途照片，转换独立路线后可选隐藏原行程。
- 收藏：固定隐藏文件夹汇集隐藏对象，可恢复/批量恢复，原文件夹归属保留。
- 路线显示：显示方式、线条、图上信息归类；无速度的路线没有速度选项；海拔统计与带色剖面合成紧凑窗口。修复设置面板被下方路线卡截获点击。
- 照片：优先时间后GPS筛选，Android相册按授权索引查询；元数据与预览/原图分开读取；缺信息保留待确认，支持地图选点添加，重导入保留手动修正。
- 标记与模型：临时创建确认保存，取消不留空记录；普通地点可拖动；模型保留精确控制器/数值调整；钻井归添加模型，固定圆圈箭头，设置口径/深度。
- 返回先处理最上层；删除重复入口、重复保存页、世界地图与布局调整入口。天气数据、地形资源、离线计算、测量算法和原始行程保持现有实现。

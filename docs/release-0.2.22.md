## 界面修复
- 普通启动自动恢复上次地图中心、缩放层级、朝向和俯仰角，移动结束及切到后台即保存；明确地图链接的位置优先。
- 输入法弹出时，普通面板保留200px预算，在真实可视空间不足时内部滚动；取消按视口百分比反复压缩。搜索结果独立浮层、清晰边框阴影，位于输入框上下可用位置，最多200px且避开键盘；通用联想采用相同边界计算。
- 设置与参数行参考收藏密度：36px行、11px文字、2–4px间距；地图直接操作保留44px。收藏管理弹窗移至顶层，避开父容器裁剪和屏幕外定位。
- 收藏目录恢复约72%空间，下方地图至少180px；选择目标后自动居中并完整适配路线、轨迹、区域和模型，调整窗口尺寸会重新适配。地图底部工具贴边。
- 测量水平线与投影默认显示在独立图框，标注非等比示意；坐标和分享仍可展开。保存后从工具入口重新测量会创建新草稿，不静默改动已保存ABC；地图记录入口用于继续编辑。
- 标记位置统一经度、纬度、地面海拔界面。照片不再被地图覆盖状态变成半透明；缩略图边缘保留原标记小图标，无照片时仍显示独立标记。
- 节点编辑收窄至300px，六个操作同排，缩小颜色与滑杆区域。画线左下角直接提供道路吸附、河流吸附、节点吸附；道路和河流互斥，节点开关独立。

类型、逻辑测试、实际浏览器截图与构建结果见CURRENT_STATE.md。UI图册为本地应用实际截图，覆盖主菜单及常用二级界面；示例标记、照片和搜索结果位于独立测试上下文，不修改用户数据。

以OPPO Find X8 Ultra为目标参考，并检查412/393/360/266 CSS像素宽度、键盘缩小视口和弹窗边界。手机系统字体/显示缩放会改变CSS视口，物理屏幕分辨率不直接当作网页宽度。浏览器模拟不能代替OPPO真机输入法、拍照耗时、手势及系统分享验收。

# 2026-10-08 PC行业工具独立EXE与地图中心点

本轮先按用户要求实现PC行业EXE，并为Android地图十字中心添加小点。用户随后要求完整地图与生图合并到根目录EXE文件夹，最终桌面交付改为[合并桌面应用](desktop-app-20261008.md)。本文件保留手机与先期独立包装验收证据，独立行业EXE不另行发布。

## 目标、功能、施工与门禁

- 目标：Windows PC双击运行行业工具，无需另装Python；Android准星增加清晰的小点。
- 功能：沿用实测剖面/钻孔柱状图的标准Excel导入、校验、SVG、PNG、完整附表与来源追溯；提供标准模板及填写示例。保留APK行业入口。
- 施工：复用`research/geology/generator-v1`的管线与网页；PyInstaller单文件打包Python、依赖、页面及固定模板，pywebview提供桌面窗口。只读资源与用户成果分离，动态loopback端口避免旧9188服务冲突。地图只改主图/双图准星组件和CSS。另修正一处既有Canvas联合类型报错，运行行为不变。
- 门禁：不得打入历史成果、原始参考资料、地图配置或签名；不覆盖用户输入；EXE在中文/空格路径实际运行、两类导入与输出检查、窗口关闭与保存检查。地图检查390×857、360×780的实际computed、截图、锁定/解锁、双图与返回；最终包资产和原签名独立核验。真机能力单独记录。

### 原生保存验证与测试弹窗处理

pywebview默认禁止下载，已显式启用`ALLOW_DOWNLOADS=True`，并提供独立“下载完整附表HTML”入口；生成本身直接落盘到用户数据目录。原生另存为对话框已触发，但用户未确认文件保存，实际系统对话框确认与落盘仍标为未验证，不用浏览器下载或自检输出替代。

下载QA多次启动可见测试窗口，用户反馈“关了又开”。根因是测试进程重复拉起并自动点击下载，属于本轮验证方式造成的干扰。已停止全部自有测试EXE、移除自动点击下载的参数与代码，保留用户主动点击后的正常保存。后续不再自动打开保存窗口；重测条件是用户主动在PC界面选择一次模板或图件保存。最终检查只使用隐藏self-test/serve，不触发桌面弹窗。

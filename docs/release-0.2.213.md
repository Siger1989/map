# 山兔 0.2.213 私人 Android 测试版

## 行程模拟的云台跟随

旧版相机后撤距离和俯仰已有连续过渡，机位会跟着短间距的路线点左右摆动。新版按屏幕播放秒数平滑机位和转向。转向使用前后时间窗口，能提前进入已知的转弯，再连续回稳。位置使用较短的窗口贴近急弯，控制目标从原路线偏移的幅度。俯仰与离地高度沿连续的地形机位过渡，画面横滚为零。箭头在地形画面中有一定的上下活动范围，减少过弯时即时拉回固定位置造成的俯仰回弹。

运动箭头的位置按真实路线和当前里程计算，方向也做短时过渡。进度、日月位置和出发到达的时刻仍按当前里程同步。暂停后回到同一时刻、从该处继续以及录制整段时使用同一套相机。跨越无连接的轨迹段时切换到新段机位。

## 镜头距离

点击行程画面右上角的「距离」，可以把第三人称跟随距离设在 55 至 200 米之间，默认 90 米，每档 5 米。暂停或播放时均可调节，重新进入后恢复上次设置。录像使用开始时选定的距离。远景多准备镜头到路线之间的地形和影像。

以同一路线位置的 WebGL 视线量测水平距离。55、90、200 米三个设定分别得到约 54.9、89.8、199.6 米。云台跟随时会随地形和急弯修正实际机位。

## 复测

右侧私人手机预览可回放青城山 8.25 公里盘山路。回归新增模拟 GPS 左右抖动的路线、跨日期变更线、多段轨迹和距离设定。行程、天文与卫星地形相关的 91 项定向测试通过，TypeScript 检查通过。[盘山路预览](http://127.0.0.1:9174/phone-preview.html?scene=journey&route=winding)

在同一路线、平坦参考面和固定 60 Hz 取样下，30 秒回放的最大相邻帧偏航变动由 3.791° 降到 2.028°，机位三维二阶差分峰值由 6.225 米降到 1.995 米。这组测量用于隔离轨迹角点引起的突变，地形和设备差异另行实测。

用正式网页构建、真实天地图影像和地形、Edge 硬件 WebGL 复测 30 秒回放。390×857 下在 49.5% 至 65.5% 的连续弯道，冷启动最大相邻帧转角由 13.94° 降到 6.01°，预热后由 14.19° 降到 6.03°。两次新版回放中，取样的 476 帧运动箭头均完整在画面内。按相同行程进度取样时，预热后角加速度的第 95 百分位从约 872°/s² 降到 367°/s²。

15 秒全程回放的最大相邻帧转角由 11.14° 降到 7.82°，45% 与 52% 的俯仰回弹均未复现。此轮取样的 514 帧运动箭头均完整可见，最靠近底部信息栏时仍留约 25 个 CSS 像素。路线测速在桌面 GTX 1660 上完成。

390×857 和 360×780 私人预览均实测播放、暂停、续播、前后拖动及退出。拖回中点得到同一镜头朝向，首尾时间为 22:00 和次日 06:00。控件通过水平溢出与边界检查。实录 15 秒 WebM 的 361 帧均含箭头，分辨率为 384×704，帧率为 24。截图和录像位于本机 `artifacts/screenshots/sky-213/`。

另在 390×857 验证 200 米镜头，从播放切入录像时，两者起点的实际机位到箭头斜距均为 204.67 米。视频为 608×960、24 fps，实际解码得到 361 帧。测试语料缺少的图块由本机天地图服务获取。360 和 390 宽度的近远标签与底色对比度均为 11.99:1，焦点框对比度为 7.14:1。

私人测试版已发布。服务端 APK 和校验文件的大小与摘要均通过核对，完整下载的 APK 得到相同 SHA-256。[下载私人 APK](https://github.com/Siger1989/shantu-private-delivery/releases/download/v0.2.213-private/Shantu-0.2.213-oldengine-private.apk)

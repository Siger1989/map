## 修改与根因

- 导航：`GuidanceCard.tsx`、`NavigationTelemetry.tsx`、`guidance.css`整理状态、出行方式及速度；等待定位不在多个格子重复，缺失数值用破折号并提供无障碍说明，紧凑速度区复用外卡背景。继续导航/展开/返回等入口保留。
- 进度：新增`GuidanceProgressRail.tsx`/`guidanceProgress.css`，由当前导航会话进度驱动，可靠定位才显示当前位置，缺定位不伪造当前位置；独立于已移除天气模块。普通纵向、短空间横向，锁定时保留；主页面及锁定白名单接入，编辑/模态阶段避让。当前为只读进度展示。
- 记录：`OutdoorPanel.tsx`/`RecordingPanel.tsx`显式传递定位错误布尔值，避免凭提示文案猜错误；`outdoorSurfaces.css`排除错误行的灰色覆盖。记录成功提示不染红，不改变暂停/记录数据。
- 定位提示：`position.css`与页面错误标志移除大背景、描边和阴影，用半透明文字说明；文字不拦截地图，关闭入口保留。
- 画线：`tracks.css`撤回同文件末段强制44px的吸附及完成按钮尺寸，外框与工具菜单同为232px宽、28px按钮行、约11px字；样式行32px且备注16px，吸附/操作各同行。
- 输入法：`keyboardViewport.ts`原本只冻结dvh防地图重排，缺少通用焦点显露。新增`keyboardFocus.ts`，仅在键盘遮挡时处理当前编辑字段所在真实浮窗，限制可见高度并内部滚动，不滚整个地图/文档、不抢焦点。已有路线编辑专用IME抬升继续独立负责；收起键盘/切换宿主恢复临时样式。实际复测补齐双图路线卡、双图标记、收藏portal和图纸信息等宿主。

补充根因：窄矮视口中，标记属性列表可能缩到不足一行输入框；原辅助逻辑只滚最近一层，`PinEditor.tsx`又按整条属性行滚动。现保证聚焦字段的内部滚动空间，逐层校正并复核第二遍；键盘关闭恢复临时内联样式。属性行高于滚动视口时，以当前输入框为滚动目标。禁止滚动地图根、body或document。

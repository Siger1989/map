## Actual188 check and correction

The active Hybrid manifest explicitly prohibited cleartext traffic, unlike the standalone native manifest. Imported HTTP URLs could therefore be rejected before redirect handling or image decoding. This version enables HTTP for user-supplied raster services. It does not rewrite source records, replace credentials, disable TLS validation, permit HTTPS downgrade, or weaken the WebView's existing `MIXED_CONTENT_NEVER_ALLOW`, local trusted-origin bridge or external-navigation guards. Arbitrary imported HTTP origins cannot be enumerated in a fixed build-time domain list; HTTPS URLs remain HTTPS.

Jilin detailed imagery remains unresolved: the original HTTPS source returned the known No Data image for detailed samples, with only a global z0 overview available. This is independent of the HTTP policy correction. The user has not yet tested the same file in Ovi. Legacy third-party Tianditu keys remain restricted; the user's registered built-in Tianditu configuration is retained.

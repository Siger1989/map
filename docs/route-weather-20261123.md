# 2026-11-23 沿途天气私人预览

沿用 `9c55c3e` 老引擎工作树、私人天地图配置和 9174 手机框。青城山盘山公路为 8.25 公里公开示例，路线用时先设为 3 小时。项目入口为「行程模拟 → 沿途天气」，规划路线以规划用时为起点，实际轨迹沿用记录或手动输入的用时。预览地址为 `/phone-preview.html?scene=weather`。

以预计到达时间读取 Open-Meteo 未来逐小时的雨和阵雨，整点前后分别匹配各自时窗。用最多 10 个采样位置批量读取预报，缓存 15 分钟。原始路线地理弯折和断点保留。确认地图、图例和时间轴使用同一组色阶。0 mm 用亮暖黄，有雨按 ＜0.2、0.2–＜0.5、0.5–＜2、2–＜5、≥5 mm 分为浅青、蓝、紫、粉和橙红。缺测用灰色虚线。雨量色阶仅供沿途显示，格点预报覆盖范围与路线采样间距分别看待。

问句在本地按出发地时区处理，支持明天、后天、指定日期、比较多个出发时刻和问当前方案的雨段。未指定明天的时刻时先比较 07:00、09:00、11:00，优先遇雨里程较短的方案，同里程比较峰值。大模型 API 未调用。青城山示例实测 6 个采样位置合成 1 次 HTTP 请求，拖时间轴、点路段、对比和改用时在本地更新。Open-Meteo 免费托管接口限非商业用途，服务商按地点、变量、预报长度等规则计量。[预报字段](https://open-meteo.com/en/docs) · [计量规则](https://open-meteo.com/en/pricing)

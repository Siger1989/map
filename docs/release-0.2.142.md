## 主要改动

- 新增原生地图适配层、透明界面叠层、真实相机/DEM 投影、拾取和手势桥接，复用原收藏、路线、画线、照片、剖面、CAD、导航与文件业务。
- 地图瓦片工厂采用稳定且按图源代次隔离的缓存身份，避免静止画面反复解码；共享前台请求从旧原型的 2 路对齐到 4 路。天地图仍限制总量 4、启动间隔 250ms，保留限流退避及后台下载预算。
- 修正 WebView 定时器接收者与 DEM 事件订阅，照片在地形就绪后自动重新分组；地图传输只含缩略图，原清晰副本保留。
- 初始化必须收到真实状态回执和真实帧才就绪；首次回执失败时可自动有界重试。
- 分享使用独立原生地图，沿用原网页最高 zoom 16 与 15/9px 路线描边；高清就绪检查绑定具体已绘帧，要求目标叶瓦片自身纹理完整，不能用低清父瓦片、收到图片或解码成功冒充最终成图。最终帧再次复核，主地图相机保持。

## 安装与剩余验证

安装前保存未保存的画线草稿和记录；画线内存草稿不会因为沿用数据库而自动保存。直接覆盖“山兔测试版”，不要先卸载。旧的独立“原生私人测试”原型是另一个包，本 APK 不把它当作完整升级目标。

Android 支持 API26+ 与 OpenGL ES3，包含四种 ABI；模拟器验证不能代替手机触控、流畅度、真实 GPS、后台/锁屏、相机与跨应用分享验收。系统分享选择器曾实际打开且未发送，不等于已完成跨应用交付。

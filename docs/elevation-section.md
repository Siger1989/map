# 三维海拔剖面

点击地图右侧“剖面”，拖动侧边海拔滑条，或输入米数/点 ±1m 微调。高于所选海拔的山体被水平切掉，下面保留三维起伏；仍可用双指或视角盘平移、旋转和倾斜。剖面默认纯白，可用“剖面颜色”选择任意纯色。软件和控制面板沿用原有配色，轮廓为一根 1.8px 实线，随填充明暗选择深/浅色以保持可见。

左侧为紧凑海拔提示，正常时仅显示“剖面 · 海拔 m”。更新时显示简短状态，加载失败或部分缺测时提供“重试”。

长方体、圆柱、球体按原有位置、米制尺寸、旋转和埋深同步裁切，交界处显示各自模型颜色的封口。地下模型保留透视示意。地形以下按实体处理；没有实测地下地层或自动推断洞穴，洞穴形状来自用户标注。

进入剖面时按真实海拔 1× 显示，退出恢复原地形开关和起伏倍率。已有 3D 视角保留；从俯视进入时临时转为 55°，退出恢复原俯视。剖面期间暂停点选/绘制，点击“退出剖面”、Esc 或安卓返回键即可退出。路线和模型存档不修改。

## 计算与性能

- 地图原生视锥和层级细节选择请求瓦片，包含防止接缝裂开的少量邻接瓦片；不扫描全区域。原 DEM 使用同一地形接口，最多 3 并发、8 秒网络超时、48 张解码缓存。
- 剖面和原地形保持同一 256px 瓦片尺寸，并采用较保守的远景 LOD。填充直接读取同一裁切 DEM，采用 nearest 采样避免边缘插值造成透明细缝。远景会降低采样密度，实际精度取决于地形采样间距，不把输入小数米数当成测量精度。
- 海拔修改合并为最多约每 350ms 一次，移动相机时延后地形重建。移动后由地图原生缓存补新视野，不再次重载全地形；颜色修改只更新渲染样式。
- 滑条保留最近完整加载的海拔范围，加载过程中的临时统计不会改动刻度；按住拖动时锁定范围，移出滑条后松手也能结束拖动，避免数值回跳。
- 轮廓由相邻高程线性求交，连接短线并删除共线点后交给地图绘制；粗瓦片中被细瓦片覆盖的线段移除，防止旧轮廓横穿切面。统计结果复用，最多每 250ms 合并发布；轮廓元数据最多缓存 128 张瓦片。退出或新高度取消旧任务，晚到结果不能覆盖新状态。
- 缺测/网络失败显示错误或部分缺测，不将缺失高程当成海拔 0。视野和剖面刷新仍受设备 GPU、底图来源和高程分辨率影响。

## 模块与验证

`modules/section/` 管理独立剖面设置、纯色样式、Terrarium 高程裁切、连续轮廓、模型平面求交、原生地图来源及侧边控件。`TerrainMap` 仅接生命周期，`AnnotationLayer` 加裁切平面与封口；`app/page.tsx` 组合状态，Web/Android 共用样式和控制器。

验证涵盖负海拔和纯色、单线轮廓拼接、3D 相机保留/退出恢复、地形失败、过期任务取消、缓存与 3 并发、移动/改色不重载、移动时延后重建，以及六种地表/地下模型的封口高度和退出恢复。完整命令及结果见 `CURRENT_STATE.md`。自动测试不等同浏览器帧率或手机触控实测；本轮未重新打包 APK。

浏览器回归：启动本地 `npm run dev`，设置 `PLAYWRIGHT_MODULE` 为可用的 Playwright 包目录、`MAP_BROWSER_PATH` 为现有 Chrome/Edge 可执行文件，然后运行 `node scripts/verify-section-browser.mjs`。该脚本在独立上下文中检查真实 WebGL 切面像素、错误码、改色/变海拔/旋转/反复开关/窄屏，并保存截图到 `artifacts/screenshots/`。仅测试上下文注入地图诊断引用，不在产品中暴露调试对象。脚本整体限时 150 秒，不绕过加载失败。

实现依据为当前安装的 MapLibre 6.7 源码和 [自定义协议接口](https://maplibre.org/maplibre-gl-js/docs/API/functions/addProtocol/)。该版本的 color-relief 渲染器仅从 Interpolate 表达式构建色带，因此用 10cm 边界过渡和切面以上恒定颜色，而不使用不能生成有效色带的 Step 表达式。

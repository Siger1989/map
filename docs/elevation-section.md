# 自由矩形剖面

点击右侧“剖面”，在当前视野生成一个矩形面。拖动中心 ✥ 平移，拖四个角点改变宽度和高度；“调整”中的“位置”控制中心海拔或移到当前视野中心，“角度”控制方位、倾斜和面内旋转，“尺寸”可输入米数并改变剖面颜色。支持竖直、斜切和水平面。收起参数后，地图上只保留小工具条和拖动手柄。

矩形沿自身法线向观察者一侧延伸形成有限裁切区域：该区域内靠近视点的地表不绘制，背侧与矩形范围外的山体保留。围绕山体转到另一侧，裁切侧自动切换；切面位置与角度保持不动。与山体相交的部分为纯色填充，默认白色，地表交线为单根实线。矩形边缘是绿色操作框。切除区域是观察用开口，不生成开口两侧的实体墙，不改写原始地形数据。

长方体、圆柱、球体使用相同的有限裁切体，并按实际模型三角形求交封口，保持原模型颜色与地下透视。此功能把高程以下视为实体，没有推断真实地下地层或洞穴。

仍可在空白地图上平移、缩放、旋转和倾斜；只有按住切面手柄才移动/缩放切面。手柄边缘视角近乎平行、无法可靠求交时不更新位置。取消手势恢复开始前状态。退出、Esc 或安卓返回关闭剖面，恢复原地形倍率/开关；从俯视进入时暂调到 55°，退出恢复俯视。路线、模型存档保持不变。

## 渲染与性能边界

- GPU 对地图原生地形片元执行有限矩形裁切。拖动、转动、改色不调用 setTiles，不替换 elevation 源，不重新编码或上传剖面 DEM；原生地形 LOD、瓦片缓存和相机选择保持使用。
- `terrainClip.ts` 是针对当前 MapLibre 6.7 地形 shader 的独立适配器，只包装本地图的 WebGL 上下文，不修改全局 WebGL 原型或 node_modules。初始化识别地形颜色 shader，在其顶点阶段恢复切面局部米制坐标，片元阶段判断五个边界。单独用于地图拾取的原始地形深度不裁切，因此可继续在被切掉的山体位置放置切面。退出时禁用裁切，销毁地图时还原包装。
- 这不是重建三角网格的通用 CSG 布尔运算。性能收益主要在连续调整时免去旧方案的 DEM 重建/传输；尚未测量手机帧率或给出性能倍数。
- 切面填色采用 64×32 网格，从已经加载的地形查询真实高程，对网格三角形求交。竖直面重复坐标共用采样；更新最多约每 90ms 合并一次，不产生额外网络地形请求。改色只改材质。旋转相机无需改变裁切几何；相机停止或地形新数据到达时刷新采样，以匹配当前 LOD。
- 面宽支持 50m–200km，高支持 50m–30km，中心海拔支持 -12km–20km。有限网格与 DEM/LOD 分辨率限制交线精度，宽大切面上的小地形细节可能被简化。未加载的部分不填成海拔 0，会显示等待/部分地形未加载/不可用。
- 若升级 MapLibre，需要先运行 shader 兼容测试与真实 WebGL 回归；不能仅凭类型检查判断适配成功。匹配失败时显示裁切不可用。

## 文件与验证

新增 `planeMath.ts`（坐标、三轴姿态、有限裁切与三角形求交）、`terrainClip.ts`（GPU 适配）、`PlaneSectionLayer.ts`（切面、采样、手柄）、`planeModels.ts`（模型裁切/封口）。更新 SectionPanel、section.css、types、TerrainMap、AnnotationLayer、MapActions 和 app/page.tsx。旧水平剖面算法仍保留及测试，但已不再接到产品入口；没有删除天气、导航、模型存档或地形来源。

逻辑回归：`node --experimental-strip-types --test tests/*.test.mjs`。新 `section-plane.test.mjs` 覆盖矩形外保留、前后侧、任意倾斜、采样缺失、shader 识别/拾取保留、米制变换、模型有界封口与退出恢复。

真实浏览器回归：启动 `npm run dev`，设置 `PLAYWRIGHT_MODULE` 和可选 `MAP_BROWSER_PATH` 后运行 `node scripts/verify-plane-browser.mjs`。在独立测试上下文中检查地形切面像素、拖动/缩放/三轴角度/背面/改色、零 DEM setTiles、退出重开、390×844/360×780/360×460 布局与 WebGL 错误。脚本总限时 180 秒，截图在 artifacts/screenshots/；不向产品添加调试全局对象。旧 verify-section-browser.mjs 只适用于历史水平 DEM 方案，新功能请使用新脚本。

实现核对了已安装的 MapLibre 6.7 `terrain.vertex/fragment.glsl`、`draw_terrain.ts`、`draw_custom.ts` 与 `program.ts`。公共接口说明：[自定义图层渲染输入](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/CustomRenderMethodInput/)、[原生地形配置](https://maplibre.org/maplibre-style-spec/terrain/)。构建和浏览器模拟不能代替手机实机触控/帧率验收。本轮没有生成新的 APK。

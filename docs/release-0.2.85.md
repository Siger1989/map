## 坐标处理

用户在85.37733,28.28054反馈OVMAP无字谷歌影像与内置影像错位。对原始同编号z14/x12077/y6849的目标影像和EOX影像做本机视觉对照，主要河谷地物位置基本一致；目标配置却声明coordType=1（GCJ-02），应用的校正在本地点约产生457m转换量。样本是诊断证据，不代表全球测绘精度验收。

新增运行时图源默认坐标解析，仅识别单层、纯卫星、明确的旧式`/vt/lyrs=s&...&gmapgz.jpg`转发模板为WGS84。混合影像/注记、多图层、未知模板仍使用原声明，手动选择始终优先。已保存的此类图源立即使用新解析，不重导入、不修改原始OVMAP声明或用户轨迹。坐标选择增加“自动”，可撤销该源手动覆盖；没有承诺任意未知服务都能从图片自动推断坐标系。

## 日期显示

每幅TerrainMap独立维护影像日期状态。内置EOX显示2025年合成；NASA每日影像仅显示实际加载成功的日期；未接入可靠日期的自定义源/天地图标明未提供，不把名称中的2025、缓存时间或当前时间当拍摄日期。普通矢量图不显示影像日期。日期来源键隔离，切源不沿用旧日期。

EOX为[年度合成产品](https://cloudless.eox.at/)。部分服务另有按区域/级别查询日期的元数据接口，例如[Esri说明](https://support.esri.com/en-us/knowledge-base/faq-can-the-date-of-an-image-be-determined-from-the-wor-000012181)；本轮未新增其查询接口，不能将“未提供”理解为供应商绝无日期信息。

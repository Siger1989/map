# 双图完整图层选项 — 2026-10-01

用户要求双图对比也提供单图完整图层菜单。最初为快速预览，0.2.92不包含本轮新增双图图层入口；用户随后授权打包，已进入0.2.93-test/code100，交付和最终产物校验见release-0.2.93-local.md。未提交或推送。

根因：比较页隐藏主图直系控件，Host仅选图源并传入原始choice.settings，没有各画面图层编辑状态。新增顶栏“对比图层”入口、上/下图（横屏左/右图）选择，复用原LayerPanel及提取后的LayerPresets。完整参数与说明按需展开，248px宽、左8px、开关36px透明底。导入图源沿用主图规则，隐藏不作用于外部底图的内置卫星开关，保留8项；内置底图9项。

Host以画面及图源ID存储临时完整设置，applyLayerPatch保持气温/地质/海拔着色互斥。设置传入相应TerrainMap，另一画面不受影响；切换后返回同一图源保留临时设置。“选用”传最终设置给原onUse，仅此动作应用到主图。关闭比较不写主图设置。原forceTerrain改为3D/摇杆动作显式开启当前两画面的地形，避免强制态遮蔽每屏地形开关。卫星状态分别接收，切换图源清理本屏旧元数据。未改地图渲染、存储格式、网络、图库、定位或记录业务。

第二个根因：复用单图窗口时，其高特异性定位规则盖过初版比较定位，390×480下底部超过操作栏。定位改为比较UI内的强作用域：顶栏32px+图源栏32px+4px，最大高扣116px及安全区；真实正文滚动，标题固定，不隐藏溢出。

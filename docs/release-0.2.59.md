# 山兔 0.2.59 测试版：标记与导航退出

地图标记改为紧凑的纯色横排标签，实心图案和名称保持单行，远景仍缩略显示。标签旁可快速设为导航起点或终点；先点选标记、再点一次打开编辑，位置调整轴仅在“调整”时显示。标记编辑窗口集中名称、备注、坐标分享、图案/颜色、照片和自定义条目，条目过多时只滚动该区域。选终点后若起点未填，焦点进入起点输入框。

框选期间即可导出、分享或删除所选内容，退出框选不再改变地图视角。画线工具恢复按钮底板；所选已保存路线卡的“缓存”改为带确认的“删除”。结束导航或取消路线时清除临时规划线及起终点；已保存轨迹本身不删除。

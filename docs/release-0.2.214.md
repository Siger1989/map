# 山兔 0.2.214 私人 Android 测试版

## 悬浮小地图

返回、朝向、记录和关闭缩成地图内的操作图标。默认 248×184 dp 小窗的地图视口高度约 156 dp。地图下沿显示进度条、已走和剩余公里数，里程来自可信定位在当前导航路线上的投影。等待定位或偏离路线时会显示对应状态。右侧按距当前位置的沿线距离从近到远排列提示，经过的标记和过期雨情会移除。记录模式使用更醒目的青色位置标记。

主图的区域天气默认关闭，可从「工具 → 实时天气」开启，按地图区域显示云、雨和雪。导航悬浮窗的雨情提示使用同一开关。随包包含最近确认的日月观景、行程天气、起播预载与后台记录和快捷设置磁贴更新。对应变更记录见 [悬浮窗和区域天气](regional-weather-floating-20261123.md)、[行程天气和起播](weather-effects-20261123.md) 与 [后台记录](native-android/background-recording-20261123.md)。

## 试用方式

Android 8.0 及以上，应用包名 `com.shantu.oldengine`，版本 `0.2.214-test`，构建号 221。请保存正在记录的轨迹和草稿，再用此包覆盖原来的 0.2.213。

在「工具 → 悬浮小地图」启用悬浮小窗。开始路线导航后切到其他应用，即可查看悬浮窗里的里程和前方提示。系统首次要求权限时，允许山兔在其他应用上层显示。

HarmonyOS 6.1 原生 HAP 待平台适配和签名后单独交付。

## 验证

TypeScript 和 73 项定向测试通过。390×857、360×780、390×480 网页预览实测排序、进度条布局，以及朝向、缩放、天气过滤和关闭重开。截图在 `artifacts/screenshots/floating-progress-20261123/`。Android 真机上的悬浮显示、定位和触控待用户实测。

签名 APK 大小为 165,958,930 字节，SHA-256 为 `2deba8caaefbef2d566e9310f79036d4f130e173e4e5fa7ab469013f9092d1cb`。包名、签名与 0.2.213 一致，版本号递增。逐文件核验了 1,950 份新网页资源以及 ZIP CRC 和条目唯一性，确认原生和网页与本机 9174 预览使用同一注册天地图配置及 39 项内置图源。8 个原生库与 0.2.213 逐字节相同，ZIP 与 64 位原生库的 16 KiB 对齐通过。

0.2.214 签名包提取出的实际网页资源通过 Android appassets 启动测试。从优化包的 DEX 核对悬浮窗路线事件和里程字段，从清单核对悬浮与记录磁贴服务。沿用已验证的 CAD ABI 二进制，构建跳过重复的 CAD JNI 构建和 lintVital 任务。

# 日月观景、标记时间轴与行程模拟

本轮在 0.2.207 私人包对应的山兔工作树开发。现有私人预览沿用 9174，已安装的 207 不包含这些改动。

- 工具 → 日月观景。安卓实景使用后摄、旋转向量和真北校正，模拟可拖动。太阳、月亮的角度按观察点和所选时刻计算。相机视场与屏幕裁切参与投影。定位缺失时以明确标出的地图位置预演；天地图卫星影像贴在高程网格上，天空随太阳高度变亮或变黑，影像保持原色。
- 时间轴按观察点时区覆盖整个当地日期。金色与浅蓝曲线分别表示太阳和月亮，月亮图标随月相变化。视野内轨迹标时，日出日落位置有独立标记。山脊时间估算含太阳上缘和标准折射；按约 1° 方位采样至 55 公里，考虑地球曲率。DEM 缺测、楼房、植被、实际折射及局地天气会影响可见时刻。普通地平线参考有单独标识。
- 找月亮显示方向、山脊遮挡和地平线状态。模拟可转向月亮或跳到当天可见时段。摄像头模式显示转向提示。
- 标记点的「日出日落时间轴」使用此点坐标，每个标记单独记住开关状态。当地时间逐分钟更新，跨越当地午夜后重算。关闭时释放计算和地形请求。
- 时间轴上以金色上箭头日出图案、橙色下箭头日落图案标记实际升落位置，文字旁保留对应图案。标记详情的「从此处观景」固定该标记的坐标，左右拖动改变方向，上下拖动改变仰角，退出回到原详情。可以在[青城山标记手机预览](http://127.0.0.1:9174/phone-preview.html?scene=marker)体验。
- 保存轨迹和已规划路线可以启动第一人称行程模拟。出发和到达时间按出发地时区解释。时钟随累计路程推进，分段轨迹之间不虚构连接。相机略高于地表，沿前进方向看。录像合成同一场景、出发地时间、行程进度、日月方位和影像署名。仅在用户点保存后输出文件。
- 青城山开发预览坐标 103.569°E、30.904°N 使用由真实 DEM 计算的完整山脊快照。2026-11-20 山脊日出 08:32、日落 17:08。开发用的短程回放是手工示例线。应用正常入口使用用户所选路线和地点。

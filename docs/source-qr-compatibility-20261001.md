# 图源二维码整理与兼容记录

用户授权采集其图源目录并研究山兔扫码识别失败。实际目录含36个主图源、196个历史期数，232张原二维码均保存并由jsQR解码。所有载荷以`ovobj?t=37`开头，是奥维明文自定义图层配置；原导入器仅支持标准URL/JSON/XML及独立OVMAP文件，缺少该文本适配，是本套普通二维码识别后导入失败的明确原因。用户未指定刚才失败的具体二维码，不能断定其当时就是同一失败阶段。奥维官方说明见[扫码添加自定义地图](https://www.ovital.com/137268-2/)。

实现范围：`oviQr.ts`新增有限profile适配，`online.ts`接入单QR及字符串JSON数组，`ovmap.ts`提取共用模板转换而保持容器行为。`qr.ts`保留大小和内容上限、bitmap关闭；图片失败后最多12个原生分辨率窗口，长截图顶部/中部小码可重试；相机每帧仍只解一次。`MapSourcesPanel.tsx`仅改格式说明。既有存储/图源选择、地图相机、Android权限、瓦片代理和此前未提交UI修改保持原样。

按本套样本适配`po=1,pn=0/1,mt=1,mf=3,pt=443/80`；名称/分类/host/path支持保留标准Base64加号及Base64URL。最大级别0–24，`pn`作为WGS84/GCJ02声明保留，未声明的最小级别/像素尺寸使用0/256默认值。禁止脚本、登录userinfo和不受支持的附加字段；专有历史、其它投影或未知profile清晰失败。旧本机OVMAP合集与本套QR的名字/URL不同，不具备逐条一致的字段对照证据；这份有限适配还需同地点、同源奥维及真机对照，不能把默认值和样本字段解释当成完整专有协议规范。

实际配置结果：231项可解析，含35个主图源和196期普通历史影像；1项985历史有专有附加数据`at/ad/al`且缺少普通XYZ配置，暂不能导入。原二维码仍完整保留。配置解析成功不等于远端服务连通、凭据有效或位置无偏差。

私有本地整理包：`APK/图源合集-36源-232二维码-20261001.zip`，614,020字节，SHA256 `6d2f76730e49c9ae090a50b9b63a544dea9203a731b85b351e7ec52099ff41d3`。包内HTML目录、原PNG、分类/日期及原始解码信息、兼容结果、导入说明；另有35主源及历史100/96两批OVMAP文件。转换回读逐项核对模板/query、坐标声明、最大级别和总数。可以先在0.2.90的“图层 → 地图图源 → 导入图源 → 导入地图文件”使用OVMAP。设备图源上限100项，已有存储计入容量，不能把完整归档等同232项同时存入。

验证：55/55图源、OVMAP、扫码/路线QR定向测试通过，类型检查、Android网页构建、diff检查通过；ZIP CRC及232PNG数量通过。

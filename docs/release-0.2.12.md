## 更新内容

- 每次打开首页默认卫星影像，可继续手动切换图源。
- 选中路线节点显示“＋节点 / −节点 / 拉分叉 / 连接”。添加中间点，删除后前后两点直接相连，支持撤销；连接两条路线生成组合路线并保留原线和照片，也能从节点画出分叉。
- 导航优先最近接入；可靠定位确认走入另一条相连路线或分叉时自动切换，保持所选终点，不跳到无关收藏路线。只有画面交叉而无共同节点的线不视为相连。
- 开始导航前可交换起终点方向、选择分叉端点；道路路线反向时重新规划转向指令。
- 收藏恢复文件夹分类入口、按文件夹颜色铺底，固定关闭按钮；省市分类与批量操作继续保留。
- 包含0.2.11已有的标记资料、Excel修复、路线照片/ZIP、扫码、图源等功能。详细操作见[节点路线与收藏说明](https://github.com/Siger1989/map/blob/main/docs/track-network-and-folders.md)。
- 每轮项目改动同步构建新APK并发布测试Release。完整构建使用新的临时网页目录，防止累计旧资源混入安装包；未删除原构建目录或更换签名。

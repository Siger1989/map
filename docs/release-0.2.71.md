## 本版内容

- 收藏夹提供统一导入入口，可导入支持的文件或标记 Excel，并沿用原预览与确认流程。
- 分享入口集中选择 JSON 或 XLSX，移除独立 Excel 导出入口。
- 不同操作窗口互斥，减少地图操作面板叠放遮挡。
- 待补：修复编辑模式框选卡顿。
- 待补：调整记录中照片入口顺序，优先直接拍摄，同时提供导入，并将文件夹导入放在选项末尾。

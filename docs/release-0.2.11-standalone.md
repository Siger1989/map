# 山兔 0.2.11 独立测试版（2026-09-08）

## 更新

- 轨迹详情显示关联照片，结束行程后可继续追加；路线 ZIP 包含二维码全程图、照片副本、GPX/KML、路线JSON与Excel照片清单。
- 收藏采用紧凑列表，支持当前结果全选、省/市全选、勾选栏滑动连选及边缘自动滚动、批量删除前确认；右侧“框选”可按地图范围选择完整对象后打包ZIP。地点上限2000个，模型独立上限80个。
- 标记和模型可以单独导出；Excel第一页从A1开始，先地名、经纬度、海拔，再按所有已添加属性的并集排列。空属性值保留空格，中文、编号和普通文本兼容共享字符串格式；模型完整参数保存在JSON。
- 标记信息第一页新增经纬度、地面海拔，以及可查询到的国家、省/州、城市、区县、乡镇/街道、社区/村和附近道路。查询使用当地名称，刷新旧自动地区缓存，保留手工分类；缺失字段不猜测。
- 地图中心准星，右侧“标记”先选择地点、模型或区域种类。保留一个定位跟随按钮，模式设置移到“更多→定位设置”；按钮标签收在框内，标记使用不透明深底白字。输入参数时收起重复浮窗，避让键盘，44px输入框，整体圆角缩小。
- 点击轨迹两节点之间的线段出现临时绿点，可在该位置添加行程标记，左侧里程条同步提示；不更改原始轨迹节点。轨迹样式可设置0–90%透明度。
- 新增12个免Key图源：全球5项、美国3项、日本4项，可切换并记忆选择；每项注明范围、数据年代和署名。区域输入改为浅底深字。
- 保留原海拔颜色，每50米细分色阶，等高线随高度变色。
- 画线设置靠后的“更多吸附”新增河流吸附，默认关闭；只沿可识别、连通的水系中心线，缺数据/断点不自动跨越。
- 包含未单独公开的0.2.10成果：扫码先看轨迹信息与海拔再手动导航；标记图标/属性模板/Excel；省市收藏；多剖面图片下方平面地图与坐标；道路吸附区域/轮廓拉伸模型；地下半透明模型与亮色接触面；标记名称定位、地质入口和摇杆遮挡修复。
- 也包含0.2.9气温、多剖面、同模式起点接入导航、扫码完整取景/镜头选择、室内网络定位与重复地图刷新修复。

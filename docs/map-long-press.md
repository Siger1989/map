# 地图长按添加标记

在空白地图上静止按住约半秒，松手后出现“在这里添加”卡片。点击地点标记、长方体、圆柱或球体，即在长按位置保存；不用进入工具菜单。卡片显示目标坐标，地图上的绿色小圈指示位置。

已有标记长按名称、图钉或模型本体约半秒，可拖到新位置，松手后保存；拖动过程中只预览。上方“撤销”恢复上次位置；点击标记仍可进入原参数编辑器。尺寸、颜色、备注等原参数保持。

## 手势与退出

- 快速点击与普通拖图保持原行为；空白长按移动超过8个CSS像素、双指、取消触摸、窗口失焦或地图开始移动都会取消添加。
- 空白长按满550ms并松手才打开卡片；现有标记继续使用480ms拖动手势。长按已有路线或模型不会叠加新标记。
- 绘制路线、地图选点或剖面操作时暂停空白长按入口，原操作优先。
- 点击取消、卡片外部、按Escape或Android返回键关闭卡片；移动地图或改变窗口大小也会关闭，不保存空标记。长按操作会暂停定位跟随，原定位入口可恢复。
- 卡片使用44px触控目标，内部滚动，避开右侧视角控制与底部导航。最多80个标记，存档不可读或空间不足时明确提示并保留卡片，可重试。

模型继续读取原有地面海拔数据；没有有效海拔时不会猜测零海拔绘制，可以从标记详情重试或填写。所有类型使用原`guanyun.annotations.v1`存档，无格式升级。

## 模块与接口

| 文件 | 职责及依赖 |
| --- | --- |
| `modules/map/MapLongPress.ts` | MapLibre空白画布手势；通过`enabled`、`occupied`回调隔离编辑状态，通过`hold({coordinate,point})`通知UI；不写存档，不禁用地图控制；`cancel/dispose/blocksClick`供生命周期与尾随点击处理。 |
| `modules/map/TerrainMap.tsx` | 地图生命周期内装配手势桥；使用现有模型/路线命中检测，公共`onMapHold`向页面发出坐标。 |
| `modules/annotations/QuickAdd.tsx`、`quickAdd.css` | 局部卡片、类型选项、目标指示、关闭与窄屏布局；只调用`onAdd/onClose`。 |
| `modules/annotations/useAnnotations.ts` | 新公开`add(kind,coordinates):boolean`复用原验证、限额、原子存档和海拔查询；菜单放置也调用同一接口。 |
| `app/page.tsx` | 通过props接线，管理卡片及定位跟随状态；存档成功关闭卡片。 |
| Android `MainActivity.java` | 返回键优先向卡片发送Escape。 |

原`FeatureDragBridge`拖动、路线、照片、GPS、图源与高程算法保持。回滚撤销以上新增桥/卡片及props即可，已创建的数据可由原标记模块读取；无文件删除或新依赖。

## 验证

`tests/map-long-press.test.mjs`覆盖时序、CSS坐标、空白/已有对象优先级、多指、移动、失焦、取消、无效地面、尾随点击及释放；既有选择拖动、模型标签和Android返回测试用于回归。

`node scripts/verify-map-hold-browser.mjs`在独立浏览器上下文验证390×844和360×780：直接创建、真实Chromium触摸事件、双指取消、拖动预览与保存/撤销/重载、失败重试、浮窗尺寸与原生返回JS；不改用户已打开页面的存档。截图存`artifacts/screenshots/map-hold-*.png`。

浏览器模拟不能代替Android真机触控验收。本机原签名私钥仍缺失；未签名构建仅用于资源和Java/DEX验证，不是可安装更新包，本轮无新Release。

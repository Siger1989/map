## 多功能页面的按钮区分

- Google Maps 固定导航的 Start，路线进度卡再承载分享、沿途搜索和地图显示。Apple Maps 在路线旁分别给出 Go 与 Steps，让启动和查看各有直接入口。[Google Maps 导航](https://support.google.com/maps/answer/3273406?hl=en) · [Apple Maps 路线指引](https://support.apple.com/en-hk/guide/iphone/ipha84a94043/27/ios/27)
- Organic Maps 把图层放在地图入口，海拔曲线随所选轨迹和实际数据出现。[Organic Maps 轨迹与图层](https://organicmaps.app/news/2025-08-09/420/)
- Android 的 Material 指南分别用实底、浅底、描边和文字表达操作轻重。山兔这版先用在路线卡。工具菜单可按测量、观景与显示、路线等用途组织，仍可保留一屏入口。[Android 按钮指南](https://developer.android.com/develop/ui/compose/quick-guides/content/create-button)

# 二级界面风格统一（2026-09-08）

此前浅色磨砂主题只覆盖枚举出来的主容器，独立浮窗和部分二级按钮仍继承深色主题或模块内硬编码颜色，因此出现深浅、圆角和字号混用。

`modules/controls/modern.css`改为让地图界面中的`.glass`浮窗共享浅色主题、背景模糊及减少透明度设置。补齐画线浮条、快速添加、导航卡片、照片浮窗、图例及剖面控制栏，保留各自位置和尺寸；地图几何和用户自选颜色不改变。

行程/数据/离线/照片、收藏编辑、绘制方式等子页的普通按钮统一12px、14px圆角和浅色底；选中状态为蓝色，主要操作蓝底白字，删除/错误保留深红色。照片全屏工具使用同一浅色主题，图片查看区域保留深底，图像不做任何处理。触控绘制按钮保留44px目标，窄屏允许换行。

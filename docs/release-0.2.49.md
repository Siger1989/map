# 山兔 0.2.49：天地图七类图层与沿线离线地图

- 接入并实测天地图矢量、影像、地形晕渲、三种注记与全球境界。注记可自动匹配或单独选择，图源窗口按现有密度分步骤展示。
- “图层 → 地图图源 → 下载当前地图范围”下载当前底图；“路线 → 详情 → 下载沿线地图”直接下载路线周围。默认两侧各10公里，可选5/10/20公里，支持12/14/16/18级（按图源上限）。开启三维时附带已有来源地形数据。
- 可暂停续传、检查完整性；重复瓦片复用，删除时保留其他包共用资源。“打开范围”恢复下载时的图层组合与清晰度上限。资源/容量/配额错误明确暂停，保持现有离线包兼容。
- 一并包含此前待打包的详情顶部直接改名，以及拉力路书大主指示、完整路名、紧凑速度区和地图避让。

版本：0.2.49-test / versionCode 56。主要修改 cartography、mapSources、outdoor、TerrainMap/terrain、RouteViews、rally 和 app 接线；新增图源目录、区域/路线下载规划及缓存适配。保留原签名、包名、轨迹/收藏/照片和用户布局，不迁移保存目录。

在新的空目录克隆上述实际开发分支，或解压源码ZIP。不要在有未提交改动的旧目录强制切分支、清理或覆盖。

```powershell

cd Shantu-180
git rev-parse HEAD
```

HEAD可能已包含后续交接文档提交，实际功能源码仍以上述f07e1cf提交为检查点。先读 `CURRENT_STATE.md`、`docs/agent-handoff.md`、本文件和 `docs/release-0.2.180.md`。

本轮实测工具为JDK 21.0.13+9、Gradle 9.5.0；Android平台、build-tools和NDK按当前Gradle文件安装。首次接续需要联网下载正常依赖，不照搬本机验证时的 `--offline`。CAD四ABI缓存未打包，首次接续也不能照搬跳过 `prepareSharedCadJni` 的 `-x` 参数。

```powershell

npx tsc --noEmit
npx vite build --config mobile/vite.config.ts --mode native-hybrid
# 配好本机JAVA_HOME、ANDROID_HOME和原有私密配置后，使用Gradle 9.5.0：
gradle -p mobile-native :hybrid:assembleOptimized -PisolatedOldEngine=true --no-daemon
```

这组构建命令不等于手机验收，不把公开/无凭据CI素材当作私人APK交付。

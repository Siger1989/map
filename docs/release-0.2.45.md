# 山兔 0.2.45：选区离线地图、导航重新规划、定位循环切换

- 定位按钮连续点击：正北跟随 → 手机朝向跟随 → 自由浏览。按钮显示“跟随 / 朝向 / 定位”，更多菜单不再重复提供方向模式选择；切换不结束导航或轨迹记录。手机方向依赖设备传感器及权限。
- 导航展开后点“当前位置重规划”，用当前有效位置、原终点和未经过的途经点重新算路；成功后更新导航路线、进度与沿途天气，保留已行距离。失败或停止导航时不覆盖原路线；重规划不会改写收藏路线。拉力导航偏离提示也提供重新规划入口。这是主动重规划，原有自动计算接回路线仍保留。
- “记录 → 离线 → 地图选区下载”：在正北2D视图移动、缩放地图，确认框内范围，命名后下载。支持资源数量预估、暂停、续传、完整性检查与打开范围。沿用现有缓存格式，不影响已有离线包。
- 离线包包含开源道路14级、地形12级和地名字库，不含天地图卫星影像、在线天气或搜索；范围过大时提示缩小，下载需保持应用前台。它是地图显示缓存，离线算路仍需单独下载“离线路网”。下载完成后可选“地图仅使用已缓存数据”并打开包的范围。修复配置天地图后无法切换到开源离线底图的问题。
- 移除底部无操作意义的“路线单色”白条；已开启的海拔数据、剖面与其他色标继续显示。包含此前记录保存/结束修复、导航前台常亮。

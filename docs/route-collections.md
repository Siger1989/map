# 收藏路线与彩色分组

底部“收藏”独立打开收藏菜单，原“道路规划/轨迹管理”里的收藏标签移除。收藏的道路路线和已保存轨迹集中管理，点条目仍打开原路线或轨迹。

- 默认按驾车（蓝）、骑行（绿）、步行（橙）、实走（紫）、导入（青）、手绘（粉）归类。旧带时间轨迹归入导入分类，原来源说明保持。
- 上方分类横向滑动筛选；“新建分组”输入名称、选择颜色；“管理分组”点击组名修改，拖动手柄改变组顺序。
- 拖条目右侧手柄上下排序，拖到分类标签或另一组的条目换组。列表正文仍正常滚动；拖动到边缘自动滚动。松手才保存，移出窗口、Escape、取消触摸或双指介入取消。
- 不使用拖动时，可点“…”选择分组、上移/下移。手柄也支持键盘上下方向键。
- 删除分组只把所属路线移到“未分组”，不删除原路线/照片。移除道路收藏保留原入口，轨迹本身仍从轨迹管理操作。

## 模块与接口

`modules/collections/data.ts` 定义分类、验证、条目视图和纯排序函数；`useCollections.ts` 负责元数据加载与写入，成功后才更新界面；`useCollectionDrag.ts` 负责手柄指针、取消和边缘滚动；`CollectionsPanel.tsx` / `GroupEditor.tsx` / `collections.css` 提供独立菜单和编辑步骤；`transfer.ts` 提供备份合并。

通过 `favorites` / `tracks` 只读条目和 `onRoute` / `onTrack` 回调接入。ControlDock 增加独立底部入口，app 仅装配公共 props。原导航算法、照片、标记、天气、GPS、地图图源不变。

整理数据使用独立本机键 `shantu.route-collections.v1`，保存组名/颜色/顺序、条目归属和条目排序。`route:` / `track:` 前缀避免编号冲突；路线坐标、时间、照片、导航结果仍在原存档中。现有存档无需改写或迁移。分组名称最多 30 字、最多 64 组，原道路/轨迹各 20 条的容量保持。

JSON 备份增加可选 `collections` 字段，版本 1 和旧备份继续可用。`outdoor/exchange.ts` 与整理模块通过导入映射通信：原记录 ID 冲突时，新记录及其分组引用一起换 ID；保留本机已有分类选择，组 ID 内容冲突保留双方。包含分组的所有写入共用原备份回滚流程。GPX/KML 保持原通用格式，不包含分组；JSON 备份仍不包含照片文件。

回滚可撤销本轮模块、菜单和备份接线，保留新增元数据键；旧版仍能读取原路线/轨迹，新版重开恢复整理信息。本机存储清除会丢失收藏和分组，跨设备使用需导出/导入 JSON 备份，并非在线同步用户行程。

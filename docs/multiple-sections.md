# 多剖面对象（0.2.9）

工具 → 剖面打开列表，点新建在视野中放置独立剖面，最多20条。各自保存名称、位置、海拔、尺寸、角度、颜色和显隐状态。地图同时显示多条矩形面及采样交线；点击面或列表的查看按钮，使用原三维操控器、剖面图和测点工具。列表支持改名、显隐、删除及撤销最近一次删除。

列表不超过38dvh/320px，按钮44px。未选对象保留轮廓与交线，精细刻度和测点编辑只显示当前对象，避免满屏手柄。

## 模块与兼容

- `sectionObjects.ts`定义稳定ID与完整参数校验；`useSavedSection`负责集合存储、独立修改、删除/撤销、历史测点所属对象恢复。
- `SectionList`为列表入口；`SectionCollectionLayer.configure/pick/dispose`管理未选对象图层，复用`SectionSurfaceLayer`和原地形采样。选中对象继续使用原剖面图。未改地形裁切算法或标记内部状态。
- 新键`shantu.section-objects.v1`保存数组。没有新键时读取旧`shantu.section-object.v1`为“剖面1”，旧键保留；明确保存空数组后不复活旧对象，坏存档不自动清空。
- 新对象可选`SectionSettings.objectId`区分同位置剖面的测点键。旧剖面保留原测点键。几何变化后的历史测点可通过原恢复入口查看，不把旧采样值当作新位置测量。
- JSON备份增加可选`sections`，版本仍为1，旧备份有效。冲突ID重新分配；先校验完整数据和20条上限，写入失败复用原回滚流程。此字段包含对象几何和显隐，既有测点历史仍在原测点存储模块。

回滚可撤回本轮多剖面文件和接入，旧单对象存档仍保留。旧包不会显示新增多剖面数组，不能称为兼容新功能。

## 验证

回归覆盖旧迁移、空集合不复活、坏数据拒绝、独立修改、重复ID/非有限参数、备份冲突和超限不写入、同位置测点隔离；安卓返回优先关闭路线对话框或剖面列表。

390×844/360×780浏览器放置两条3828米剖面，独立保存-35°/+35°方位并同时显示不同颜色交线；重命名、隐藏、删除/撤销、刷新后保留两条和显隐状态通过。选中剖面2显示其名称、地形交线与实际海拔采样。未进行OPPO真机多剖面性能和触控验收。

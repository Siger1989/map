# 山兔0.2.33-test：贴边适配与组内组件调整

「更多 → 布局 → 参数 → 选择范围」支持整组、组内组件、单控件和任意元素。整组操作整个外框；组内组件直接点选最近的独立按钮、卡片、图例等，单独修改尺寸、位置、字号和显示层级。「外层」切回父组。切换范围保持当前选择，多选仍可用，父子同时选中时只调整外层一次。

包含0.2.32全部改进：

- 进入布局保留当前功能页面；操作工具条不会触发外部点击关闭。
- 手机默认40px高的一行可拖工具条，没有常驻组件清单；移动、大小、使用分开，减少误拖。
- 默认整体缩放：八边角或数值宽高调整时，文字/图标/间距同步变化，保留原居中/靠边对齐。缩放固定当前所贴边，取消整体缩放才只调外框。
- 跨手机贴边：移动后记录相对安全区或父组的边距，靠右/靠下缩小时边距不变，居中组件保持居中。参数显示当前锚边；改变尺寸、旋转、保存后重开或导入另一部手机时重算位置，旧草稿按原样读取。
- 字号显示首处文字的实际显示px；移动有细粉色对齐线与吸附；上一层/下一层调整同父级遮挡。
- 保存后重启继续使用，参数→更多→导出布局得到shantu-layout-draft.json，后续可依照草稿统一优化。旧布局格式兼容，用户草稿不会默认写入安装包。

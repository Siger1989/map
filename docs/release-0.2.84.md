# 山兔 0.2.84 测试版

版本 `0.2.84-test` / versionCode `91`，Android API26及以上。独立包 `com.guanyun.weather.shantu.preview` 及原签名沿用，可覆盖安装；原图源、轨迹、照片和布局存储格式不变。

- 撤回强制隐藏Android状态栏和导航栏，恢复原顶部及安全区处理。
- 从手机文件管理器用山兔打开或分享OVMAP，自动进入图源解析与导入确认；普通路线文件仍走原路线导入。
- 外部瓦片连接支持已验证公网DNS地址间回退及标准公网NAT64；单层影像无需OffscreenCanvas，合成提供普通Canvas回退。失败显示不含地址或凭据的阶段提示。用户反馈所有外部图源失败尚未取得真机网络证据，不能据此宣称全部服务已恢复。
- 图源选择记住会话内分类、搜索、筛选和列表滚动位置。
- 双图竖屏上下、横屏左右；底栏按可用宽度均分；顶部复用地点搜索；两幅地图统一使用常规延长棒画线与草稿数据，点位/道路/河流吸附放在下图底部指定位置。

本机APK继续显式注入全部39项购买图源，首次写入后可删除，重启不补回。含访问凭据的配置不进入Git或自动公开Release；已有37项初始化标记的安装不会自动补回/重置图源。构建方式见[0.2.83说明](release-0.2.83.md)。

源码检查、APK完整性与实际手机验收分别记录在CURRENT_STATE。浏览器读取接口连接失败，无法新增实际布局截图；手机外部图源显示、文件打开、旋转及画线需真机验证。HarmonyOS6.1原生HAP/APP仍未交付。

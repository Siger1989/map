# 天地图加载系统 · 2026-10-27

## 已确认目标与范围

用户明确授权先建设地图加载系统，解决手机内置天地图首屏空白和拖动/放大缺块；保留现有功能与UI，完整原生重建暂缓，`mobile-native/`与完整备份保留。

本轮在现有React/MapLibre/WebView架构内实施，保留用户注册Key、内置图源入口、相机、画质、DEM、标记、导航与数据格式。实际分支 `codex/tianditu-loading-20261027`。私人预览使用本机配置；固定APK仍为141，未转入安装交付前不覆盖。

## 功能与施工

1. 普通在线内置天地图瓦片通过MapLibre自定义协议，连接共享加载器；主图、双图、路线小地图和固定级别取图使用同一加载器。原HTTP地址与Key保留；不更换图源或绕过额度。
2. 独立浏览缓存：内存与IndexedDB，持久化键仅SHA256，不保存URL/Key；容量有界，遵守响应缓存策略。原离线包及仅缓存显示优先，不自动批量下载。
3. 网络请求有界：初始4路，合并同图块并隔离不同Key；消费者独立取消，最后消费者取消释放请求；全请求超时覆盖响应体。
4. 429及带Retry-After的503共用服务冷却；按服务端等待，不切域绕过。超时/暂时失败有界恢复，401/403/404不反复重试。
5. 仅补载当前地图仍需要的失败瓦片；成功瓦片、相机、图层选择和编辑任务保持。移动手势期间暂停自动补载，地图销毁清理监听和计时器。
6. 脱敏统计支持缓存命中、请求、取消、超时与限流排查。当前初始并发是保守配置，不宣称已经测得最佳速度。

- 行为测试：并发上限、去重、单/全消费者取消、悬挂响应超时、Retry-After长值/跨子域冷却、无效图片不入库、缓存持久化及禁缓存响应。
- 集成测试：普通天地图确实进入自定义协议；非天地图原样；仅缓存模式不联网；主/双图共享，失败定向补载，地图销毁不再重试。
- 类型检查、私人web构建、390×857/360×780实际预览，正常/失败恢复与相机不变。截图不能用模拟地图冒充真实天地图加载成功。

### 实际改动

- 新增 `modules/mapSources/tiandituLoader.ts`：4路并发、最多256个排队请求、跨子域去重、独立取消、12秒请求总超时、有效图片校验及限流冷却。后续复测修正为每250ms启动一个请求；429/503后至少1000ms间隔。可读到Retry-After时遵守服务器时间，缺失或无效时30/60/120秒退避。冷却期间排队、允许取消、已有缓存立即可用；超长冷却不会溢出为忙循环。网络使用no-store，成功瓦片仍按响应策略进入独立浏览缓存。
- 新增 `tiandituProtocol.ts` 与 `tiandituRecovery.ts`：内置图源进入统一协议，只定向补载当前可见失败瓦片，每个稳定视图每瓦片最多3次自动补载，间隔至少750ms；手势、隐藏页、离线、地图销毁均受控。
- `TerrainMap.tsx`（主/双图共用）、`RouteMiniMap.tsx` 与 `tileTransport.ts` 的固定级别直接取图接入；后续补充官方t0–t7的合法DataServer导入地址进入同一调度器，保留原地址参数与Key；其它导入图源和显式离线下载传输保持原有机制。
- `browserTileCache.ts` 增加冷启动 ready 接口；新库128MiB/8192条，内存层沿用有界缓存。无服务器缓存信息时默认5分钟，服务器指定有效期上限24小时；不是永久离线地图。缓存键仅散列，摘要/存储不可用时退化联网。
- `outdoor/tileCache.ts` 给既有Mac分支增加window存在性保护；显式离线包优先及仅缓存禁止联网不变。
- 新增三组测试文件；原离线、浏览缓存及图源传输回归同时执行。

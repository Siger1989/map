# 地点搜索

配置有效 `NEXT_PUBLIC_TIANDITU_KEY` 时，顶部搜索默认使用天地图地名搜索 V2.0。查询全国范围，最多请求10条点位，去重并校验经纬度；顶部“搜索数据源”可切换全球 Photon / OpenStreetMap。未配置时仍使用 Photon。

路线规划地名检索优先天地图，无点位结果时保留 Photon 回退；服务授权/网络错误不会静默吞掉。明确离线模式仍只搜索已下载路网道路名，不发在线请求。地图中心地址反查、路线计算、底图、保存格式均不变。

天地图接口通过 HTTPS 请求，复用项目已有浏览器应用 Key；不新增密钥，不在日志输出 Key 或完整请求 URL。返回的 `lonlat` 按官方顺序经度、纬度保留，不作 GCJ 偏移；POI并非测绘控制点，不能保证山峰坐标精度或完整覆盖。同名景区、商户、乡镇会保留，可通过地址区分。明确返回中心坐标的城市/行政区以“行政区中心”注明，统计、建议和边界不充作点位。

官方接口说明：https://lbs.tianditu.gov.cn/server/search2.html

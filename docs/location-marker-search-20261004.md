# 2026-10-04 标记、搜索与定位续验

## 当前实现与行为约定

- 标记备注为88px多行文本区；自定义属性的滚动只发生在列表内部，高度上限148px，对应最多5行（28px行高、4px间距）。主图/双图均需维持其余按钮可达。
- 中心准星保持中心坐标，尺寸52×52px、中心开口38px、四臂opacity 0.68且中心无描边；地点气泡三角指针加长16px，尖端仍锚在原地理坐标。
- 标记名称编辑是普通输入框，不显示自动地点建议。长按480ms开始拖动，松开持久保存，双指取消；主图与双图共享行为。
- 用户更正隐藏语义：标记的隐藏/显示改变标记几何及其照片的可见性，编辑面板继续打开；规划路线隐藏同时作用于地图路线、端点与同一路线的收藏副本，面板继续打开；已记录实体hidden只改变地图可见性，详情面板保留。不得将实体隐藏实现成关闭面板。
- 搜索结果可在列表内纵向触摸滚动。排序参考使用新鲜且非IP来源系统位置；没有该位置时以地图中心作为参考，并清楚标示“地图中心参考”，不宣称GPS。Photon调用添加lat/lon、zoom=12、location_bias_scale=0.1；天地图仍为现有国内搜索源。
- 定位优先系统定位；IP粗略位置只在权限拒绝、定位失败或等待6秒后作为回退。浏览器可复用持续watch，原生位置轮询间隔250ms；IP位置标识估计误差约50km且120秒后过期，后续系统定位覆盖IP结果。IP估计点、标签与当前定位均以灰白色显示；无有效航向时显示圆点，不猜测IP方位，仅有有效航向时才显示灰白箭头。模拟航向不等于硬件罗盘验收。初次定位可放大至16级，之后保留用户缩放；等待/错误/暂停状态不可伪装成实际跟踪绿灯。

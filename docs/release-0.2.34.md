# 山兔 0.2.34-test：保留布局、清晰层级与行程点数据

本版将已完成的布局修正加入安装包。覆盖同包名、同签名的山兔独立测试版时继续读取已保存布局；启动不会用新默认布局重置用户位置、尺寸、比例、字号、锚边或层级。布局存储键`shantu.ui-layout.v1`与JSON version1不变。保留应用数据覆盖安装，不需卸载旧版。

## 使用与变化

- 左上角头像页直接显示「调整布局 / 导出布局 / 导入布局」。导出`shantu-layout-draft.json`可备份、换设备导入，或作为后续视觉优化基准。退出编辑不再残留左侧常驻布局按钮，右侧更多入口保留。旧版导出藏在布局→参数→更多。
- 海拔剖面图在「组内组件」模式下点曲线可选完整卡片外框；任意元素/层级菜单仍能单选内部图形。独立控件移出装饰父组后保持显示和点选，真正滚动列表仍保留滚动。
- 大小模式显示对齐辅助线与吸附；拖左边改变左边，拖其他边角同理固定对边。数值尺寸保持已有贴边位置；默认文字、图标、间距随整体缩放。
- 层级可选「页面层 / 组内层」，显示实际调整对象和数值。页面层调整所属堆叠父组，解决子项数值再大仍被其他组遮挡；组内层只改当前控件。当前选择和功能页面保持。
- 点选已选行程的节点或路线位置，显示海拔、带方向路段坡度/角度；展开点数据可查看点序号、沿线里程、经纬度、记录时间及区间速度。高程优先原轨迹，缺失时使用已有地形读取/缓存，并标明估算来源。暂停/断段不拼接，没有真实记录时间时不伪造速度。

## 模块与范围

`modules/uiLayout`新增共享裁切/缩放/文件交换和头像设置视图，修正选择、会话、层级及手机工具条；`tools/layout-editor`复用共享接口。`modules/help/AboutPanel`挂载头像入口；`modules/routeAnalysis/pointMetrics`与`RoutePointSummary`提供只读点数据，`modules/tracks/RouteViews`与`app/page`最小接线，删除重复单点高程请求和节点里程固定0。地图手势、原轨迹存档、离线引擎/缓存、定位记录、照片分享与通信业务未改。

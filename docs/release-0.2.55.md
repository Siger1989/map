# 山兔 0.2.55 测试版：个性化配色与紧凑地图操作

整合9月22日反馈及上一轮尚未公开交付的0.2.54修复。保留既有轨迹、照片、标记、布局、包名与签名。

- 山兔Logo内新增个性化：浅色、深色、跟随系统和三套预设；主色、窗口背景、按钮底色、文字独立调整，支持实时预览、保存和恢复默认。菜单、路线、画线、工具统一按钮与底板风格。
- 路线缓存并入同一排操作，来源与高程提示合并，正反向按钮上移。画线入口放底部，移除绘制前重复选项及已保存轨迹列表，已保存轨迹继续从收藏查看，绘制中吸附功能保留。
- 导航小地图增加加减按钮与3D摇杆；加强页面及Android WebView缩放限制，保留地图自有缩放操作。
- 原始导航路线与已规划方案同图展示，选中高亮；切换方式复用结果，明确点击才重新规划。方案在当前应用进程内保留。缩略底图接入天地图/离线请求与失败重试。
- 修复联网打开离线包后残留14级清晰度上限；纯缓存和图源自身上限仍保留。缓存区域选中绿色高亮约3秒；未完成包标计划范围，旧包无法还原覆盖时标外接边界。修复离线移除重试与并行下载进度问题。
- 记录窗口照片去重、移除返航、同类功能分组；结束保存等待最终快照并核验，失败保留重试。方向与跟随独立；锁定/收藏保留3D摇杆，海拔小色标移至右栏。

# 山兔 0.2.26-test：节点吸附拼合、同色汇总与电脑网页版

## 修改内容

- 修复编辑路线拖节点只改坐标、不合并目标存档的问题。进入“编辑”，开启“节点吸附”，点选自己的节点后拖到另一条路线的可见节点，14 CSS像素内锁定准确坐标；松手预览拼合，可撤销，保存后合为一条存档。
- 编辑时显示其他可拼合路线的节点；拾取先排除正在移动的路线，防止预览节点遮住目标。隐藏、实走原始记录和带原始采样的受保护路线不作为拼合目标。
- 端点相接合成连续线，中间节点连接保留真实分岔。保存沿用第一条可编辑路线ID，删除已并入的其他来源存档；颜色、同色备注及照片来源关联保留，标记重新绑定。100条存档时也可合并减少数量。
- 合并使用收藏存储事务，同时提交路线与标记关联；来源被其他窗口修改则阻止覆盖，存储写入失败回滚。
- 路线详情、行程高度图图例和分享图路况说明改为一种颜色一项：累计同色长度，取所有对应区间的海拔范围，保留合并后的备注。红—绿—红只列红、绿两项；选红色同时高亮两处红色。地理形状、实际里程和缺测断点保留。
- 分享图最多展示16种颜色的说明，超过时明确提示通过完整路线包查看；原路线包、二维码、GPX/KML的色段及备注数据保持兼容。
- 头像内“连接与合并路线”教程补充直接拖动拼合与同色汇总步骤。
- 增加 Windows/Mac 本地网页包，解压后使用对应启动脚本；首次需安装 Node.js 22.13+ LTS，无需项目依赖或安卓模拟器。包含473区域地形及4个现有API的本地适配，不需要在线托管或OpenAI登录。

## 模块与回退

新增 `modules/tracks/nodeJoin.ts`（精确节点拼合）和 `joinedEditStore.ts`（跨存档事务），复用现有几何、颜色继承和收藏事务接口。修改 `FeatureDragBridge`、`TerrainMap`、`TrackLayer` 的目标拾取/预览接线，`routeEdit`、`useManualTracks`、`RouteViews`及 `app/page.tsx` 的编辑保存；`colorSections`、`ColorElevation`及 `routeShare/image.ts` 的按色汇总；`help/tutorials.ts`和版本配置。

移除拖动路径“只改坐标”的缺口，以及图例中同色重复条目；没有删除数据格式或照片文件。剖面、测量、天气、定位、相机、地图源和导航算法不改。回退需整体回退本次业务提交；新存档结构仍兼容旧版，但保存后的拼合只有一个存档，恢复原分离状态需预先导出的备份。

## 安装与边界

Android：`Shantu-0.2.26-test-standalone.apk`，0.2.26-test / code33，Android8.0+，包名 `com.guanyun.weather.shantu.preview`，沿用4a94独立测试签名。可覆盖同包名同签名独立版，与原 `com.guanyun.weather.preview` 并存，数据不自动迁移。

本机无ADB手机；实际手机安装、手指拖动及系统保存分享仍待真机验收。HarmonyOS6.1原生HAP/APP未交付，此APK不是原生鸿蒙安装包。

同步到 `codex/huawei-webview-touch`，未合main；测试标签 `v0.2.26-test-standalone`。

电脑产物 `Shantu-0.2.26-test-Windows-Mac-Web.zip`。安装一次 [Node.js LTS](https://nodejs.org/en/download)，解压后 Windows 双击 `Start-Windows.cmd`，Mac 双击 `Start-Mac.command`（或终端 `sh Start-Mac.command`）；浏览器打开固定地址 `http://127.0.0.1:8787/`。保持启动窗口打开；数据在当前浏览器本地，和手机用JSON备份导入交换，不自动同步。地图/天气/区域外高程仍需联网；网页后台记录及系统分享有浏览器限制。详见包内README。

电脑模块新增 `desktop-web/server.ts`及README、`scripts/build-desktop-web.mjs`，以单向导入复用现有app/api；只监听本机，拒绝其他Host、目录越界和非GET/HEAD请求。构建目录和QA样本加入.gitignore，防止打包副产物进源码库。回退电脑适配可单独删除这些新增文件，不影响安卓业务。

# 山兔 0.2.54 测试版：导航方案保留与地图操作优化

本版按9月22日集中反馈修订，保留原有路线、照片、标记和布局。

- 导航原线和已规划的步行/骑行/驾车方案同时显示，选中高亮；切换不重复算路，首次明确规划、再次明确重新规划。应用进程内保留方案，应用重启后需重新生成备选。导航缩略图接入天地图及离线缓存请求，增加失败重试。
- 记录窗口照片去重、取消返航入口、功能底色分组、导入导出与离线地图明确命名。暂停/继续保留；结束直接“结束并保存”或“取消并结束”，无需再清空。保存等待最终记录快照并核验，失败保留可重试。
- 离线包允许在另一包下载期间移除；当前包先停止再清理，缺失原生任务可重试，共享瓦片保留。修复联网时继承14级缓存上限的问题；图源本身上限仍保留。
- 选中缓存包绿色标范围约3秒。完整天地图包显示14级或所选更低级别覆盖；未完成包标计划范围，旧包无法还原覆盖时标外接边界。
- 方向和位置跟随拆为独立按钮；收藏和锁定保留3D摇杆。海拔小色标放右侧栏，与按钮/摇杆避让。

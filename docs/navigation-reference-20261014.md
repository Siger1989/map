## 改动

- `GuidanceCard.tsx`、`guidance.css`、`outdoorSurfaces.css`：紧凑导航卡分出标题操作和主指引，距离34px、单位16px、指令14px；剩余里程直接使用 `g.remaining`。错误/定位质量优先，辅助视角提示不覆盖主指令。第一人称高亮、展开/返回/结束保留。
- 新增 `maneuverPresentation.ts`：只根据已有明确转向文字选择 Lucide 图标，未知说明使用通用图标，不推测车道/红绿灯。没有添加不存在的实时交通数据。
- `NavigationCueLayer.ts`、`navigationCueGeometry.ts`及新增 `navigationCueImage.ts`：沿现有导航折线显示前方最多500m绿带；最多5个小V，附近大箭头会替代相邻小V。前方至少剩60m时，在 `min(50m, 剩余×0.65)` 处显示一个白色蓝边指引，按该处真实路线切线旋转。本地 Heroicons/Lucide 路径生成普通RGBA图标，无新增在线图标资源。沿用累计里程缓存，10万点路线后续更新保持局部采样。
- `PositionLayer.ts`：导航时蓝色箭头放在固定屏幕大小白色圆盘内；IP估计不获得导航圆盘，退出/丢失位置恢复普通状态或清空。
- `overlayData.ts`：近景宽路线位于可见地名之下，端点说明、前方箭头和当前位置保持可读；非近景沿用原有排序。连续100次相同同步无重复图层移动。
- 定向测试新增/更新在 `tests/guidance-maneuver-presentation.test.mjs`、`navigation-cue-layer.test.mjs`、`forward-navigation-ui.test.mjs`、`navigation-position-visibility.test.mjs`、`place-label-layer-order.test.mjs`。未删除业务功能或用户资产。

## 追加：已走路线显示为灰色

用户要求“走过的路变成灰色”。主图通过 `app/page.tsx` 将活动 session 的米制 `progress` 接到 `RouteOverlay.navigationProgress`，它与前视/俯视和定位当前是否可跟随无关。因此偏航、定位质量中断时沿用已经确认的进度，不用外部位置推算新进度。

- 新增 `modules/navigation/routeProgress.ts`，按原路线/segment 的累计地理距离切分已走和未走段。缓存累计距离、二分定位边界，完整段复用原坐标；段间距离计入进度但不画新连接线。先画已走、再画前路，保留往返/闭环方向和 access 虚线。
- `RouteLayer.ts` 中已走段为灰色 `#8e999b`，未来道路为绿色 `#39c878`。近景灰段14px、外轮廓18px，普通视图4/8px；未来近景绿带由原 cue layer 绘制。近景绿色 ribbon 从当前进度点开始，修正之前向后20米覆盖灰线的问题；终点不输出零长带。
- `types.ts` 仅添加显示态 `navigationProgress` 和 `navigationClose`。结束导航撤销进度后恢复原 displayParts/路线颜色；保存路线、图源、导航计算与原生能力未改。手机与PC共用实现，未新增或删除产品控件。

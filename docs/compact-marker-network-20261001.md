## “推荐超强”网络证据

只读本地私有合集准确匹配该源，一份HTTPS443模板、一个主机。输出仅包含脱敏阶段与时长，未输出或公开上传地址、凭据或二维码。

- 本机 DNS 得到一个公网IPv4，无IPv6；TCP约41ms，TLS原主机证书校验约98ms成功。
- 使用已验证IPv4、原SNI/Host、原生UA、无Cookie/Referer、12秒总deadline的raw TLS GET：12.013秒仍未收到响应头。
- OSM对照12.002秒未收到响应头，TLS没有完成。两请求共12.169秒结束，没有HTTP状态/MIME/图片字节可检查。
- 本机结果不能证明图源服务器故障、手机代理/VPN问题、鉴权限制或运营商拦截；也不能据OSM失败判断全部图源不可用。与手机“推荐超强”测试仍需对照。

原生网络适配器有 `dns/blocked/connect/tls/timeout/upstream_http/format` 分类，`LocalGateway.java` 发送 `X-Shantu-Tile-Error`，前端已有中文映射。电脑Node代理catch只回通用502而没有该分类头，不能混作手机行为。原生12秒总预算已实现，Node的socket空闲超时也不能被说成相同总预算。

下一步诊断应区分DNS/TCP/TLS/等响应头/读响应体，保留耗时、状态、MIME及字节数等脱敏信息，并补齐Node分类头；当前原生timeout尚未细分为首字节和响应体阶段。先获取手机实际中文错误、VPN状态及同手机其它地图应用对照，再决定需要何种适配。公网DNS保护、TLS校验、格式校验保持；本轮没有新增绕过代理功能。

本轮仅修改UI和记录调查，没有升级版本、打APK、提交或推送。已交付0.2.91 APK不包含本轮紧凑化及前一轮双图宿主修复。

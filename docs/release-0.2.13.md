## 本次改动

- 修复从节点拉分叉时旧路线中间节点消失：绘制期间旧节点持续可见，并参与精确吸附，新线可接回旧节点形成闭环；原线几何不丢失。
- 点选地图节点直接出现一排“＋、−、分叉、连接、撤销、完成”，草稿和已保存路线都能操作。取消额外详情菜单与连接坐标下拉框；按“连接”后直接点地图另一节点。草稿操作可撤销，“完成”保存；误添孤立单点可删除，前后点直连。
- 新绕路接回原路线的两个共同节点后，自动成为不同颜色的备选。默认原路保持原顺序；备选完整线为前半段＋绕路＋后半段，跳过连接点之间的原段，避免重复计里程。选备选时被跳过原段淡化。
- 左侧两条细进度轨道收在原有44px宽区域内，每条视觉10px；起终点与里程标签只保留一份。点轨道或顶部切换按钮选择原路/备选，拖动浏览对应路线，沿线标记按该路线计算。
- 仅识别真实共同节点之间的回接路径；画面交叉、断开的线、未接回的分叉不作为完整绕路。复杂网络最多显示8条单独备选，多个备选可通过顶部按钮循环；不自动穷举所有绕路组合。选择进度条用于浏览，不改变已有GPS导航的最近接入和相连分叉自动切换规则。
- 保留0.2.12的默认卫星、文件夹分类/底色/固定关闭、导航起终点方向等功能；地图和轨迹数据格式、照片关联及原签名保持兼容。

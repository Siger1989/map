# 山兔窗口、导航层级与操作位置总规范

2026-11-11，依据用户本轮明确要求建立。本规范补充 `ui-standard.md`；同类型关闭、返回、标题位置与二级层级呈现按本规范执行。保留深色/黄绿主题、用户数据与业务语义色。它不是全功能重新设计，也不改变原生地图、定位、记录或存档契约。

2026-11-11追加：路线出发确认页直接选择驾车/摩托车/骑行/步行；有限二级操作优先紧凑网格一次显示完，不依赖滚动。详情替换操作列表并按可用屏高展开，普通屏不得为了硬凑200px强制内容滚动；矮屏、长数据/来源说明保留可达的真实滚动。

## 1. 层级与行为

| 场景 | 左侧 | 右侧 | 行为 |
| --- | --- | --- | --- |
| 一级窗口 | 标题 | X | 关闭当前窗口，回到地图；不再同时显示作用相同的“返回地图” |
| 二级页 | 返回 | X（仅与返回作用不同时） | 返回恢复父页；X退出整个窗口；父页原选择、滚动与输入应保留 |
| 三级页 | 返回上一层 | X（退出整个窗口） | 标注直接父级，逐层返回；不连续叠加同名卡片 |
| 临时确认对话框 | 标题 | X或取消 | 取消本次确认并回到发起页；不得等同于执行删除、保存或结束任务 |
| 有未保存内容 | 按当前层级 | 按当前层级 | 退出遵循已有草稿保存/放弃保护；不得因规范化悄悄丢失输入 |

“返回”只表示回上一级，不用于一级窗口回地图。相同回调的返回和X不重复渲染；语义相同但使用不同闭包的场景需人工核对。关闭窗口不自动结束记录、导航或删除对象；“结束导航”等业务动作独立保留。

## 2. 统一尺寸与位置

- 标题关闭按钮使用 `ui-panel-close`，36×36 CSSpx，lucide X为18×18px，4px控件圆角，主题柔和暖黄色。禁止各模块再使用文本乘号或独立的28/44px关闭按钮。
- X始终位于标题栏最右侧，同类浮窗距外框上/右边至少8px；边框及显示比例带来的约1px差异不视为布局换档。标题文字距外框至少10px。
- 一级、二级共享标题栏均44px；二级父级提示与标题在同一标题槽内排两行。返回、标题和X垂直居中，按钮使用与二级标题栏可区分的独立底板，不连成整块。X仍在同一上/右定位槽。
- 返回在标题左侧，图标加“返回”，至少36px高；X和返回不能因标题长度换行、被压缩或滚出窗口。标题可截断并提供完整文本，主要动作文案不可截断。
- 独立门户弹窗标题用8px内距，必要时增加标题高度保证36px按钮完整。主图、双图和portal弹窗使用相同关闭样式，不因DOM宿主不同重写尺寸。
- 保存/确认放固定操作区最右或明确主操作位置；取消在其左。确有即改即存的设置不额外加保存按钮。主操作和地图直接操作保留44px热区，密集设置按已批准的28–36px规范，不把关闭尺寸推广到所有按钮。

## 3. 二级视觉识别

- 使用“父级名称 /”小字、明确返回入口、略有区别的标题底色，以及轻微下方阴影。
- 深度不能只靠阴影或颜色表达；父级文字与返回行为必须同时正确。
- 保持同一卡片和同一锚点替换内容，不因进入子页跳到屏幕另一角。浮层型编辑器需遮挡/焦点规则一致。
- 共用 `MapPanelHeader` 通过 `data-ui-level` 输出层级；独立标题组件按同一规范接入，不猜测业务父子关系。

## 4. 参数与状态

- 每个图层的参数入口跟随对应图层；展开内容在该图层行下方，不再集中在列表底部。无参数不显示空入口。
- 参数展开只改变页面状态，不切换图层、不重置参数；主图和双图保持各自参数。道路/注记共用参数应明确说明真实作用范围。
- 导航收起状态也显示等待定位、精度不足、偏航和到达；无可信速度时不以空速度占主信息区。网络定位接入策略另行处理。

## 5. 施工与门禁

1. 先判定一级/二级和返回目标，检查是否与X重复，再接入共享标题或关闭类。
2. 清理会覆盖共享尺寸的旧ID级规则；检查computed尺寸、min/max、padding、flex及伪元素命中范围，不能只看CSS声明。
3. 390×857和360×780检查主要页面；内容溢出要真实可滚动，标题固定。矮屏、键盘和更深层编辑视情况补验，不冒充已验。
4. 实际点击返回、X、参数展开并确认状态；截图与测量记录绑定本轮源码。主图、双图与门户弹窗至少各取样。
5. 视觉预览不升版本、不打包、不提交推送，直到用户确认交付；浏览器结果不代替Android真机触控和原生桥接验收。

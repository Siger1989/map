# 顶部地点搜索

地图上方现在可以直接输入城市、街道或山峰名称，无需进入路线面板。

- 搜索框与山兔标识、世界地图按钮共用一行44px顶栏，保持原磨砂样式。空输入框同时提示当前地图中心地名。
- 输入至少两个字符后自动搜索，支持回车或点放大镜重新搜索。中文输入法组词期间不请求服务。
- 结果显示地点名及所属区域，最多五项；选择后地图移动到该地点、收起结果和软键盘，并暂停当前位置跟随。
- 支持清空、关闭、Esc收起、上下方向键选择结果和回车确认。点其他工具会收起搜索结果。
- 复用路线功能的Photon/OpenStreetMap搜索、缓存与请求节流。网络错误、无结果和短输入都有提示；关闭、改词或卸载时中止旧查询。实际覆盖和网络可用性取决于现有服务，不代表新增国内搜索服务。

## 实现范围

`modules/controls/PlaceSearch.tsx`负责搜索交互；`PlaceName.tsx`提供共用地图中心地名标签；`app/page.tsx`负责地图定位接线；`modern.css`提供同一行顶栏和内部滚动结果布局。原路线搜索、图源、存储、签名、3D控制器保持兼容。

## 固定布局

- 白底黑字，宋体/SimSun优先，细黑网格；标题居中，下一行比例尺。顶栏三组信息：左开孔日期/终孔日期/孔深，中X/Y/孔口标高，右钻孔方位/倾角。不得用全部Excel字段的大信息卡替代。
- 表头三级合并，纵排表头；主体竖线从表头贯通孔底。左起：回次；回次进尺（米）[自/至/进尺]；岩芯采取[岩芯长/采取率]；层位；换层深度；分层厚度；岩芯长；分层采取率；柱状图；岩性描述；标志面与岩芯轴的夹角；采样情况[样品编号、采样位置（米）[自/至/样长]]；岩矿芯长；采取率；分析结果[自定义元素横列]；钻孔结构；备注。
- 基准绘图坐标：左边28，上表头272，高158；每窄列54；柱状162（内左27留白/中98图案/右37样号标记）；描述486；钻孔结构及备注各108。3元素时表宽1998，6元素时2160。标题48，元信息20，表头20，正文14（紧凑数值可缩至11，不移动深度）。所有端共用这些值。
- 主体深度固定线性比例：比例尺分母100时每米80/3绘图单位，其他比例尺按100/分母缩放。不得因元素数量/标签增多改变纵深或抽离标签。短孔仍使用该比例。主图沿全孔深，详图0–45m仍同一比例。
- 回次行仅横跨回次六列，分层行仅横跨层位至描述相关列，采样横线仅采样与分析列；各行按自身深度绘制。层位数值靠层底，描述靠层顶，回次/采样数值居中。柱状图沿深度绘制图案，样品小黑段及样号贴右侧。不要增加独立深度尺/彩色线/游离引线。
- 分析项目按自定义show/order逐项横列，保留原始未检出文本及空值；不加结果标记。缺失数值留空，不虚构。长样号可收窄文字，不改变行位置。
- 底部并排三个区域：左孔深校正记录表（序号、记录孔深、校正孔深、误差米、误差率‰）；中弯曲度测量表（序号、校正孔深、方位角、倾角、天顶角）；右图签（单位/图名整行，拟编-顺序号、审核-图号、制图-比例尺、项目负责-日期、单位负责-资料来源）。无彩色表头，无额外“图签”标题。误差率显示千分比=既有百分比×10；倾角仅在有天顶角时按90-天顶角注明数据派生，原数据不改。图签比例尺与图面主比例保持一致，采用基本信息的比例尺优先，缺失才用图签，最终缺失默认100并记录默认。

# 山兔 0.2.46：地点分享

- 搜索结果右侧新增分享按钮；长按地图可“分享位置”；已保存地点标记的摘要增加“分享”，详情页分享也进入同一地点分享窗。
- 先预览地点名称与坐标，再“分享位置”打开手机系统分享，或“复制信息”粘贴给朋友。内容只有选中地点的名称、经纬度和地图链接，不自动带上实时定位、照片、备注或其他收藏。
- 地图链接使用[高德单点标注URI](https://lbs.amap.com/api/uri-api/guide/mobile-web/point)，明确传WGS84，名称按URL参数编码。接收者通过链接查看指定位置，无需安装山兔；实际外部地图访问取决于接收端网络与应用。
- 已保存地点保留“导出标记文件”入口，模型标记的原导出流程不变。安卓返回键优先关闭地点分享窗；取消系统分享、旧APK缺接口和浏览器不支持分享均有反馈，复制权限不可用时可长按文字复制。

验证：类型检查、4项地点分享定向测试及React静态渲染检查通过；覆盖WGS84/经纬度顺序、特殊名称、坐标边界、私有字段排除、安卓桥接失败与浏览器取消。网页生产构建、最终APK编译、版本/签名/zipalign和473项内置地形资源检查通过。

限制：浏览器控制持续返回nodeRepl.fetch失败，未取得本轮390×844/360×780实际布局截图；Android系统分享面板、微信等接收应用以及真机触控尚待安装复核。分享只打开系统选择器，不代用户选联系人或发送。

安装：Android 8.0及以上，`Shantu-0.2.46-test-standalone.apk`，versionCode53，沿用独立山兔签名，直接覆盖安装。新增placeShare模块、PlaceOutput安卓适配和地点分享测试；改地点入口与桥接接线，路线分享、记录、离线包、收藏存储格式保持兼容。

HarmonyOS 6.1原生HAP/APP仍未交付，APK不代表原生鸿蒙支持。用户关于默认保存文件夹的提议还在沟通，本次未据此改动保存目录。

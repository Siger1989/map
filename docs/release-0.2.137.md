# 0.2.137-test：地图与缓存并发优化

用户反馈各图源地图加载慢，要求地图和缓存提速。不是宣称达到物理极限：图源带宽/配额、HTTP限流、手机解码和系统调度仍会影响吞吐。

## 修改

- MapLibre共享影像请求调度16→32；主图/双图共用有界队列，原有取消和图像清晰度保持。
- 坐标校正网络pipeline及共享输入4→8，CPU校正worker保持2；固定级别影像2→8，换视野取消旧图、不提交过期输出。
- 导入图源缓存（用户选择的自定义图源）浏览器/Android下载8→16。其它旧区域下载规则保持。
- Android `MapTransferBudget` 将在线地图/离线缓存分开计数，各最多16、总32；地图有请求时，离线新请求最多4，等待中的地图优先。在途离线下载自然结束，不强杀；地图空闲恢复16。预算等待不计入12秒网络超时，取消可唤醒队列。DNS最多8；连接池/同主机各32，继续复用。
- 含136的 `offlineBegin` 线程修复；原包名、签名、数据格式、已注册天地图与39种子保留。

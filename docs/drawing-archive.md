# 新建与续画、时间位置存档（2026-09-08）

底部「画线」打开后，主按钮始终是「新建轨迹」。「继续绘制」为有底色、边框和展开图标的次要按钮；展开后选择具体轨迹，再点击蓝色「继续所选轨迹」，地图定位到该轨迹末端。旧列表中的续画入口仍可使用。

点击绘制浮条的「完成」，有效轨迹自动保存到本机；新建下一条时不会连接上一条。当前还有有效草稿时，新建或切换续画先保存草稿。普通暂停、查看其他工具和调整节点不清空草稿。只有单点或含孤立点时无法作为完整线路存档，提示补点或撤销，草稿保留；存储满或写入失败也不会清空草稿。现有20条上限不变，未完成的内存草稿不保证在刷新或关闭应用后恢复。

新绘制默认名称含开始绘制时间和起点附近位置；保存创建时间、更新时间以及约1公里精度的起点位置。地名复用现有Photon/OpenStreetMap查询，只查询四舍五入到两位小数的位置；尚未查询到地名或离线时，用大概经纬度作为位置。完整轨迹坐标精度不变。

存档按最近更新排序，列表直接展示创建时间与位置；续画更新所选记录，保留原名称、创建时间和其他轨迹。已有无位置元数据的轨迹从起点派生大概位置，旧数据不需要迁移。实走/含逐点时间的轨迹续画仍创建手绘副本，原始坐标和时间保留。这里的绘制时间不是逐点GPS时间，不用于自动匹配照片。

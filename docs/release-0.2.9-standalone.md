# 山兔 0.2.9 独立测试版（2026-09-08）

## 本版功能

- 气温颜色图层：当前区域2米气温预报、℃色标、对应时间；精简为约60px高色标，来源点开查看，地图着色加深，空白处表示无数据。
- 多剖面：工具→剖面新建多条，地图同时显示，独立改名/移动/调整/显隐/删除与撤销；自动兼容原单剖面并保留测点键。JSON备份支持多剖面对象。
- 修复起终点仅输入文字后规划按钮灰色无说明：可点击并指出未确定坐标的地点。
- 手绘/收藏/规划导航先选驾车、骑行或步行；不在起点时，同模式规划接入段，经过原起点再继续主体。
- 规划、轨迹、收藏与导航全程可分享图片/GPX/KML/高德分段导航链接。图片包含完整线形、地名、起终点标记名称坐标、全程数据和海拔图。
- 分享图附离线路线二维码；工具→扫码载入路线，也能识别相册里的分享图。容量不足逐级简化弯道/概括为直线，明确标注简化阈值；保留起终点和途经点。完整图片及GPX/KML保持原始几何。
- 包含0.2.8的室内网络定位、扫码完整取景与镜头切换、权限返回修复、覆盖层重复刷新/小幅位置跟随抖动修复，以及实走记录样式选择。

说明：[本轮模块与使用](https://github.com/Siger1989/map/blob/main/docs/temperature-navigation-sharing.md)、[室内定位与相机](https://github.com/Siger1989/map/blob/main/docs/indoor-position-and-camera.md)。

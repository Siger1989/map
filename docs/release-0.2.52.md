# 山兔 0.2.52-test：后台地图缓存、细节锁定与路线规划预览

- 地图缓存窗口和收藏离线包增加进度条、完成数和容量。浏览器恢复下载先检查已有缓存，只补缺项。Android 新增持久瓦片存储和 dataSync 前台服务，支持通知进度/暂停、断网退避重试、返回应用读取进度；切换应用后下载由原生服务执行。
- 细节锁定优先用所选级别覆盖当前视野，相机可继续缩放；超出144张瓦片预算时保留中心固定级别、外围同图源概览。界面明确显示加载结果，不把低级别概览称作18级。道路与注记仍按各自图层缩放。
- 收藏打开时暂隐右侧地图工具；记录、设置等操作面板避让全局锁定入口。锁定后保留定位按钮及原有模式循环，并更新10秒回位基准。
- 路线详情和轨迹样式增加步行、跑步、自行车、摩托车、汽车选择，速度颜色与图例按出行方式分为五档。摩托车按20/40/60/80 km/h划分，便于辨别快慢。坡度界面从百分比改为角度，内部原始坡比和预警阈值保留。
- 导航准备可选择“沿原路线”或“按道路新规划”。步行、骑行、驾车实际请求原有规划服务，成功后显示新路线预览和统计；可切回原路线。等待、失败或过期响应不能作为新路线启动导航，原实走或手绘存档不覆盖。

修改范围：cartography、outdoor、collections、controls、guidance、position、routeAnalysis、routeDisplay、tracks、rally及安卓外壳。新增固定细节覆盖器、出行色标/角度工具、进度组件、原生离线存储/服务及相关测试；未删除用户数据。包名、签名、照片目录、原始轨迹和用户布局保持兼容，没有迁移默认保存文件夹或提交服务凭据。

验证：类型检查、54项定向测试、安卓网页生产构建、Java/DEX/APK构建通过；签名v2/v3、zipalign、版本59、543项ZIP内容、473地形瓦片、18项网页与7项原生功能标识核对通过。实际浏览器核对收藏进度与工具避让、锁定定位、固定级别全屏/中心状态；390×857和360×780真实组件检查导航预览与摩托速度色标。独立组件截图使用标注的测试地图和规划数据，不代表在线规划服务或真机验收。

## 本次内容

- 收藏轨迹/路线三点菜单提供缓存，收藏主页及文件夹三点菜单支持批量选择，地图选中路线及规划详情也可进入。
- 强制选择自定义在线图源，默认路线两侧各 4 km。多路线按独立线段合并去重；下载前估算、顺序下载、暂停续传及请求错误停止保持有效。自定义图源仍受服务方的授权、计费与额度约束。
- 收藏“缓存区域”显示路线名称、图源、实际已下载空间、百分比与项目数。点击条目切换缓存地图并关闭面板；删除为独立确认操作，保留其他包共用瓦片和原路线。
- 正式构建时 Tailwind 隐式扫描未在数分钟内完成，将扫描范围显式限定为 app、components、modules 和 mobile 顶层 TS/TSX；保持 CSS import 在 source 指令之前。新正式构建约 8 秒完成，当前使用 utility 类的源码目录只读审查无遗漏。

具体模块、前轮模拟数据与删除隔离证据见 [缓存实现记录](route-cache-20261024.md)。本轮不修改用户真实路线/存档、地图服务凭据或原生定位逻辑。

# 照片导入后自动回中（2026-11-10快速预览）

基于196/code203的未交付增量；与20–32px照片下限一起保留。本轮未升版/出APK/提交推送，不能说已安装手机得到新功能。

## 行为

- app/page.tsx在saveGpsPhotoMarkers成功返回后，设照片可见并立即查看本批位置；保留结果面板供查看成功/重复/无GPS结果，仍可点“查看地图”再次定位并关闭面板。
- modules/photos/focusGpsMarkers.ts：一个唯一标记位置回中，至少到16级，已近于16级则保留当前级别；多处用现有fitCollection范围查看，预留顶部面板、右侧工具和底栏空间。去掉重复/非法位置，没有可用坐标不移动地图。相机不可用或报错返回false，不把已保存的照片误报成保存失败。
- modules/photos/saveGpsMarkers.ts：只把本批真正带有效GPS的重复照片计入可回中位置，防止无GPS输入凭旧同hash记录误定位。新增/重复/合并和数据事务格式不变。

## 远处图标

根因：旧实现仅在 DOM 上隐藏选点；原生 Marker 仍参与移动事件中的投影/地形遮挡，其他注记和照片也仍计算远处对象。移动过程中显隐与原生更新不同步，会短暂露出远处图标。

新增 `modules/map/NearbyMarker.ts`、`nearbyMarkerRange.ts`：先按中心坐标、zoom、纬度和画布尺寸计算范围，原生 Marker 只挂载附近对象。范围随视窗变化，下限 150m，上限 30km；进入阈值为退出阈值的 90%，避免边界来回闪烁。这里仍有一次廉价距离筛选，范围外不进入原生投影、地形遮挡或 DOM 挂载。此范围是视窗附近的距离门禁，不采用高倾角下包含远处地平线的 bounds。

`TerrainMap.tsx` 的绿色选点和预览光标、`AnnotationLayer.ts` 的标记/模型标签、`PhotoLayer.ts` 的照片接入此门禁。照片在 `map.project`、DOM 和图片 URL 创建之前筛掉远点；脱离 DOM 的模型标签不再逐帧计算三维锚点。靠近时复用标记对象和元素，保留原坐标、样式与点击回调。删除旧 `selectionMarkerVisibility.ts` 与其测试，替换为原生挂载门禁测试；山体遮挡样式继续生效。

## 键盘与路线布局

根因有两层：系统键盘缩小 WebView 可视高度，`dvh` 随之收缩；同时原有短屏媒体查询误判为矮屏，缩小路线内容并改变右侧工具布局。

- `mobile/keyboardViewport.ts` 与 `compatibility.ts`：输入聚焦后，同宽度下高度明显缩小时锁定原布局高度，独立保留实际可视高度。关闭动画完成才恢复；宽度变化按旋转处理，移除监听会还原样式。
- PC同步时补充：仅移动设备或明确打开的预览模拟键盘允许冻结，普通桌面聚焦输入后缩小窗口高度正常响应。预览宿主在缩小iframe前设置键盘标记，关闭时移除；新增两项回归并实际复测手机三尺寸与PC四种尺寸。
- `routeCompact.css` 与 `outdoorTheme.css`：键盘打开时按原屏幕高度档位布局。真实矮屏仍使用矮屏规则，底部导航与地图工具不被键盘推高。
- `useRouteKeyboardFocus.ts` 与 `RoutePanel.tsx`：仅滚动路线卡片的内部内容，让聚焦输入框在键盘上方，卡片外框不被压缩。
- `phonePreviewKeyboard.js/.css` 与 `phone-preview.html`：点击输入框展示九宫格模拟键盘；支持示例中文候选、数字、空格、标点、删除、完成和 Escape。使用真实输入事件更新 React。九宫格只在预览宿主加载，手机 APK 继续使用系统输入法。模拟候选是少量常见地点，并非完整中文输入法；桌面键盘可输入任意文字。

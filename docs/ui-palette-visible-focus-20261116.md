# 右侧预览比例、配色和路线选点

右侧网页预览使用 [OPPO Find X8 Ultra 官方参数](https://www.oppo.com/cn/smartphones/series-find-x/find-x8-ultra/specs/) 的 1440×3168。用户提供的 1164×2560 真机截图，App 从约第 129 像素开始。390 CSS 像素宽的预览外框高 858，状态栏约 43，App 约 815。模拟键盘占用 App 内剩余高度。

左上角山兔菜单的配色设置使用公共标题和返回、关闭控件。预设与默认配色只写颜色，保留每项材质原有透明度、外观模式、对比度、磨砂、阴影、边缘宽度与圆角。预览已有临时调色时，切换配色同步颜色并保留临时透明度和尺寸，首次替换前留原草稿副本。保存的个人配色文件仍是该轮接续时的原件。选择「我的调色」可重用已保存颜色。

路线选中搜索结果、从地点发起路线和其他共用主动点位定位的操作，读取可见面板和地图工具实际边界，优先采用足够宽且高、面积最大的无覆盖矩形作为居中区域。键盘和正退出的窗口参与边界处理。路线结果在键盘尺寸变动后重新测量，接下来的地图手势和表单操作结束本次定位跟随。正常地图浏览、用户手动拖动和普通定位跟随继续使用既有路径。收藏沿用已验证的下方可视区域策略。主图、双图和安卓桥共用矩形计算。
